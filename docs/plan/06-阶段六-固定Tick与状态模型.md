# 阶段六：固定 Tick 与状态模型

> 前置依赖：阶段五全部完成标准达成
>
> 阶段交付：可由单机、回放和服务器共同驱动的玩法模拟

## 1. 阶段目标

将完整单机玩法整理为普通 C# 状态数据和固定 Tick 模拟。输入来源、玩法规则和 Unity 表现形成清晰边界，为服务器权威同步提供稳定基础。

## 2. 输入帧

输入帧包含：

- 玩家标识。
- 输入序号。
- 目标 Tick。
- 移动方向。
- 跳跃动作位。
- 冲刺动作位。
- 拾取动作位。
- 投掷动作位。
- 使用药水动作位。
- 瞄准或投掷方向。

输入采集在渲染帧读取设备状态，并在模拟 Tick 到来时生成一次输入帧。

## 3. 状态数据

### 3.1 玩家状态

- 标识。
- 位置和旋转。
- 线速度。
- 地面状态。
- 动作状态。
- 生命值。
- 生存状态。
- 冲刺状态和冷却。
- 药水效果。
- 持有道具。
- 最近有效作用。
- 分数。

### 3.2 道具状态

- 标识和类型。
- 位置和旋转。
- 线速度和角速度。
- 生命周期状态。
- 持有者。
- 最近作用者。
- 倒计时。
- 药水效果类型。

### 3.3 回合状态

- 当前阶段。
- 阶段开始 Tick。
- 阶段结束 Tick。
- 玩家分数。
- 目标分数。
- 胜者。
- 复活队列。

### 3.4 事件状态

- 事件类型。
- 事件阶段。
- 阶段计时。
- 安全区。
- 伤害参数。

### 3.5 游戏状态

游戏状态汇总当前 Tick、随机状态、玩家、道具、回合和事件。

## 4. 固定 Tick 循环

以 30Hz 作为起始频率。

每个 Tick 按以下顺序推进：

1. 读取输入帧。
2. 更新回合阶段。
3. 更新玩家移动和动作。
4. 更新碰撞、推挤和伤害。
5. 更新道具状态。
6. 更新药水效果。
7. 更新酸雨事件。
8. 处理死亡、掉落和计分。
9. 生成玩法事件。
10. 输出新状态。

模拟时钟管理暂停、结算、重开和时间缩放语义。

## 5. Unity 表现边界

### 5.1 状态应用

表现层读取状态并更新：

- 角色 Transform。
- 道具 Transform。
- 动画参数。
- 粒子和音效。
- 镜头。
- UI。

### 5.2 事件应用

玩法事件驱动：

- 起跳和落地。
- 冲刺开始和结束。
- 命中和受击。
- 拾取和投掷。
- 爆炸。
- 药水开始和结束。
- 淘汰和复活。
- 回合转换。

## 6. 真人与机器人统一

- 真人输入采集器生成 `InputFrame`。
- 机器人控制器生成 `InputFrame`。
- 回放读取器生成 `InputFrame`。
- 网络客户端输入接收器生成 `InputFrame`。
- 玩法模拟只消费输入帧。

## 7. 随机数

- 游戏状态保存随机种子和随机推进状态。
- 道具刷新使用模拟随机数。
- 药水颜色与效果映射使用模拟随机数。
- 酸雨触发和安全区选择使用模拟随机数。
- 回放从记录的随机状态开始。

## 8. 输入记录与回放

记录内容：

- 初始配置。
- 初始随机状态。
- 每 Tick 输入帧。
- 关键玩法事件。
- 周期性状态摘要。

回放流程：

```text
加载初始配置
  → 恢复随机状态
  → 按 Tick 输入记录
  → 推进玩法模拟
  → 比较关键状态
```

比较内容：

- 回合结束 Tick。
- 淘汰顺序。
- 分数。
- 胜者。
- 道具关键状态。
- 玩家关键位置误差。

## 9. 完成标准

- [ ] 模拟以 30Hz 固定 Tick 推进。
- [ ] 渲染帧率变化保持关键玩法结果稳定。
- [ ] 玩家、道具、回合和事件使用普通状态数据。
- [ ] Unity 表现通过单向状态应用更新。
- [ ] 真人、机器人和回放共用输入帧。
- [ ] 随机状态可以记录和恢复。
- [ ] 三局完整输入回放的分数、胜者和淘汰顺序一致。
- [ ] 游戏状态可以序列化为 Unity 对象之外的数据。

## 10. 测试用例

- 30、60、120 渲染帧率下运行相同输入。
- 暂停和恢复模拟。
- 结算阶段 Tick 行为。
- 回合重开后的 Tick 和随机状态。
- 真人输入替换为机器人输入。
- 真人输入替换为回放输入。
- 药水和酸雨随机结果复现。
- 同 Tick 多事件顺序。

## 11. 风险与控制

| 风险 | 控制 |
|---|---|
| 一次性抽取全部玩法导致回归 | 按玩家、回合、道具和事件逐步迁移 |
| 表现脚本继续写入玩法状态 | 使用单向状态应用接口和调试断言 |
| 浮点误差影响回放 | 比较关键状态和误差范围 |
| PhysX 更新与模拟 Tick 分离 | 明确物理推进和状态采样顺序 |
