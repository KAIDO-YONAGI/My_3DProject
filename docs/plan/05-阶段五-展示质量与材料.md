# 阶段五：展示质量与材料
> 前置：阶段四完成；交付：可独立运行、可录制、可讲解的单机垂直切片
## 1. 表现范围
角色完成待机、移动、跳跃、下落、落地、冲刺、受击、持有、投掷、死亡、复活和胜利表现。音效覆盖移动、跳跃、冲刺、命中、受击、拾取、投掷、药水、爆炸、酸雨、淘汰和结算。
粒子与视觉反馈覆盖冲刺轨迹、命中火花、击退方向、药水颜色、爆炸范围、酸雨区域、安全区和复活保护。所有反馈服务于动作判读，强度和持续时间受配置限制。
## 2. 镜头与 UI
镜头具备平滑跟随、边界约束、高速前视、冲刺和爆炸轻量震动、死亡与复活过渡、结算胜者聚焦。对局 UI 显示生命、分数、回合时间、冲刺冷却、药水效果、爆炸物倒计时和酸雨提示；结算 UI 显示得分变化、淘汰来源、排名、胜者和重开入口；调试 UI 显示状态、速度、活跃对象和事件阶段。
## 3. 构建与材料
构建从干净目录生成，验证启动场景、首次运行、连续多局、退出、再次启动和控制方式。视频展示竞技场、核心动作、推挤淘汰、药水、爆炸物、酸雨、回合结算和比赛结果，内容以实际可运行能力为准。
README 说明目标、操作、已实现功能、技术结构、Mirror 边界、运行方式、测试方式和当前取舍。架构图同时展示单机固定 Tick 和 Mirror 服务器权威链路。
## 4. 完成标准
□ 角色核心动作具有动画、音效和视觉反馈；
□ 道具与酸雨状态清晰；
□ 镜头稳定展示对抗；
□ 对局与结算 UI 完整；
□ 构建可连续完成多局；
□ 视频覆盖玩法循环；
□ README 和架构图与实际结果一致；
□ 项目可在 3～5 分钟内讲清楚。
测试不同分辨率、长文本、多位数分数、多效果同时显示、爆炸与酸雨并发、镜头边缘、高速击退、连续回合清理和构建重复启动。
