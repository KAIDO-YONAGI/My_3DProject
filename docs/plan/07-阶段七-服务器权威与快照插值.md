# 阶段七：服务器权威与快照插值

> 前置依赖：阶段六全部完成标准达成
>
> 阶段交付：双客户端可连续完成整局的服务器权威联机样片

## 1. 阶段目标

接入 Unity Transport 2.x，由 Unity Server Build 运行固定 Tick 玩法模拟。客户端发送输入帧，服务器生成权威状态快照，远端角色和道具通过插值显示。

## 2. 依赖与工程

- 在当前 Unity 版本中引入兼容的 Unity Transport 2.x。
- 锁定实际使用的包版本。
- 建立客户端和服务器共同引用的协议程序集。
- 建立 Server Build 场景入口。
- 建立本地多客户端启动方式。
- 保持玩法模拟程序集独立于客户端表现。

## 3. 传输接口

传输接口提供：

- 启动服务器。
- 停止服务器。
- 连接服务器。
- 断开连接。
- 发送数据。
- 接收数据。
- 连接事件。
- 断开事件。
- 传输错误事件。

Unity Transport 适配器实现接口，协议和玩法层只依赖接口。

## 4. 连接与玩家映射

连接流程：

```text
客户端建立传输连接
  → 发送加入请求
  → 服务器验证协议和容量
  → 创建玩家标识
  → 发送加入确认和当前比赛状态
  → 客户端进入快照流
```

服务器保存：

- 连接标识。
- 玩家标识。
- 最近输入序号。
- 最近接收时间。
- 玩家状态引用。
- 加入状态。

## 5. 输入上传

客户端输入包包含：

- 协议版本。
- 玩家标识。
- 输入序号。
- 目标 Tick。
- 一个或多个输入帧。

服务器校验：

- 玩家映射。
- 输入序号。
- Tick 范围。
- 移动向量范围。
- 动作位。
- 输入频率。
- 数据包长度。

服务器缓存可接受输入，并在目标 Tick 消费。

## 6. 服务器 Tick

服务器每 Tick：

1. 为每名玩家选择输入帧。
2. 为缺失输入应用明确策略。
3. 推进权威玩法模拟。
4. 处理玩家、道具和事件。
5. 结算伤害、淘汰、得分和胜负。
6. 更新已处理输入序号。
7. 按快照频率生成状态快照。

缺失输入策略采用最近有效移动输入和一次性动作清零，具体持续 Tick 数由配置管理。

## 7. 状态快照

快照包含：

- 服务器 Tick。
- 快照序号。
- 每名玩家已处理输入序号。
- 玩家状态。
- 道具状态。
- 回合状态。
- 全局事件状态。

离散玩法事件可以作为快照状态变化或独立可靠消息传输，实施时按丢失影响选择。

## 8. 快照缓冲与插值

客户端流程：

```text
接收快照
  → 校验协议和序号
  → 按服务器 Tick 排序
  → 写入快照缓冲
  → 计算目标显示 Tick
  → 查找前后快照
  → 插值位置和旋转
  → 应用离散状态
```

插值对象：

- 远端玩家位置和旋转。
- 爆炸物位置和旋转。
- 移动障碍物状态。

离散应用对象：

- 死亡和复活。
- 拾取和释放。
- 爆炸。
- 药水效果。
- 回合阶段。
- 酸雨阶段。

## 9. Late Join

Late Join 接收：

- 当前服务器 Tick。
- 当前回合状态。
- 全部玩家状态。
- 全部活跃道具状态。
- 当前药水效果。
- 当前酸雨阶段和安全区。

客户端完成初始状态应用后进入增量快照流。

## 10. 断线处理

- 客户端主动离开发送离开请求。
- 服务器按连接关闭或超时移除玩家。
- 持有道具按规则释放或回收。
- 药水效果和归属记录按玩家移除规则清理。
- 回合控制器重新判断剩余玩家和胜利条件。

## 11. 完成标准

- [ ] Unity Server Build 可独立启动并推进比赛。
- [ ] 两个客户端可加入同一比赛。
- [ ] 客户端发送输入帧，服务器生成最终状态。
- [ ] 两个客户端连续完成多局，分数和胜负一致。
- [ ] 远端玩家和爆炸物显示平滑。
- [ ] Late Join 获得完整当前状态。
- [ ] 主动离开和异常断线完成玩家与道具清理。
- [ ] 双客户端稳定后扩展到 5 个客户端。
- [ ] 服务器 Tick、快照频率和上下行字节数可以观测。

## 12. 测试用例

- Server Build 启动和关闭。
- 两客户端同时加入。
- 客户端逐个加入。
- 回合中 Late Join。
- 回合结算时 Late Join。
- 主动离开。
- 进程直接关闭。
- 持有爆炸物时离开。
- 药水效果期间离开。
- 酸雨期间离开。
- 快照重复。
- 快照乱序。
- 快照间隔波动。

## 13. 风险与控制

| 风险 | 控制 |
|---|---|
| 协议结构与状态模型耦合 | 使用独立网络数据结构和显式转换 |
| 快照体积增长 | 按状态频率分类并记录实际字节数 |
| 远端对象抖动 | 使用 Tick 排序、插值缓冲和时间同步 |
| Late Join 状态缺失 | 初始完整状态覆盖玩家、道具、回合和事件 |
| 断线留下持有关系 | 玩家移除流程统一释放或回收关联对象 |
