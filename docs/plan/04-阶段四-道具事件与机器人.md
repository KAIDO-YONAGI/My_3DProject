# 阶段四：道具、事件与机器人
> 前置：阶段三完成；交付：玩家与机器人使用完整玩法完成多局比赛
## 1. 机器人
机器人每个模拟 Tick 生成与玩家相同的 `InputFrame`，输入包括移动、跳跃、冲刺、拾取、投掷和使用药水。感知自身状态、玩家位置与生存状态、场地边界、KillZone、附近道具和酸雨安全区。
行为优先级为脱离危险区域、进入安全区、选择目标、接近目标、在有效距离冲刺、拾取道具、投掷爆炸物和使用药水。先保证不出场和能完成整局，再调整攻击强度。
## 2. 药水
药水状态包含颜色、效果、持续时间、数值参数、叠加规则、刷新权重、表现标识和来源。生命周期为 `刷新 → 空闲 → 拾取 → 使用 → 生效 → 结束 → 回收`。
加速修改移动或冲刺参数；中毒按固定间隔造成伤害并参与归属；致盲只改变本地表现，保持角色状态和网络状态清晰。死亡、复活、回合重开和回收都清理效果。
## 3. 爆炸物与酸雨
爆炸物生命周期为 `Spawned → Free → Held → Thrown → Free → Exploded → Recycled`。服务器验证拾取距离、物品状态和持有者唯一性；投掷和踢动更新权威速度与作用者；爆炸结算伤害、击退和可恢复平台状态。
酸雨状态为 `Inactive → Warning → Active → Ending → Inactive`。预警显示安全区和倒计时，生效阶段按固定间隔检查区域并造成伤害，结束阶段停止伤害、清理表现并恢复场地。
## 4. 重置、完成标准与测试
重置位置、父节点、速度、持有者、作用者、倒计时、冷却、效果、Collider、Rigidbody、Renderer、粒子、音效、事件订阅和预反馈。完成标准为机器人参加整局；2～3 种药水正确生效；爆炸物可重复刷新、拾取、投掷、踢动、爆炸和回收；酸雨完整运行；玩家与机器人连续完成 10 局。
测试同时拾取、持有时死亡、投掷后爆炸、踢动后爆炸、进入 KillZone、药水中死亡、酸雨中复活、机器人同时面对道具和危险区域。对象状态由唯一状态机驱动，回合控制器统一启动、暂停和清理事件。
