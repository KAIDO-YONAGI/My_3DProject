# 阶段四：道具、事件与机器人

> 前置依赖：阶段三全部完成标准达成
>
> 阶段交付：具备随机变化和单人完整对抗的玩法闭环

## 1. 阶段目标

加入基础机器人、颜色药水、爆炸投掷物和酸雨事件。阶段完成后，一名玩家可以与机器人连续完成多局比赛，道具和事件能够改变局势。

## 2. 基础机器人

### 2.1 输入边界

机器人每个模拟步生成与玩家相同的输入帧：

- 移动方向。
- 跳跃。
- 冲刺。
- 拾取。
- 投掷。
- 使用药水。

### 2.2 感知信息

机器人读取：

- 自身状态。
- 其他玩家位置和生存状态。
- 场地中心和边界。
- KillZone 距离。
- 附近道具。
- 酸雨安全区。

### 2.3 行为优先级

1. 脱离场地边缘和危险区域。
2. 进入酸雨安全区。
3. 选择目标玩家。
4. 接近目标。
5. 在有效距离冲刺。
6. 拾取附近道具。
7. 投掷爆炸物。
8. 使用药水。

机器人先保证完整参与和稳定移动，再调整对抗强度。

## 3. 药水系统

### 3.1 数据

药水配置包含：

- 颜色。
- 效果类型。
- 持续时间。
- 数值参数。
- 叠加规则。
- 刷新权重。
- 视觉和音效标识。

### 3.2 效果

加速：

- 修改移动或冲刺参数。
- 效果结束后恢复基础值。

中毒：

- 按固定间隔产生伤害。
- 记录效果来源。
- 参与淘汰归属。

致盲：

- 调整本地画面表现。
- 保持角色状态和网络状态可读。

### 3.3 生命周期

```text
刷新
  → 空闲
  → 拾取
  → 使用
  → 生效
  → 结束
  → 回收
```

## 4. 爆炸投掷物

### 4.1 状态机

```text
Spawned
  → Free
  → Held
  → Thrown
  → Free
  → Exploded
  → Recycled
```

### 4.2 交互

- 玩家接近后拾取。
- 持有者唯一。
- 玩家选择方向并投掷。
- 地面、玩家和障碍物可以改变运动轨迹。
- 倒计时持续推进。
- 爆炸产生范围伤害和击退。

### 4.3 归属

- 拾取更新当前持有者。
- 投掷更新最近投掷者。
- 踢动更新最近作用者。
- 爆炸伤害使用最近有效作用者。

### 4.4 平台作用

首版爆炸触发以下一种可恢复效果：

- 预制平台块暂时下降。
- 预制缺口暂时打开。
- 爆炸区域短时间成为危险地面。

效果结束或回合重开时恢复场地。

## 5. 酸雨事件

### 5.1 状态

```text
Inactive
  → Warning
  → Active
  → Ending
  → Inactive
```

### 5.2 行为

- `Warning` 显示安全区和倒计时。
- `Active` 周期性检查玩家所在区域。
- 暴露玩家按固定间隔受到伤害。
- `Ending` 停止伤害并清理表现。

### 5.3 回合集成

- 回合控制器决定触发时机。
- 比赛结算暂停事件推进。
- 回合重开恢复事件初始状态。
- 事件伤害进入环境统计或配置的归属规则。

## 6. 生命周期重置

道具和事件重置以下内容：

- Transform 和父节点。
- 线速度和角速度。
- 持有者和最近作用者。
- 倒计时和冷却。
- 药水效果和持续时间。
- Collider 和 Rigidbody 状态。
- Renderer、粒子和音效。
- 事件订阅和延迟任务。

## 7. 完成标准

- [ ] 机器人使用输入帧参与完整比赛。
- [ ] 机器人能够避开场地边缘和酸雨危险区域。
- [ ] 2～3 种药水效果可以正确开始、刷新和结束。
- [ ] 爆炸物可以重复刷新、拾取、投掷、踢动、爆炸和回收。
- [ ] 爆炸伤害和淘汰归属正确。
- [ ] 酸雨完成预警、生效和结束流程。
- [ ] 回合重开后全部道具、效果和事件恢复初始状态。
- [ ] 一名玩家与机器人连续完成 10 局。

## 8. 测试用例

- 两名角色同时拾取同一爆炸物。
- 持有爆炸物时死亡。
- 投掷后爆炸。
- 踢动后爆炸。
- 爆炸物落入 KillZone。
- 药水效果期间死亡。
- 同类药水连续使用。
- 酸雨预警期间回合结束。
- 酸雨生效期间玩家复活。
- 机器人同时面对道具和危险区域。

## 9. 风险与控制

| 风险 | 控制 |
|---|---|
| 道具状态和物理状态双向覆盖 | 使用唯一状态机驱动持有、释放和回收 |
| 药水组合降低可读性 | 首版限制效果数量并提供清晰持续反馈 |
| 机器人逻辑范围过大 | 使用优先级状态机完成最小行为 |
| 酸雨与回合状态冲突 | 回合控制器统一启动、暂停和清理事件 |
