# 阶段三：手感、冲刺与推挤
> 前置：阶段二完成；交付：能够稳定形成对抗的核心动作系统
## 1. 操作手感
跳跃和冲刺使用输入缓冲，每次动作只消费一次；离开平台后保留跳跃宽限；空中加速度和转向低于地面；所有窗口和上限进入配置。
冲刺状态为 `Ready → Starting → Active → Recovery → Cooldown → Ready`，配置启动、持续、恢复、冷却、速度或冲量、转向、命中伤害、击退和单次命中限制。
## 2. 推挤、受击与归属
推挤来源包括身体接触和冲刺命中，道具与爆炸物使用同一作用记录接口。受击处理生命、击退、短暂受击状态、作用者、作用类型和发生 Tick，并生成表现事件。
角色设置地面、空中、冲刺、击退和垂直速度上限。高速移动使用连续碰撞检测或分段查询，避免穿透场地和目标。
记录作用者、目标、作用类型、伤害、击退、发生 Tick 和归属过期 Tick。直接伤害使用当前有效记录；推挤掉落使用时间窗内最近记录；环境伤害进入环境统计；复活清理旧记录。
## 3. 验收与调试
调试显示速度、地面、动作、冲刺剩余、冷却、最近作用者、归属剩余时间、最近伤害和击退值。测试移动、跳跃、冲刺、静止目标、双方同时冲刺、连续接触、推挤后掉落、受击后进入 KillZone 和复活后再次受击。
通过标准为核心动作稳定，冲刺命中只产生一次明确伤害和击退，两名玩家可以完成淘汰，直接伤害、推挤掉落和环境淘汰归属正确。连续碰撞用单次命中集合和受击间隔控制，命中与动作由统一模拟步推进。
