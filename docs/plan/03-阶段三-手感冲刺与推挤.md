# 阶段三：手感、冲刺与推挤

> 前置依赖：阶段二全部完成标准达成
>
> 阶段交付：能够形成稳定对抗的核心动作系统

## 1. 阶段目标

让移动、跳跃、冲刺、推挤和击退形成完整对抗。玩家可以只依靠角色动作制造伤害和淘汰，得分归属具有稳定规则。

## 2. 操作手感

### 2.1 输入缓冲

- 跳跃输入保存短时间窗口。
- 冲刺输入保存短时间窗口。
- 输入在角色恢复可行动状态后消费。
- 每次输入只消费一次。

### 2.2 跳跃宽限

- 角色离开平台边缘后保留短暂跳跃时间。
- 角色落地前按下跳跃可以在落地后触发。
- 宽限时间由配置数据管理。

### 2.3 空中控制

- 空中加速度低于地面加速度。
- 空中转向具有上限。
- 冲刺后的空中控制按动作状态调整。

## 3. 冲刺

冲刺状态包括：

```text
Ready
  → Starting
  → Active
  → Recovery
  → Cooldown
  → Ready
```

关键参数：

- 启动时间。
- 持续时间。
- 恢复时间。
- 冷却时间。
- 速度或冲量。
- 转向能力。
- 命中伤害。
- 命中击退。
- 单次冲刺命中次数限制。

## 4. 推挤与受击

### 4.1 推挤来源

- 玩家身体接触。
- 冲刺命中。
- 爆炸和道具作用预留统一接口。

### 4.2 受击结果

- 扣除生命值。
- 应用击退速度。
- 进入短暂受击状态。
- 记录攻击者、作用类型和发生 Tick。
- 触发动画、音效和粒子事件。

### 4.3 速度约束

- 地面移动速度上限。
- 空中移动速度上限。
- 冲刺速度上限。
- 击退速度上限。
- 垂直速度上限。

速度约束保证角色保持可控和可读。

## 5. 淘汰归属

记录结构包含：

- 作用者。
- 目标玩家。
- 作用类型。
- 伤害值。
- 击退强度。
- 发生 Tick。
- 归属过期 Tick。

归属规则：

1. 直接伤害致死使用当前有效作用记录。
2. 推挤后掉落使用归属时间窗内的最近有效记录。
3. 环境伤害进入环境统计。
4. 新的有效作用覆盖旧记录。
5. 复活时清空旧记录。

## 6. 调试工具

调试显示：

- 当前速度。
- 地面状态。
- 动作状态。
- 冲刺剩余时间。
- 冲刺冷却。
- 最近作用者。
- 归属剩余时间。
- 最近伤害和击退值。

## 7. 完成标准

- [ ] 移动、跳跃和冲刺在目标帧率范围内保持稳定。
- [ ] 输入缓冲和跳跃宽限按配置工作。
- [ ] 冲刺命中产生一次明确伤害和击退。
- [ ] 两名玩家可以通过核心动作完成淘汰。
- [ ] 直接伤害、推挤掉落和环境淘汰归属正确。
- [ ] 复活后旧伤害和归属状态完成清理。
- [ ] 所有关键参数通过集中配置调整。

## 8. 测试用例

- 冲刺命中静止目标。
- 双方同时冲刺。
- 连续接触同一目标。
- 推挤后立即掉落。
- 推挤后归属时间窗结束再掉落。
- 受击期间进入 KillZone。
- 复活后再次受击。
- 高速移动接触场地边缘。

## 9. 风险与控制

| 风险 | 控制 |
|---|---|
| 连续碰撞重复伤害 | 使用单次动作命中集合和受击间隔 |
| 高速击退穿过碰撞体 | 速度上限、连续碰撞检测和场地边界检查 |
| 多人作用归属混乱 | 记录最近有效作用和过期 Tick |
| 渲染帧率影响命中 | 命中与动作状态放入统一模拟步进 |
