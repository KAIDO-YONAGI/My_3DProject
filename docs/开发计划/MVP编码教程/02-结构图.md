# 02 找出删格子后还连着的部分

这一章只回答一个问题：删掉几个格子后，剩下的格子分成了几片？先理解规则，再把规则写成代码。这里不创建测试组件，也不运行物理模拟。

## 1. 用格子编号描述连接

平台每格有一个编号。两个格子只有共用一条边时才算相邻；只碰到角不算。对编号 `40` 而言，四个候选邻格是：

```text
左：39    右：41    下：31    上：49
```

但候选编号还要检查是否真的存在于平台上。例如把编号 `32` 删除后，剩余格子 `30、31、33、34` 形成两组：

```text
30 -- 31       33 -- 34
```

这和在 Unity 里查看 Cube 是否碰撞无关。图搜索只看格子编号和相邻规则，结果之后才交给平台物理代码处理。

## 2. 先写出一次搜索

在 `Assets/Core/Scripts/Gameplay/Mvp/` 创建 `PlatformGraph.cs`。第一步先写一个方法：从一个格子开始，把所有能沿边走到的格子找出来。

```csharp
using System.Collections.Generic;

namespace Core.Scripts.Gameplay.Mvp
{
    public static class PlatformGraph
    {
        private static List<int> FindOneGroup(
            int start,
            HashSet<int> remaining)
        {
            var group = new List<int>();
            var queue = new Queue<int>();

            // 从起点开始，之后找到的相邻格都排进同一条待处理队列。
            remaining.Remove(start);
            queue.Enqueue(start);

            while (queue.Count > 0)
            {
                int current = queue.Dequeue();
                group.Add(current);

                int x = current % PlatformLayout.Width;
                int z = current / PlatformLayout.Width;

                if (x > 0)
                    AddIfPresent(current - 1, remaining, queue);
                if (x < PlatformLayout.Width - 1)
                    AddIfPresent(current + 1, remaining, queue);
                if (z > 0)
                    AddIfPresent(current - PlatformLayout.Width, remaining, queue);
                if (z < PlatformLayout.Width - 1)
                    AddIfPresent(current + PlatformLayout.Width, remaining, queue);
            }

            return group;
        }
    }
}
```

`queue` 是“已经发现、还没检查”的格子。每轮取出一个格子，把它加入 `group`，再检查它的四个方向。边界条件防止编号 `8` 的右边错误地连到下一行的 `9`：这两个编号相差一，但在棋盘上并不共边。

把下面的方法加到 `PlatformGraph` 类中，放在 `FindOneGroup` 后面、类的最后一个 `}` 前：

```csharp
private static void AddIfPresent(
    int candidate,
    HashSet<int> remaining,
    Queue<int> queue)
{
    // Remove 同时完成“存在吗”和“访问过了吗”两项检查。
    if (remaining.Remove(candidate))
    {
        queue.Enqueue(candidate);
    }
}
```

`remaining` 初始装着所有还存在的平台格子。格子一旦被放入队列，就立刻从 `remaining` 移除；这样它不会因为周围有多个邻居而被重复搜索。

## 3. 让搜索找出所有组

一个起点只能找到与它连通的一组。要找完整个平台上的所有组，就从还留在 `remaining` 里的格子继续搜索。把下面这个方法加到 `PlatformGraph` 类中：

```csharp
public static List<List<int>> Split(IEnumerable<int> cells)
{
    var remaining = new HashSet<int>(cells);
    var groups = new List<List<int>>();

    while (remaining.Count > 0)
    {
        // 取任意一个未访问格子，它所在的整组都会被 FindOneGroup 找到。
        int start = 0;
        foreach (int cellId in remaining)
        {
            start = cellId;
            break;
        }

        groups.Add(FindOneGroup(start, remaining));
    }

    return groups;
}
```

这三段放在同一个 `PlatformGraph` 类里，文件顶部保留第一段已有的 `using System.Collections.Generic;` 即可。保存文件，等 Unity 编译后再继续。

`Split` 的过程可以手算：先从 `{30,31,33,34}` 任选一个起点。若从 `30` 开始，第一次搜索得到 `{30,31}`；`remaining` 只剩 `{33,34}`，第二次搜索得到 `{33,34}`。最终返回两组。

## 4. 在实际玩法里怎么看结果

保存脚本并等待 Unity 编译。此时它还没有挂到场景，也不会改变游戏画面。第 03 章的平台代码会在服务器实际破坏平台后调用 `PlatformGraph.Split`；你可以从格子被移除和剩余碎片的形状观察结果。

“连通”不等于“有支撑”。`Split` 只把共边相连的格子分组。之后平台代码才检查每组是否包含 `PlatformLayout.IsAnchor(cellId)` 返回 `true` 的外边缘格子。只有原本锚定、且新组仍含锚点时，新组才保持固定。

因此本例的两组虽然各自连通，但 `30、31、33、34` 都不是外边缘格子；它们不会仅仅因为连通就获得支撑。图搜索负责回答“连成几组”，物理代码负责回答“哪组固定、哪组下落”。
