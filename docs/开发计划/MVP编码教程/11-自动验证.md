# 11 自动验证

本章先在独立 .NET 控制台工程中执行纯 C# 核心测试，再到 Unity 中检查完整适配层的编译与 Mirror Weaver。两个环境分别给出自己的证据。

| 验证环节 | 输入 | 验证内容 | 观察结果的位置 |
| --- | --- | --- | --- |
| 独立核心测试 | 01 至 04 章的四个文件和本章 `Tests/Program.cs` | 图算法、输入拒绝、协议编码、快照与恢复 | PowerShell 终端的测量行、PASS 或异常 |
| Unity 编译与 Weaver | 01 至 09 章的全部文件、工程内 Mirror 与 Input System | Unity 类型引用、partial 类、网络消息与 SyncVar 的代码生成 | Unity Console 与 Editor 日志 |
| 运行验收 | 第 10 章的场景与 Windows 构建 | 真实 PhysX、碰撞、玩家权限、客户端显示与联机恢复 | 第 12 章的画面、日志、调试器和 Profiler |

核心测试中的丢包、重复与延迟是内存队列模拟。真实 UDP 传输和 PhysX 接触在第 12 章运行。这样每次失败都能对应到具体层级。

## 接上当前项目：这条命令具体检查哪一份代码

当前工程的正式角色、场景与网络脚本位于 `Assets/Core/`，工程测试位于 `Assets/Tests/`。本章第一段命令从教程 Markdown 提取四个核心文件和本章测试入口，放进新的系统临时目录编译。**终端出现 PASS，说明提取出的教学核心通过断言；Unity 适配层和正式游戏各自使用对应的编译、测试与运行检查。**

第一次使用时，先完整运行命令，找到输出中的独立目录与 PASS 行。再按失败提示回到对应章节读函数：

| 你想确认什么 | 看哪组测试 | 回到哪章理解 |
| --- | --- | --- |
| 平台切开以后分组对不对 | `GraphTests` | 第 02 章 |
| 重复按键包会不会被接受两次 | `InputTests` | 第 01 章 |
| 发出去的数据能否按精度要求读回来 | `WireTests` | 第 03 章 |
| 先到运动包、后到基线能否恢复 | `ReplicaTests` | 第 04 章 |

阅读顺序是 01—04 → 本章核心验证 → 05—09 → 本章 Unity 编译检查 → 第 10、12 章。当前源码与教程的联系见 [00 导读](00-从当前项目开始.md)。

## 1. 一次执行完整核心验证

准备条件：

1. 打开 PowerShell 7，例如从开始菜单打开 `PowerShell 7 (x64)`。命令中的版本检查会说明当前终端是否符合要求。
2. 确认本教程位于 `D:/Unity/Projects/My_3DProject/docs/开发计划/MVP编码教程/`。工程在其他位置时，只修改下面的 `$tutorialDir`。
3. 安装 .NET SDK，SDK 包含编译器和控制台工程模板。本机可执行文件为 `C:/Program Files/dotnet/dotnet.exe`，命令先检查这个位置，再尝试 PATH。
4. 完整执行下面唯一的 PowerShell 代码块。它把 5 个 `csharp file=` 完整代码块提取到系统临时目录，创建独立工程并编译运行。原教程与 Unity 源文件保持原样。

**PowerShell 块 1：提取、建工程、指定 C# 9、编译、运行。**

```powershell
$ErrorActionPreference = 'Stop'
Set-StrictMode -Version Latest
if ($PSVersionTable.PSVersion.Major -lt 7) {
    throw '请在 PowerShell 7 中执行这整块命令。'
}

$tutorialDir = 'D:/Unity/Projects/My_3DProject/docs/开发计划/MVP编码教程'
$dotnet = 'C:/Program Files/dotnet/dotnet.exe'
if (-not (Test-Path -LiteralPath $dotnet)) {
    $dotnetCommand = Get-Command dotnet -CommandType Application -ErrorAction Stop
    $dotnet = $dotnetCommand.Source
}
$sdkList = @(& $dotnet --list-sdks)
if ($LASTEXITCODE -ne 0 -or $sdkList.Count -eq 0) {
    throw '找不到可用的 .NET SDK，请检查 dotnet --list-sdks 的输出。'
}
Write-Host "使用 dotnet：$dotnet"
$sdkList | ForEach-Object { Write-Host $_ }

# 每次使用新的临时目录，避免上一轮提取文件或构建结果影响本次验证。
$testDir = Join-Path ([IO.Path]::GetTempPath()) ('MvpCoreChecks-' + [Guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $testDir | Out-Null
Write-Host "独立测试目录：$testDir"

# 从临时目录创建项目，使项目目录外的仓库构建配置与 global.json 保持隔离。
Push-Location -LiteralPath $testDir
try {
    & $dotnet new console --name MvpCoreChecks --output $testDir --no-restore
    if ($LASTEXITCODE -ne 0) { throw '创建控制台工程失败。' }
} finally {
    Pop-Location
}
$project = Join-Path $testDir 'MvpCoreChecks.csproj'

# .NET SDK 版本决定目标框架；LangVersion 决定本次源码允许的 C# 语法。
# 禁用模板生成的 global using，避免 C# 9 编译时出现 C# 10 语法错误。
$projectXml = [System.Xml.Linq.XDocument]::Load($project)
$properties = $projectXml.Root.Element([System.Xml.Linq.XName]'PropertyGroup')
if ($null -eq $properties) { throw '控制台工程缺少 PropertyGroup。' }
$properties.SetElementValue([System.Xml.Linq.XName]'LangVersion', '9.0')
$properties.SetElementValue([System.Xml.Linq.XName]'ImplicitUsings', 'disable')
$properties.SetElementValue([System.Xml.Linq.XName]'Nullable', 'disable')
$projectXml.Save($project)

# 模板的 Program.cs 使用顶级语句；本章提供有 Main 的完整测试入口。
Remove-Item -LiteralPath (Join-Path $testDir 'Program.cs')
$expected = @(
    'Core/Model.cs'
    'Core/Structure.cs'
    'Core/Wire.cs'
    'Core/Replica.cs'
    'Tests/Program.cs'
)
$chapters = @(
    '01-数据与职责.md'
    '02-结构图.md'
    '03-编码协议.md'
    '04-快照与恢复.md'
    '11-自动验证.md'
)
$seen = [Collections.Generic.HashSet[string]]::new([StringComparer]::Ordinal)
$pattern = '(?ms)^```csharp[ \t]+file=(?<path>[^\r\n]+)\r?\n(?<code>.*?)^```[ \t]*\r?$'
$utf8 = [Text.UTF8Encoding]::new($false)
foreach ($chapter in $chapters) {
    $source = Join-Path $tutorialDir $chapter
    if (-not (Test-Path -LiteralPath $source)) { throw "找不到章节：$source" }
    $text = [IO.File]::ReadAllText($source, $utf8)
    $blocks = [regex]::Matches($text, $pattern)
    if ($blocks.Count -eq 0) { throw "章节没有完整 csharp file= 代码块：$chapter" }
    foreach ($block in $blocks) {
        $relative = $block.Groups['path'].Value.Trim()
        if ($relative -cnotin $expected) { throw "代码块路径不在测试清单中：$relative" }
        if (-not $seen.Add($relative)) { throw "重复代码块：$relative" }
        $destination = Join-Path $testDir $relative
        New-Item -ItemType Directory -Path (Split-Path -Parent $destination) -Force | Out-Null
        [IO.File]::WriteAllText($destination, $block.Groups['code'].Value, $utf8)
        Write-Host "提取：$chapter -> $relative"
    }
}
foreach ($relative in $expected) {
    if (-not $seen.Contains($relative)) { throw "缺少完整源码：$relative" }
}

# build.log 和 run.log 留在本次临时目录，终端中也显示相同输出。
Push-Location -LiteralPath $testDir
try {
    & $dotnet build $project --configuration Release --nologo 2>&1 |
        Tee-Object -FilePath (Join-Path $testDir 'build.log')
    if ($LASTEXITCODE -ne 0) { throw "核心编译失败，查看 $testDir/build.log" }
    & $dotnet run --project $project --configuration Release --no-build 2>&1 |
        Tee-Object -FilePath (Join-Path $testDir 'run.log')
    if ($LASTEXITCODE -ne 0) { throw "核心测试失败，查看 $testDir/run.log" }
} finally {
    Pop-Location
}
Write-Host "核心验证通过。源码、工程与日志目录：$testDir"
```

命令中的路径清单只接受四个核心文件和一个测试文件，重复或缺失会立即停止。每次执行打印独立目录路径，该目录中的 `Core/`、`Tests/`、`.csproj`、`build.log` 和 `run.log` 就是本次验证的材料。

目标框架由实际安装的 SDK 和控制台模板决定，工程的 `LangVersion` 设置为 `9.0`。目标框架提供运行库，语言版本限制编译语法。`ImplicitUsings` 与 `Nullable` 均关闭，核心源码与下面的测试程序使用自己声明的 `using` 和普通引用类型。

### 怎样判读输出

编译成功后，测试依次输出以下内容：

```text
协议测量: 80 对象 / <包数> 包 / <字节数> 字节
模拟网络: 20% 丢包与 20% 重复 / 收到 <包数> 包 / 恢复通过
PASS: <断言次数> 次断言
```

最后的 PASS 表示四组测试全部运行到结尾。断言次数包含每种截断长度的检查，因此用实际输出记录次数。协议字节来自 `Wire.Motion` 产生的业务载荷；模拟网络的百分比是固定随机种子下每包丢弃与复制的概率。

| 失败表现 | 先检查 | 对应文件与定位动作 |
| --- | --- | --- |
| 提示终端版本或 SDK 错误 | PowerShell 7、dotnet 的完整路径、`--list-sdks` 输出 | 在终端检查安装；运行时列表与 SDK 列表分别确认 |
| 找不到章节、代码块重复或缺失 | `$tutorialDir`、文件名、代码围栏与 `file=` 标记 | 查看报错章节，检查是否贴入了完整文件 |
| 编译器提示顶级语句或 global using 语法错误 | `build.log` 中第一条 CS 错误 | 打开临时 `.csproj`，确认 C# 9 与两个 disable 值；确认模板 `Program.cs` 已移除 |
| 编译器提示找不到 `Mvp` 或类型重复 | 提取的五个文件及对应路径 | 按命令打印的映射回到对应章节核对代码 |
| 异常提示“局部结果等于完整遍历对应区域” | `GraphTests` 调用栈 | 第 02 章 `Structure.Cut` 的旧分量取值与断边顺序 |
| 异常提示输入拒绝、速率额度 | `InputTests` 调用栈 | 第 01 章 `InputGate.Accept` 的序号、窗口与操作位 |
| 异常提示量化误差、基线、截断 | `WireTests` 调用栈 | 第 03 章编码与解码的字段顺序、长度检查 |
| 异常提示恢复、回合、插值或缓冲 | `ReplicaTests` 调用栈 | 第 04 章基线、姿态缓冲与时间线 |

优先处理终端显示的第一条异常和它的调用栈。比如“截断基线拒绝”表示某个不完整字节数组被接受；“错误基线拒绝”表示解码器接受了与包头身份不匹配的基线。它们直接指向被检查的规则。

## 2. 完整测试入口与注释

下面的 `Tests/Program.cs` 是 PowerShell 块 1 提取的第五个文件。阅读顺序是辅助函数、四组测试、`Main`。

| 测试组 | 构造方式 | 断言的目的 |
| --- | --- | --- |
| `GraphTests` | 同一随机断边序列分别运行局部更新与完整遍历 | 用独立对照检查连续分裂、重复断边与全图连通关系 |
| `InputTests` | 构造重复输入、旧回合、NaN、非法位和满速率窗口 | 验证输入入口先拒绝异常，再接收下一窗口 |
| `WireTests` | 80 对象分包、远坐标、逐字节截断和随机姿态往返 | 检查包预算、精度、回退编码与损坏数据拒绝 |
| `ReplicaTests` | 先运动后基线、重复、跨回合、重用身份和模拟网络队列 | 检查恢复、插值、队列上限与播放时钟 |

```csharp file=Tests/Program.cs
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Numerics;
using Mvp;

static class Program
{
    // 每次规则检查都累加，Main 的 PASS 汇总实际走到的断言数量。
    static int checks;
    static void Assert(bool ok, string message)
    {
        ++checks;
        if (!ok) throw new Exception(message);
    }
    static void Reject(Action action, string message)
    {
        // 损坏协议应以数据或 I/O 异常被拒绝；其他异常保留调用栈用于定位程序错误。
        try { action(); }
        catch (Exception e) when (e is IOException || e is InvalidDataException) { ++checks; return; }
        throw new Exception(message);
    }
    // 对分量内节点及分量集合排序，把遍历顺序差异消除后再比较连通关系。
    static string Groups(IEnumerable<int[]> groups) =>
        string.Join("|", groups.Select(g => string.Join(",", g.OrderBy(n => n))).OrderBy(s => s));
    static BodyState Body(uint id, float x = 0, ushort gen = 1) => new BodyState {
        Id = id, Generation = gen, Kind = BodyKind.Player, Position = new Vector3(x, 3, 0),
        Rotation = Quaternion.Identity, Velocity = new Vector3(1, 0, 0), Health = 100 };
    static WorldState World(uint round = 1, uint tick = 10, uint version = 1, uint baseline = 1,
                            int count = 1)
    {
        // 使用真实 Structure 的节点坐标与边数量，构造符合协议约束的完整世界。
        var g = new Structure();
        return new WorldState { Round = round, Tick = tick, Version = version, Baseline = baseline,
            Bodies = Enumerable.Range(1, count).Select(n => Body((uint)n)).ToArray(),
            Blocks = Enumerable.Range(0, 24).Select(n => new BlockState {
                Node = n, Parent = 0, Local = g.Rest[n] }).ToArray(),
            Broken = new bool[g.Edges.Count] };
    }
    static WorldState Copy(WorldState basis, uint tick, float x)
    {
        // 保留回合、版本、基线与身份代次，仅推进时间并改变位置。
        var w = World(basis.Round, tick, basis.Version, basis.Baseline, basis.Bodies.Length);
        for (int i = 0; i < w.Bodies.Length; ++i) w.Bodies[i] = Body((uint)(i + 1), x, basis.Bodies[i].Generation);
        return w;
    }

    static void GraphTests()
    {
        var all = new Structure();
        Assert(all.Components().Count == 1, "初始图连通");
        all.Cut(Enumerable.Range(0, all.Edges.Count), true);
        Assert(all.Components().Count == 24, "全部断开");
        // 固定种子使每次验证的断边序列一致，便于在相同步骤复现失败。
        var rng = new Random(3419);
        for (int run = 0; run < 120; ++run)
        {
            var local = new Structure(); var full = new Structure();
            for (int step = 0; step < 40; ++step)
            {
                int[] cuts = Enumerable.Range(0, rng.Next(1, 5)).Select(_ => rng.Next(local.Edges.Count)).ToArray();
                // 先找到此次新断边涉及的旧分量，再与完整遍历的相应区域比较。
                int[] fresh = cuts.Distinct().Where(e => !local.Broken[e]).ToArray();
                var ends = fresh.SelectMany(e => new[] { local.Edges[e].A, local.Edges[e].B }).ToHashSet();
                var affected = local.Components().Where(g => g.Any(ends.Contains)).SelectMany(g => g).ToHashSet();
                var a = local.Cut(cuts, true); full.Cut(cuts, false);
                var expected = full.Components().Where(g => g.Any(affected.Contains));
                Assert(Groups(a) == Groups(expected), "局部结果等于完整遍历对应区域");
                Assert(local.Broken.SequenceEqual(full.Broken), "断边状态一致");
                Assert(Groups(local.Components()) == Groups(full.Components()), "全图连通关系一致");
            }
        }
    }

    static void InputTests()
    {
        // 只有第一条有效输入推进序号；重复、旧回合和非法数据保持拒绝。
        var gate = new InputGate();
        Assert(gate.Accept(1, 1, 1, 1, 0, 1, 0), "输入通过");
        Assert(!gate.Accept(1, 1, 1, 0, 0, 0, 0), "重复拒绝");
        Assert(!gate.Accept(0, 1, 2, 0, 0, 0, 0), "旧回合拒绝");
        Assert(!gate.Accept(1, 1, 2, float.NaN, 0, 0, 0), "NaN 拒绝");
        Assert(!gate.Accept(1, 1, 2, 0, 0, 4, 0), "非法操作拒绝");
        // 第一个窗口总共接受 60 条；服务器到第 30 Tick 后开始新窗口。
        for (uint i = 2; i <= 60; ++i) Assert(gate.Accept(1, 1, i, 0, 0, 0, 0), "速率额度");
        Assert(!gate.Accept(1, 1, 61, 0, 0, 0, 0), "速率上限");
        Assert(gate.Accept(1, 1, 61, 0, 0, 0, 30), "新窗口恢复");
    }

    static void WireTests()
    {
        // 80 个对象超过单包 12 个对象的预算，迫使运动编码走完整分包路径。
        var basis = World(count: 80);
        byte[] baseline = Wire.Baseline(basis);
        var decoded = Wire.ReadBaseline(baseline);
        Assert(decoded.Bodies.Length == 80 && decoded.Blocks.Length == 24, "完整恢复");
        var current = Copy(basis, 12, 1.23456f);
        byte[][] packets = Wire.Motion(current, decoded).ToArray();
        var states = packets.SelectMany(p => Wire.ReadMotion(p, decoded).Bodies).ToArray();
        Assert(states.Length == 80 && states.Select(s => s.Id).Distinct().Count() == 80, "分包覆盖");
        Assert(packets.All(p => p.Length <= Rules.MaxPacket), "分包预算");
        Assert(states.All(s => Math.Abs(s.Position.X - 1.23456f) < .001f), "量化误差");
        // 100 米差值超出毫米短整数范围，应回退为完整整数坐标。
        var far = Copy(basis, 14, 100);
        var farState = Wire.ReadMotion(Wire.Motion(far, basis).First(), basis).Bodies[0];
        Assert(Math.Abs(farState.Position.X - 100) < .001f, "完整位置回退");
        // 从零字节直到少最后一个字节，逐种截断长度检查读取器的拒绝行为。
        for (int n = 0; n < baseline.Length; ++n)
        {
            byte[] truncated = baseline.Take(n).ToArray();
            Reject(() => Wire.ReadBaseline(truncated), "截断基线拒绝");
        }
        byte[] packet = packets[0];
        for (int n = 0; n < packet.Length; ++n)
        {
            byte[] truncated = packet.Take(n).ToArray();
            Reject(() => Wire.ReadMotion(truncated, basis), "截断运动拒绝");
        }
        // 长度合法的运动包仍须匹配基线编号；完整基线的块节点也必须唯一。
        Reject(() => Wire.ReadMotion(packet, World(baseline: 2)), "错误基线拒绝");
        var bad = World();
        bad.Blocks[1] = bad.Blocks[0];
        Reject(() => Wire.Baseline(bad), "重复块拒绝");
        // 随机位置覆盖差量与完整坐标，四元数点积取绝对值以接受等价的 q 和 -q。
        var rng = new Random(818);
        for (int i = 0; i < 1000; ++i)
        {
            var w = Copy(World(), 12, (float)(rng.NextDouble() * 100 - 50));
            var s = w.Bodies[0];
            s.Rotation = Quaternion.CreateFromYawPitchRoll((float)rng.NextDouble() * 6, .8f, .4f);
            w.Bodies[0] = s;
            var result = Wire.ReadMotion(Wire.Motion(w, World()).Single(), World()).Bodies[0];
            Assert(Vector3.Distance(s.Position, result.Position) < .001f, "随机位置误差");
            Assert(Math.Abs(Quaternion.Dot(s.Rotation, result.Rotation)) > .99999f, "随机旋转误差");
        }
        Console.WriteLine($"协议测量: 80 对象 / {packets.Length} 包 / {packets.Sum(p => p.Length)} 字节");
    }

    static void ReplicaTests()
    {
        var basis = World();
        var later = Copy(basis, 20, 10);
        byte[] motion = Wire.Motion(later, basis).Single();
        var replica = new Replica();
        // 运动先到时缺少解码基线，接收器先缓存；基线到达后重放缓存。
        replica.ReceiveMotion(motion);
        Assert(replica.NeedsBaseline && replica.PendingCount == 1, "先到运动进入恢复队列");
        replica.ReceiveBaseline(Wire.Baseline(basis));
        Assert(replica.PendingCount == 0 && !replica.NeedsBaseline, "恢复完成");
        Assert(Math.Abs(replica.Render(15).Bodies[0].Position.X - 5) < .001, "中间插值");
        replica.ReceiveMotion(motion);
        Assert(Math.Abs(replica.Render(20).Bodies[0].Position.X - 10) < .001, "重复幂等");
        // 推进回合后旧运动包保持隔离；同编号的另一代对象从新基线开始。
        replica.ReceiveBaseline(Wire.Baseline(World(round: 2, tick: 0, baseline: 2)));
        replica.ReceiveMotion(motion);
        Assert(replica.Round == 2 && replica.Render(0).Bodies[0].Position.X == 0, "回合隔离");
        var reused = World(round: 2, tick: 10, version: 2, baseline: 3);
        reused.Bodies[0] = Body(1, 30, 2);
        replica.ReceiveBaseline(Wire.Baseline(reused));
        Assert(replica.Render(10).Bodies[0].Generation == 2, "身份代次隔离");
        // 连续送入缺少基线的未来回合运动包，检查恢复队列遵守 MaxPending 上限。
        for (int i = 0; i < 180; ++i) replica.ReceiveMotion(Wire.Motion(Copy(World(round: 3, baseline: 50), 20, 1),
                                                                 World(round: 3, baseline: 50)).Single());
        Assert(replica.PendingCount <= Rules.MaxPending, "恢复队列有界");
        // 位置可以插值，生命是离散状态，应在对应 Tick 到达后切换。
        var buffer = new PoseBuffer();
        var oldHealth = Body(1); var newHealth = Body(1); newHealth.Health = 35;
        buffer.Push(10, oldHealth); buffer.Push(12, newHealth);
        Assert(buffer.Sample(11).Health == 100 && buffer.Sample(12).Health == 35,
               "离散状态在对应 Tick 生效");
        buffer = new PoseBuffer();
        for (uint i = 100; i > 0; --i) buffer.Push(i, Body(1, i));
        Assert(buffer.Count == 32 && buffer.Sample(100).Position.X == 100, "乱序缓冲有界");

        // 模拟延迟队列中的乱序、重复和丢包，最终完整基线提供一致恢复点。
        var rng = new Random(937);
        var sim = new Replica(); sim.ReceiveBaseline(Wire.Baseline(basis));
        var queue = new List<(int Delivery, byte[] Bytes)>();
        for (uint tick = 12; tick <= 120; tick += 2)
        {
            var p = Wire.Motion(Copy(basis, tick, tick / 10f), basis).Single();
            if (rng.NextDouble() < .2) continue;
            queue.Add(((int)tick + rng.Next(0, 15), p));
            if (rng.NextDouble() < .2) queue.Add(((int)tick + rng.Next(0, 15), p));
        }
        foreach (var p in queue.OrderBy(p => p.Delivery)) sim.ReceiveMotion(p.Bytes);
        var final = Copy(basis, 120, 12); final.Baseline = 2;
        sim.ReceiveBaseline(Wire.Baseline(final));
        Assert(Math.Abs(sim.Render(120).Bodies[0].Position.X - 12) < .001, "弱网最终恢复");

        // 持续推进客户端时间并间歇接收新服务器 Tick，播放时间应保持单调。
        var clock = new PlaybackClock(); clock.Observe(1, 10, 0);
        double previous = clock.Tick;
        for (int i = 1; i < 1000; ++i)
        {
            if (i % 10 == 0) clock.Observe(1, (uint)(10 + i / 2), i / 60.0);
            double value = clock.Advance(i / 60.0, 1 / 60.0);
            Assert(value >= previous, "播放时间单调"); previous = value;
        }
        Console.WriteLine($"模拟网络: 20% 丢包与 20% 重复 / 收到 {queue.Count} 包 / 恢复通过");
    }

        GraphTests(); InputTests(); WireTests(); ReplicaTests();
        Console.WriteLine($"PASS: {checks} 次断言");
```

## 3. Unity 完整代码的编译与 Weaver 检查

准备条件是 01 至 09 章的所有 `Core/`、`Unity/` 文件都在第 10 章指定的目录中。`MvpWorld` 的三个 partial 文件同时存在，测试入口保留在独立临时目录。

2. 在 Project 中选中 `Assets/MvpTutorial`，右键选择 `Reimport`，等待导入和脚本编译结束。
3. 从 Console 的第一条 C# 错误开始处理。`MvpWorld` 中找不到 `MovePlayer`、`ThrowBomb` 或 `FinishTick` 时，核对三个 partial 文件是否齐全；找不到 `Keyboard` 时，核对 Input System 包和命名空间；找不到 Mirror 类型时，核对插件和程序集引用。

6. 打开 Console 菜单的 `Open Editor Log` 查看完整编译上下文，定位 `Weaver`、`error` 和具体类型名。Console 不一定逐条显示成功的生成过程，以编译结束、错误检查和运行结果共同确认链路。
