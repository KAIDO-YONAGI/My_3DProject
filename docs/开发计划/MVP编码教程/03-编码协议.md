# 03 编码协议

## 本章要解决的问题

第 01 章的 `WorldState` 能表达状态，第 02 章能表达断边结果。本章把这些字段按确定顺序写成字节，让另一端读回相同的对象身份、块归属和运动状态。创建 `Core/Wire.cs`，完整代码位于本章后半部分。

沿用玩家 `Id=5`、`Generation=1` 的例子。完整基线为 `Round=2`、`Tick=120`、`Version=4`、`Baseline=7`，位置为 `(1,3,0)`，生命为 `100`。到 `Tick=122`，位置变为 `(1.23456,3,0)`，生命变为 `35`。我们希望接收端拿着基线 7，把运动包中的 X 差量 `235` 毫米还原成 `1.235` 米，并把生命 `35` 放入 Tick 122 的快照。

完整基线还携带 24 个块与 37 个断边标记，通过可靠通道发送。运动包携带至多 12 个对象，编码结果受 `Rules.MaxPacket=900` 字节约束，通过可丢弃通道发送。通道选择由第 05 章的 Mirror 接入负责；`Wire` 负责字节布局和解码。

## 接上当前项目：Mirror 送消息，Wire 定义消息里面的字节

现有 [CharacterIdSync.cs](../../../Assets/Core/Scripts/Networking/Sync/CharacterIdSync.cs) 通过 `CommandSetCharacter` 上报角色选择，再用 `SyncVar` 下发确认值。Mirror 为这些字段生成网络读写代码。现有位置同步则交给玩家根上的 `NetworkTransformReliable`。

本教程要一起传对象姿态、块归属和断边，所以 `Wire` 自己规定内部格式，再由第 05 章的 Mirror 消息携带这个 `byte[]`。可以把它理解为：`Wire` 写好包裹中的清单，Mirror 和 KCP 负责外层传送。

先这样读：

1. 从 `Baseline` 与 `ReadBaseline` 读一遍“完整状态写出、按相同顺序读回”。
2. 沿下面的玩家 X 坐标例子追 `Motion` 与 `ReadMotion`，理解差量参考的是指定基线。
3. 能解释 `1.23456` 为什么还原成 `1.235` 后，再核对每个字段占几字节以及异常检查。

**本章只把数据与字节互相转换。** 角色选择、网络连接、生成物体和播放画面分别由它们的调用方处理。现有类与教程类的职责对照见 [00 导读](00-从当前项目开始.md#4-现有角色相关类怎样对应教程)。

## 字段、输入与输出

| 术语或方法 | 对应字段与输入 | 输出及用途 |
| --- | --- | --- |
| 回合、拓扑、基线身份 | `Round`、`Version`、`Baseline` | 回合隔离世界，版本隔离结构，基线编号定位差量原点 |
| 状态时刻 | `Tick` | 指明整条基线或本个运动包的采样时刻 |
| 完整基线 | `Baseline(WorldState)` | 一个 `byte[]`，包括 Bodies、Blocks、Broken |
| 基线解码 | `ReadBaseline(byte[])` | 一个经过结构检查的 `WorldState` |
| 运动编码 | `Motion(current, basis)` | `IEnumerable<byte[]>`，按当前数组顺序每 12 个对象分包 |
| 头部探测 | `Header(byte[])` | 四个编号，供第 04 章先找到所需基线 |
| 运动解码 | `ReadMotion(bytes, basis)` | `MotionPacket`，只含本包对象的状态 |
| 对象元数据 | `Id`、`Generation`、`Kind`、`Sleeping`、`Health`、`Score` | 身份和离散状态随每个运动包一起发送 |

`Motion` 是迭代器，调用后需要 `foreach` 枚举才实际编码并执行检查。每个运动包都引用 `basis.Baseline`，解码依赖指定完整基线。当前包与上一个运动包之间没有差量链。

## 先在纸上画出字节布局

这里计算的是 `Wire` 返回的原始字节数组长度。Mirror 消息封装、数组长度前缀和 KCP、UDP 开销由各自传输层加入。

`BinaryWriter` 按字段调用顺序写入，小端字节序。`uint` 和 `int` 各占 4 字节，`ushort` 和 `short` 各占 2 字节，`float` 占 4 字节，`byte` 和这里的 `bool` 各占 1 字节。

运动包的公共头如下，偏移从 0 开始：

| 起始偏移 | 字段 | 类型 | 字节数 |
| --- | --- | --- | --- |
| 0 | Round | uint | 4 |
| 4 | Tick | uint | 4 |
| 8 | Version | uint | 4 |
| 12 | Baseline | uint | 4 |
| 16 | 本包对象数 | ushort | 2 |

因此头部共 18 字节。`Header` 只读前 16 字节的四个编号；`ReadMotion` 从偏移 16 开始读取对象数，随后从偏移 18 开始读对象。

每个对象先写 `Meta`。对象内偏移为：`Id` 在 0 占 4 字节，`Generation` 在 4 占 2 字节，`Kind` 在 6 占 1 字节，`Sleeping` 在 7 占 1 字节，`Health` 在 8 占 2 字节，`Score` 在 10 占 2 字节。合计 `4+2+1+1+2+2=12` 字节。

| 对象内起始偏移 | 短差量分支 | 字节数 | 绝对位置分支 | 字节数 |
| --- | --- | --- | --- | --- |
| 0 | Meta | 12 | Meta | 12 |
| 12 | `delta=true` 标记 | 1 | `delta=false` 标记 | 1 |
| 13 | 三个 short 毫米差量 | 6 | 三个 int 毫米绝对坐标 | 12 |
| 19 或 25 | 四个 short 旋转分量 | 8 | 四个 short 旋转分量 | 8 |
| 27 或 33 | 三个 short 速度分量 | 6 | 三个 short 速度分量 | 6 |

单对象分别为 `33` 或 `39` 字节。若一包含 D 个短差量对象、A 个绝对位置对象，长度为 `18+33D+39A`，其中 `D+A<=12`。12 个对象全走短差量为 **414Bytes**，全走绝对位置为 **486Bytes**；一个对象分别为 51 或 57 字节。两种满包长度都在 900 字节预算内。

完整基线使用另一种布局：四个 uint 头字段共 16 字节，然后依次写对象数和对象、块数和块、断边数和断边标记。它的对象位置通过 `V` 写三个 float，保留浮点位置；一个对象为 `12+12+8+6=38` 字节。每块为 `Node` 4 字节、`Parent` 4 字节、`Local` 三个 float 12 字节，合计 20 字节。合法基线总长度为：

```text
16 + 2 + 38×对象数 + 2 + 20×24 + 2 + 37
= 539 + 38×对象数
12 个对象：995Bytes
96 个对象：4187Bytes
```

900 字节检查应用于运动包。`ReadBaseline` 接受长度至多 32768 字节的基线，并结合对象数、块数和边数检查结构。

## 按顺序编写方法

1. 先写 `Q` 和 `S`，把浮点数转换规则固定下来。`Q` 检查有限数和绝对值不超过 100000 米，乘 1000 后用 `AwayFromZero` 舍入成毫米整数。`S` 检查有限数，按给定比例舍入并夹到 short 范围；速度超过可表达范围时发生饱和。
2. 写 `V`、`Rotation`、`Velocity` 的写入和读取配对。`V` 写原始 float；读取后调用 `Q` 检查位置范围，但保留读出的 float。旋转归一化后写四个 short，读取后再次归一化。速度以每秒厘米编码，读取时除以 100。
3. 写 `Meta`。读写字段顺序必须逐项对应；读取时检查 Id、Generation 和 Kind。运动包也携带生命、分数和休眠状态，使它们属于该包的 Tick。
4. 写 `Count` 和 `End`。先检查计数再分配数组，避免按包内任意数量分配；读完后要求流位置恰好等于长度，使尾随字节被拒绝。
5. 写 `Validate`，再写 `Baseline` 和 `ReadBaseline`。编码前检查世界结构，解码时先逐字段读，再检查完整结构。节点必须覆盖 0 至 23 且唯一；非零 Parent 必须指向基线中 Kind 为 Fragment 的对象。
6. 写 `Motion`。先检查回合和版本，建立基线 Id 索引；按 12 个对象分包。逐对象核对 Generation 和 Kind，然后分别量化当前坐标和基线坐标，再判断三轴差值是否都装得进 short。
7. 写 `Header` 和 `ReadMotion`。先探测头并核对基线身份，再读对象数和对象；差量加回量化后的基线坐标，绝对位置直接读取 int，最后除以 1000 还原米。

短差量每轴范围是 `[-32768,32767]` 毫米，即 `[-32.768,32.767]` 米。判断使用的是两个位置分别量化后的整数之差。任一轴超出范围，整个位置改用三个绝对 int 坐标，三个轴共用一个标记。

速度的表达步长为 `0.01` 米每秒，范围为 `[-327.68,327.67]` 米每秒。`S` 的 `Math.Round` 使用默认中点舍入规则，`Q` 明确使用 `AwayFromZero`。旋转占四个 short 共 8 字节，编码前要求四分量有限且长度平方至少为 `0.1`。

## 完整代码

```csharp file=Core/Wire.cs
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Numerics;

namespace Mvp
{
    public sealed class MotionPacket
    {
        // 四个字段说明本包属于哪个回合、Tick、结构版本和解码基线。
        public uint Round, Tick, Version, Baseline;
        // 只包含本包分到的对象，最多 Rules.PacketBodies 个。
        public BodyState[] Bodies;
    }

    public static class Wire
    {
        // 运动位置转为毫米整数；基线位置读取也用它检查合法范围。
        static int Q(float v)
        {
            if (!Rules.Finite(v) || Math.Abs(v) > 100000)
                throw new InvalidDataException("坐标越界");
            // 当前与基线各自调用 Q，然后才相减。
            return (int)Math.Round(v * 1000.0, MidpointRounding.AwayFromZero);
        }
        // 通用短整数编码：速度用 100，旋转用 32767；越界值夹到 short 范围。
        static short S(float v, float scale)
        {
            if (!Rules.Finite(v)) throw new InvalidDataException("数值无效");
            return (short)Math.Max(short.MinValue, Math.Min(short.MaxValue, Math.Round(v * scale)));
        }
        // 基线位置和块局部坐标写三个原始 float，共 12 字节。
        static void V(BinaryWriter w, Vector3 p) { w.Write(p.X); w.Write(p.Y); w.Write(p.Z); }
        static Vector3 V(BinaryReader r)
        {
            var p = new Vector3(r.ReadSingle(), r.ReadSingle(), r.ReadSingle());
            // 只做范围检查；Q 的返回值未赋回 p，因此这里保留原浮点精度。
            Q(p.X); Q(p.Y); Q(p.Z);
            return p;
        }
        // 先排除无效旋转，再归一化并按 X、Y、Z、W 写四个 short。
        static void Rotation(BinaryWriter w, Quaternion q)
        {
            if (!Rules.Finite(q.X) || !Rules.Finite(q.Y) || !Rules.Finite(q.Z) ||
                !Rules.Finite(q.W) || q.LengthSquared() < 0.1f)
                throw new InvalidDataException("旋转无效");
            q = Quaternion.Normalize(q);
            w.Write(S(q.X, 32767)); w.Write(S(q.Y, 32767));
            w.Write(S(q.Z, 32767)); w.Write(S(q.W, 32767));
        }
        // 短整数还原会有舍入误差，再次归一化得到用于显示的旋转。
        static Quaternion Rotation(BinaryReader r)
        {
            var q = new Quaternion(r.ReadInt16() / 32767f, r.ReadInt16() / 32767f,
                                   r.ReadInt16() / 32767f, r.ReadInt16() / 32767f);
            if (q.LengthSquared() < 0.1f) throw new InvalidDataException("旋转无效");
            return Quaternion.Normalize(q);
        }
        // 身份 7 字节、休眠 1 字节、生命和分数各 2 字节，总计 12 字节。
        static void Meta(BinaryWriter w, BodyState s)
        {
            w.Write(s.Id); w.Write(s.Generation); w.Write((byte)s.Kind);
            w.Write(s.Sleeping); w.Write(s.Health); w.Write(s.Score);
        }
        // 读写顺序一致，读取时检查非零身份和已定义的对象种类。
        static BodyState Meta(BinaryReader r)
        {
            var s = new BodyState { Id = r.ReadUInt32(), Generation = r.ReadUInt16(),
                Kind = (BodyKind)r.ReadByte(), Sleeping = r.ReadBoolean(),
                Health = r.ReadInt16(), Score = r.ReadInt16() };
            if (s.Id == 0 || s.Generation == 0 || s.Kind < BodyKind.Player || s.Kind > BodyKind.Fragment)
                throw new InvalidDataException("对象身份无效");
            return s;
        }
        // 米每秒乘 100 编为厘米每秒，三个 short 共 6 字节。
        static void Velocity(BinaryWriter w, Vector3 v)
        {
            w.Write(S(v.X, 100)); w.Write(S(v.Y, 100)); w.Write(S(v.Z, 100));
        }
        // 还原速度单位为米每秒。
        static Vector3 Velocity(BinaryReader r) =>
            new Vector3(r.ReadInt16() / 100f, r.ReadInt16() / 100f, r.ReadInt16() / 100f);
        // 计数占 2 字节；先检查上限，再由调用方分配数组。
        static int Count(BinaryReader r, int max)
        {
            int n = r.ReadUInt16();
            if (n > max) throw new InvalidDataException("集合超出预算");
            return n;
        }
        // 完整消费消息，拒绝合法字段后面附带的额外字节。
        static void End(BinaryReader r)
        {
            if (r.BaseStream.Position != r.BaseStream.Length) throw new InvalidDataException("尾部数据无效");
        }

        // 完整基线输出：头、对象集合、块集合、断边集合，按此顺序写入。
        public static byte[] Baseline(WorldState world)
        {
            Validate(world);
            using var stream = new MemoryStream();
            using var w = new BinaryWriter(stream);
            w.Write(world.Round); w.Write(world.Tick); w.Write(world.Version); w.Write(world.Baseline);
            // 基线对象的位置走 V 的 float 分支，旋转和速度使用短整数。
            w.Write((ushort)world.Bodies.Length);
            foreach (var s in world.Bodies)
            {
                Meta(w, s); V(w, s.Position); Rotation(w, s.Rotation); Velocity(w, s.Velocity);
            }
            // 每个块写节点编号、所属碎片编号和局部坐标。
            w.Write((ushort)world.Blocks.Length);
            foreach (var b in world.Blocks) { w.Write(b.Node); w.Write(b.Parent); V(w, b.Local); }
            // 顺序与 Structure.Edges 的编号对应，每条边一个 bool。
            w.Write((ushort)world.Broken.Length);
            foreach (bool b in world.Broken) w.Write(b);
            return stream.ToArray();
        }

        // 逐项按写入布局还原，读取结束再检查跨对象的归属关系。
        public static WorldState ReadBaseline(byte[] bytes)
        {
            if (bytes == null || bytes.Length > 32768) throw new InvalidDataException("基线长度无效");
            using var r = new BinaryReader(new MemoryStream(bytes, false));
            var world = new WorldState { Round = r.ReadUInt32(), Tick = r.ReadUInt32(),
                Version = r.ReadUInt32(), Baseline = r.ReadUInt32() };
            // 对象上限 96；每个对象先身份、再位置、旋转和速度。
            world.Bodies = new BodyState[Count(r, Rules.MaxBodies)];
            for (int i = 0; i < world.Bodies.Length; ++i)
            {
                var s = Meta(r); s.Position = V(r); s.Rotation = Rotation(r);
                s.Velocity = Velocity(r); world.Bodies[i] = s;
            }
            // Count 限制最大值，Validate 进一步要求块数恰好为 24。
            world.Blocks = new BlockState[Count(r, 24)];
            for (int i = 0; i < world.Blocks.Length; ++i)
                world.Blocks[i] = new BlockState { Node = r.ReadInt32(), Parent = r.ReadUInt32(), Local = V(r) };
            // 同样由 Validate 要求恰好有 37 条断边标记。
            world.Broken = new bool[Count(r, 37)];
            for (int i = 0; i < world.Broken.Length; ++i) world.Broken[i] = r.ReadBoolean();
            End(r); Validate(world); return world;
        }

        // 检查固定结构、对象 Id 唯一性，以及节点和碎片归属。
        static void Validate(WorldState w)
        {
            if (w.Round == 0 || w.Baseline == 0 || w.Bodies.Length > Rules.MaxBodies ||
                w.Blocks.Length != 24 || w.Broken.Length != 37)
                throw new InvalidDataException("基线结构无效");
            // 对象编号在这条基线内必须非零且唯一。
            var ids = new HashSet<uint>();
            foreach (var s in w.Bodies)
                if (s.Id == 0 || !ids.Add(s.Id)) throw new InvalidDataException("对象编号重复");
            // 24 个唯一且处于 0..23 的节点恰好覆盖全部块。
            // Parent 为零表示固定世界；非零必须能找到对应碎片对象。
            var nodes = new HashSet<int>();
            foreach (var b in w.Blocks)
                if (b.Node < 0 || b.Node >= 24 || !nodes.Add(b.Node) ||
                    (b.Parent != 0 && !w.Bodies.Any(s => s.Id == b.Parent && s.Kind == BodyKind.Fragment)))
                    throw new InvalidDataException("块归属无效");
        }

        // 枚举时逐包编码；所有包独立引用传入 basis 的基线编号。
        public static IEnumerable<byte[]> Motion(WorldState current, WorldState basis)
        {
            if (current.Round != basis.Round || current.Version != basis.Version)
                throw new InvalidDataException("基线身份不匹配");
            // 通过 Id 找原点，再用 Generation 和 Kind 确认是同一个对象。
            var byId = basis.Bodies.ToDictionary(s => s.Id);
            for (int start = 0; start < current.Bodies.Length; start += Rules.PacketBodies)
            {
                using var stream = new MemoryStream();
                using var w = new BinaryWriter(stream);
                // 这里写 basis.Baseline；current.Baseline 不决定解码原点。
                w.Write(current.Round); w.Write(current.Tick); w.Write(current.Version); w.Write(basis.Baseline);
                int count = Math.Min(Rules.PacketBodies, current.Bodies.Length - start);
                w.Write((ushort)count);
                for (int i = start; i < start + count; ++i)
                {
                    var s = current.Bodies[i];
                    if (!byId.TryGetValue(s.Id, out var b) || b.Generation != s.Generation || b.Kind != s.Kind)
                        throw new InvalidDataException("对象需要新基线");
                    // 离散状态每次完整写入，随后才编码位置差量。
                    Meta(w, s);
                    int[] p = { Q(s.Position.X), Q(s.Position.Y), Q(s.Position.Z) };
                    int[] origin = { Q(b.Position.X), Q(b.Position.Y), Q(b.Position.Z) };
                    // 三轴都满足有符号 short 范围才使用短差量。
                    bool delta = Enumerable.Range(0, 3).All(n => p[n] - origin[n] >= short.MinValue &&
                                                               p[n] - origin[n] <= short.MaxValue);
                    // 标记占 1 字节；false 时三轴写绝对毫米整数。
                    w.Write(delta);
                    for (int n = 0; n < 3; ++n)
                        if (delta) w.Write((short)(p[n] - origin[n])); else w.Write(p[n]);
                    Rotation(w, s.Rotation); Velocity(w, s.Velocity);
                }
                // 限制实际产出的原始载荷长度，每包至多 12 个对象。
                byte[] packet = stream.ToArray();
                if (packet.Length > Rules.MaxPacket) throw new InvalidDataException("运动包超出预算");
                yield return packet;
            }
        }

        // 只读取四个头字段，让 Replica 能在完整解码前找到指定基线。
        public static (uint Round, uint Tick, uint Version, uint Baseline) Header(byte[] bytes)
        {
            if (bytes == null || bytes.Length < 18 || bytes.Length > Rules.MaxPacket)
                throw new InvalidDataException("运动包长度无效");
            using var r = new BinaryReader(new MemoryStream(bytes, false));
            return (r.ReadUInt32(), r.ReadUInt32(), r.ReadUInt32(), r.ReadUInt32());
        }

        // 解码当前一个包；需要指定的完整基线，不依赖上一条运动包。
        public static MotionPacket ReadMotion(byte[] bytes, WorldState basis)
        {
            var h = Header(bytes);
            if (h.Round != basis.Round || h.Version != basis.Version || h.Baseline != basis.Baseline)
                throw new InvalidDataException("运动包基线无效");
            using var r = new BinaryReader(new MemoryStream(bytes, false));
            // 跳过四个 uint，停在对象数之前；对象数占偏移 16、17。
            r.BaseStream.Position = 16;
            var packet = new MotionPacket { Round = h.Round, Tick = h.Tick,
                Version = h.Version, Baseline = h.Baseline, Bodies = new BodyState[Count(r, Rules.PacketBodies)] };
            var byId = basis.Bodies.ToDictionary(s => s.Id);
            // 同一包内禁止重复 Id，并逐项匹配基线里的对象身份。
            var seen = new HashSet<uint>();
            for (int i = 0; i < packet.Bodies.Length; ++i)
            {
                var s = Meta(r);
                if (!seen.Add(s.Id) || !byId.TryGetValue(s.Id, out var b) ||
                    b.Generation != s.Generation || b.Kind != s.Kind)
                    throw new InvalidDataException("运动对象无效");
                // 相同的标记控制三轴读取 short 差量或 int 绝对坐标。
                bool delta = r.ReadBoolean();
                int[] origin = { Q(b.Position.X), Q(b.Position.Y), Q(b.Position.Z) };
                int[] p = new int[3];
                for (int n = 0; n < 3; ++n)
                    p[n] = delta ? origin[n] + r.ReadInt16() : r.ReadInt32();
                // 毫米整数转回米；位置量化发生于运动包这一条路径。
                s.Position = new Vector3(p[0] / 1000f, p[1] / 1000f, p[2] / 1000f);
                s.Rotation = Rotation(r); s.Velocity = Velocity(r);
                packet.Bodies[i] = s;
            }
            End(r); return packet;
        }
    }
}
```

## 手工跟踪：235 毫米怎样变成 1.235 米

1. 让基线 7 的玩家位置为 `(1,3,0)`，当前 Tick 122 的位置为 `(1.23456,3,0)`。`Q` 分别得到原点 `[1000,3000,0]` 和当前位置 `[1235,3000,0]`。
2. 相减得到 `[235,0,0]`，三轴都落在 short 范围，写入 `delta=true`。玩家的 `Health=35`、`Score=2` 等元数据仍完整写入。
3. 只有这个玩家的运动包长度为 `18+33=51` 字节。头的 Baseline 是 7；对象 Meta 占包偏移 18 至 29，标记位在偏移 30，位置三个 short 在 31 至 36。
4. X 差量 235 的小端字节为 `EB 00`。若旋转是单位四元数，四分量为 `[0,0,0,32767]`，W 的两字节为 `FF 7F`；旋转占偏移 37 至 44。若速度为 `(1,0,0)`，X 写成 short 100，其字节为 `64 00`，速度占 45 至 50。
5. 接收端先用 `Header` 找到基线 7，再调用 `ReadMotion`。X 为 `1000+235=1235` 毫米，除以 1000 得到 `1.235` 米。与输入差 `0.00044` 米；生命 35 留在同一个 Tick 122 状态里。

把当前 X 改成 `33.767`，与原点 1 米之间的量化差为 `32767` 毫米，仍走短差量。改成 `33.768`，差为 `32768`，标记改为 false，写的是绝对 X `33768` 毫米，同时 Y、Z 也改为 int。负方向对应的边界是 X `-31.768` 和 `-31.769`。

若当前有 80 个对象，枚举 `Motion` 得到 7 包：前 6 包各 12 个对象，最后一包 8 个对象。全走短差量时，前 6 包各 414 字节，最后一包 `18+8×33=282` 字节，总载荷为 2766 字节。某一包丢失只影响其中对象的新快照，其他包依然能相对同一个完整基线独立解码。空对象数组产生零个运动包。

## 自检方法与失败检查点

按第 11 章的独立测试方式运行核心检查。也可以把下表的参数代入同一份基线与当前状态，枚举编码结果并读回字段；基线中的 24 个块、37 个标记及碎片 Parent 引用始终要合法。

| 操作 | 预期结果 | 不符合时先检查 |
| --- | --- | --- |
| 玩家 X 从 1 变到 1.23456，编码并解码运动 | X 约为 1.235，Id=5、Gen=1、Tick=122、HP=35 | Q 的单位、先分别量化再相减、解码原点是否来自基线 7 |
| 对原始 X=1.23456 做完整基线往返 | V 路径保留原 float；速度、旋转经过各自量化 | 是否把完整基线位置误改成了毫米整数 |
| X=33.767 与 X=33.768 分别编码 | 单对象包分别 51 与 57 字节 | short 的正上限为 32767，三轴共享标记 |
| 12 个对象全短差量或全绝对位置 | 包长分别 414 与 486 字节 | Meta 是否为 12 字节、头是否为 18 字节 |
| 12 对象完整基线往返 | 长度 995 字节，块数 24、边数 37 | 是否漏了三个 ushort 计数或把基线套用 900 字节限制 |
| 用错误 Round、Version 或 Baseline 的 basis 解码 | `ReadMotion` 抛出数据异常 | 是否只凭 Tick 匹配而漏核对基线身份 |
| 运动对象改为基线没有的 Id 或不同 Gen、Kind | 对象身份检查拒绝 | byId 查找和两端 Generation、Kind 比较 |
| 一个包中重复 Id；基线中重复节点或悬空 Parent | 对应对象或结构检查拒绝 | seen、nodes 集合与 Fragment 归属检查 |
| 截断包或在完整包尾部加一个字节 | 读取截断时抛异常；尾随字节由 End 拒绝 | 字段顺序、计数及是否执行到 End |
| 速度 X=400 米每秒 | 编码饱和为 327.67 米每秒 | S 的夹取行为，不能期待其抛出速度越界异常 |

检查范围要与代码对应。`Validate` 负责世界结构和归属；读 `Meta` 时检查 Generation 与 Kind；读取基线的 `V` 检查坐标。写入的 `Meta`、`V` 没有同样的逐字段检查，`ReadMotion` 还原绝对坐标后也没有再次调用 `Q`。包内字段满足这些检查时会被接受，校验能力不能表述成“任意损坏都可检测”。

截断或无效数据产生的异常由第 09 章的接收入口捕获，并触发完整状态恢复；恢复请求的速率限制由服务器入口负责。第 04 章处理的是尚未拿到所引用基线的合法运动包，将它们暂存后再解码。
