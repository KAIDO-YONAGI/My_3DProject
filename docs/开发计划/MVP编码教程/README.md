# 破坏竞技场 MVP 编码教程

按本教程完成一张可运行的双人竞技场。玩家移动、跳跃、投掷炸弹，爆炸切断平台连接，失去支撑的块组成刚体碎片，碎片撞击玩家并触发连锁爆炸。玩家在运动碎片上移动和跳离，服务器结算伤害与回合，新客户端恢复当前场景。

从 [第一章：数据与职责](01-数据与职责.md) 开始，按章创建文件。读正文理解本章目标，跟着代码编写，完成章末检查后继续。中文注释解释关键逻辑的编写理由，细节结合实际遇到的问题逐步学习。

Mirror 是 Unity 的网络框架。本教程使用它建立连接、管理网络对象身份和传递消息。结构算法、消息编码、快照缓冲、插值与恢复流程使用普通 C# 编写。服务器负责共享物理，客户端通过自写快照内核显示运动。

## MVP 规则

模拟频率为 30Hz，运动发送频率为 15Hz，客户端保留三 Tick 的播放缓冲。平台有 24 个块，两端四个块连接固定支撑。炸弹引信为 45 Tick，爆炸作用半径为 3.5 米。角色有 100 生命值，投掷冷却为 15 Tick，每局持续 900 Tick。玩家掉出场地或生命归零时被淘汰，剩余一人时结算，三秒后重开。

MVP 的角色采用服务器运动与客户端插值。后续角色预测、对应 Tick 的支撑历史重演与校正，按 [阶段八](../改造计划总览.md#阶段八-预测校正与弱网验证) 和 [专项设计](../联机系统教学/专项设计/独立快照同步内核.md) 继续实施。这里的独立场景为这些工作提供固定 Tick、服务器状态与可恢复身份。

场景中的 Mirror 网络对象包括玩家、炸弹和碎片。业务编号在回合内递增，消息携带回合和代次。完整基线保存块归属与局部坐标，运动包依赖明确的基线编号。客户端按基线恢复几何，再按快照显示运动。

## 编码与验证入口

运行 [Verify-Tutorial.ps1](Verify-Tutorial.ps1) 从章节提取源文件。它在临时目录执行核心测试，使用本工程的 Unity 与 Mirror 程序集编译适配层，再执行 Mirror Weaver 验证。Weaver 是 Mirror 的代码生成工具，负责生成网络消息读写与状态同步代码。指定 `-ExportPath` 可以把相同代码导出到你选定的学习目录。

```powershell
pwsh -File .\docs\开发计划\MVP编码教程\Verify-Tutorial.ps1
pwsh -File .\docs\开发计划\MVP编码教程\Verify-Tutorial.ps1 -ExportPath D:\Unity\MvpStudy
```

验证代码集中在第 11 章。完成场景后，按第 12 章运行两个客户端，检查玩法与状态恢复。

总体职责与技术主线见 [开发计划总览](../改造计划总览.md)。算法与协议的扩展设计见 [结构破坏与动态碎片](../联机系统教学/专项设计/结构破坏与动态碎片.md) 和 [独立快照同步内核](../联机系统教学/专项设计/独立快照同步内核.md)。
