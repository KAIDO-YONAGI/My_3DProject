# 09 显示玩家状态并观战

本章使用 `NetworkPlayer` 里的角色、相机和动画，先做隔着平台也能看见的白色名字，再做淘汰后的观战。显示代码只读取 `Alive`、`Phase` 等状态，不修改胜负规则。

## 1. 给现有 NetworkPlayer 添加显示组件

创建 `Assets/Core/Scripts/Gameplay/Mvp/ArenaPlayerPresentation.cs`。先放入下面骨架；后面的代码都加到 `ArenaPlayerPresentation` 类中、类的最后一个 `}` 前。写完并等 Unity 编译后，再把组件加到现有 `NetworkPlayer.prefab` 根节点。

```csharp file=Assets/Core/Scripts/Gameplay/Mvp/ArenaPlayerPresentation.cs
using System.Collections.Generic;
using Core.Scripts.Camera.Runtime;
using Mirror;
using UnityEngine;
using UnityEngine.InputSystem;

namespace Core.Scripts.Gameplay.Mvp
{
    public sealed class ArenaPlayerPresentation : NetworkBehaviour
    {
        private ArenaPlayerActions actions;
        private Transform spectatorTarget;
        private Transform spectatorProxy;
        private ThirdPersonCamera localCameraController;
        private GUIStyle nameStyle;
        private GUIStyle hudStyle;

        private void Awake()

            actions = GetComponent<ArenaPlayerActions>();

```

`actions` 是同一个玩家根节点上的第 05 章组件，里面保存存活状态与道具数量。`spectatorTarget` 指向要看的玩家，`spectatorProxy` 是相机真正跟随的本地空物体，两者的用途在第 4 节展开。

## 2. 每个玩家画自己的白字标签

先加入界面入口：

```csharp
        private void OnGUI()
        {
            UnityEngine.Camera viewCamera = UnityEngine.Camera.main;
            if (viewCamera == null)
                return;

            DrawPlayerName(viewCamera);
            if (isLocalPlayer)
                DrawHud();
        }
```

这里用 Unity 的即时界面 `OnGUI` 画文字，便于先验证玩法。每个网络玩家对象画一个自己的标签，只有本机玩家对象画左上角 HUD。下面加入标签方法：

```csharp
        private void DrawPlayerName(UnityEngine.Camera viewCamera)
        {
            Vector3 screen = viewCamera.WorldToScreenPoint(
                transform.position + Vector3.up * 2.2f);
            if (screen.z <= 0f)
                return;

            if (nameStyle == null)
            {
                nameStyle = new GUIStyle(GUI.skin.label)
                {
                    alignment = TextAnchor.MiddleCenter,
                    fontSize = 17,
                    normal = { textColor = Color.white }
                };
            }

            string label = $"Player{netId}  {PlayerStateLabel()}";
            // 世界坐标投到屏幕后，GUI 的 Y 轴方向与投影结果相反。
            float y = Screen.height - screen.y;
            GUI.color = Color.black;
            GUI.Label(new Rect(screen.x - 81f, y - 14f, 164f, 26f), label, nameStyle);
            GUI.color = Color.white;
            GUI.Label(new Rect(screen.x - 80f, y - 15f, 164f, 26f), label, nameStyle);
        }
```

标签画在屏幕上，不经过场景深度遮挡，所以平台挡住角色时仍能看见文字。黑字偏移一像素作为阴影，再画白字，提高亮背景上的可读性。`screen.z<=0` 表示人在镜头后面，跳过绘制。

下面加状态文字方法：

```csharp
private string PlayerStateLabel()
{
    ArenaMatch match = ArenaMatch.Instance;
    if (actions == null || !actions.Alive ||
        (match != null && actions.RoundId != match.RoundId))
        return "观战";

    if (match != null && match.CarrierNetId == netId)
        return "携带者";

    return "存活";
}
```

## 3. 本机窗口显示回合和库存

加入 `DrawHud`。读这个方法时，只需要关注每一行文字来自哪个已同步字段：

```csharp
        private void DrawHud()
        {
            if (hudStyle == null)
            {
                hudStyle = new GUIStyle(GUI.skin.label)
                {
                    fontSize = 16,
                    normal = { textColor = Color.white }
                };
            }

            ArenaMatch match = ArenaMatch.Instance;
            GUI.color = new Color(0f, 0f, 0f, 0.72f);
            GUI.Box(new Rect(12f, 12f, 270f, 140f), GUIContent.none);
            GUI.color = Color.white;
            GUILayout.BeginArea(new Rect(24f, 20f, 246f, 124f));
            GUILayout.Label($"回合：{(match != null ? match.RoundId : 0)}", hudStyle);
            GUILayout.Label($"阶段：{PhaseLabel(match != null ? match.Phase : ArenaMatchPhase.Waiting)}", hudStyle);
            GUILayout.Label($"存活：{(match != null ? match.AliveCount : 0)}    道具：{(actions != null ? actions.Charges : 0)}", hudStyle);

            if (match != null &&
                (match.Phase == ArenaMatchPhase.Countdown ||
                 match.Phase == ArenaMatchPhase.Results))
            {
                // 两端从同一个结束时间算剩余秒数，不各自启动倒计时。
                int seconds = Mathf.CeilToInt(
                    Mathf.Max(0f, (float)(match.PhaseEndsAt - NetworkTime.time)));
                GUILayout.Label($"剩余：{seconds}", hudStyle);
            }

            if (match != null && match.Phase == ArenaMatchPhase.Results)
            {
                string winner = match.WinnerNetId == 0 ? "平局" : $"胜者：Player{match.WinnerNetId}";
                GUILayout.Label(winner, hudStyle);
            }

            GUILayout.EndArea();
        }
```

再加阶段名称转换方法：

```csharp
private static string PhaseLabel(ArenaMatchPhase phase)
{
    return phase switch
    {
        ArenaMatchPhase.Waiting => "等待玩家",
        ArenaMatchPhase.Countdown => "倒计时",
        ArenaMatchPhase.Playing => "进行中",
        ArenaMatchPhase.Results => "结算",
        _ => "等待玩家"
    };
}
```

## 4. 淘汰后把相机交给本地观战目标

先加入本机控制入口。存活时恢复自己，淘汰后自动挑选存活目标，Tab 切换到下一个：

```csharp
        private void Update()
        {
            if (!isLocalPlayer || actions == null)
            {
                return;
            }

            if (actions.Alive)
            {
                RestoreLocalCamera();
                return;
            }

            bool targetUnavailable = spectatorTarget == null ||
                !spectatorTarget.GetComponent<ArenaPlayerActions>().Alive;
            if (targetUnavailable ||
                (Keyboard.current != null && Keyboard.current.tabKey.wasPressedThisFrame))
            {
                CycleSpectatorTarget();
            }
        }

        private void LateUpdate()
        {
            if (spectatorProxy != null && spectatorTarget != null)
            {
                // 只跟随位置，保留代理自己的朝向供相机旋转。
                spectatorProxy.position = spectatorTarget.position + Vector3.up * 1.2f;
            }
        }
```

接着加入目标选择方法。先从所有玩家中筛选本局存活者，再按网络编号排序，选择下一个：

```csharp
        private void CycleSpectatorTarget()
        {
            List<ArenaPlayerActions> candidates = new();
            foreach (ArenaPlayerActions player in FindObjectsOfType<ArenaPlayerActions>())
            {
                ArenaMatch match = ArenaMatch.Instance;
                if (player != null && player != actions && player.Alive &&
                    match != null && player.RoundId == match.RoundId)
                {
                    candidates.Add(player);
                }
            }

            candidates.Sort((a, b) => a.netId.CompareTo(b.netId));
            if (candidates.Count == 0)
            {
                return;
            }

            int currentIndex = candidates.FindIndex(
                player => player.transform == spectatorTarget);
            int nextIndex = (currentIndex + 1) % candidates.Count;
            spectatorTarget = candidates[nextIndex].transform;

            if (spectatorProxy == null)
            {
                // 代理只有本机创建，不添加 NetworkIdentity，也不 Spawn。
                GameObject proxyObject = new GameObject("LocalSpectatorCameraTarget");
                spectatorProxy = proxyObject.transform;
            }

            spectatorProxy.position = spectatorTarget.position + Vector3.up * 1.2f;
            GetLocalCameraController()?.SetTarget(spectatorProxy);
        }
```

当前 `ThirdPersonCamera` 会在收到移动输入时旋转目标。直接把远端玩家根物体交给它，会改动本机看到的远端角色朝向。所以相机跟随本地 `spectatorProxy`，代理只复制观战对象的位置。

最后加入恢复和清理方法：

```csharp
        private void RestoreLocalCamera()
        {
            if (!isLocalPlayer || spectatorProxy == null)
            {
                return;
            }

            GetLocalCameraController()?.SetTarget(transform);
            Destroy(spectatorProxy.gameObject);
            spectatorProxy = null;
            spectatorTarget = null;
        }

        private ThirdPersonCamera GetLocalCameraController()
        {
            if (localCameraController != null)
            {
                return localCameraController;
            }

            UnityEngine.Camera localCamera = UnityEngine.Camera.main;
            if (localCamera != null)
            {
                localCameraController = localCamera.GetComponent<ThirdPersonCamera>();
            }

            return localCameraController;
        }

        private void OnDestroy()
        {
            if (spectatorProxy != null)
            {
                Destroy(spectatorProxy.gameObject);
            }
        }
```

死亡由第 05 章的 `Alive` 钩子关闭本机运动。新回合中，`ServerReset` 调用 `ServerTeleport` 复位位置，第 07 章的 `TargetResetMotion` 清理本机旧速度；本章看到 `Alive=true` 后恢复相机。

## 5. 接入 Unity 并检查

保存完整脚本，等待 Unity 编译，把 `ArenaPlayerPresentation` 加到现有 `NetworkPlayer.prefab` 根节点并保存。运行服务器和两个客户端：先让另一人被平台挡住，检查白字仍可见；再让自己落入虚空，检查相机切到存活玩家，按 Tab 能换目标；下一局开始时，检查镜头回到自己、移动和跳跃恢复。
