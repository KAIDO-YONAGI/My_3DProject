# 10 场景与构建

使用 Unity `2022.3.62f3c1`、工程内 Mirror 与 Input System，渲染使用工程的 Universal Render Pipeline。教程代码放在 `Assets/MvpTutorial/Core` 与 `Assets/MvpTutorial/Unity`。普通 C# 核心使用 Unity 支持的 C# 9 语法。

## 创建网络 Prefab

1. 在 Hierarchy 创建空对象 `MvpBody`，Transform 位置归零，缩放为一。
2. 添加 Mirror 的 `NetworkIdentity` 和本教程的 `MvpBody`。
3. 将对象保存为 `Assets/MvpTutorial/MvpBody.prefab`，随后删除场景中的实例。

服务器通过 `NetworkServer.Spawn` 创建共享物体，通过 `NetworkServer.Destroy` 销毁。玩家创建使用 `NetworkServer.AddPlayerForConnection`，让连接获得自己的玩家身份。形状和物理组件由服务器代码生成，客户端形状由完整基线生成。

## 创建竞技场

1. 创建场景并保存为 `Assets/MvpTutorial/MvpArena.unity`。
2. 创建空对象 `MvpRoot`，添加 `MvpNetwork`、`MvpWorld`、`MvpView` 和 Mirror 的 `KcpTransport`。
3. `MvpNetwork.World` 指向本对象的 `MvpWorld`，`View` 指向本对象的 `MvpView`，`BodyPrefab` 和继承的 `Player Prefab` 都指向 `MvpBody.prefab`。
4. `MvpView.Manager` 指向 `MvpNetwork`。管理器的 `Transport` 指向 `KcpTransport`，`Network Address` 填 `localhost`。
5. `KcpTransport.Port` 填 `7777`，管理器 `Auto Create Player` 勾选。`Offline Scene` 与 `Online Scene` 留空，连接保持当前竞技场。
6. `MvpBody.prefab` 作为玩家 Prefab 自动注册。管理器的 `Registered Spawnable Prefabs` 按 Unity Inspector 显示检查此 Prefab 的注册，保持每个 Prefab 一份有效注册。
7. 创建 Directional Light，旋转设置为 `50, -30, 0`。
8. Camera 位置设置为 `0, 13, -15`，旋转设置为 `38, 0, 0`，视野角设置为 `60`，裁剪范围设为 `0.1` 至 `100`。设置背景色为浅灰，开启工程的 URP 渲染。
9. 创建 `MvpArenaMaterial.mat`，Shader 选 `Universal Render Pipeline/Lit`，基础颜色设为白色，把材质赋给 `MvpWorld.ArenaMaterial`。场景引用使构建保留此着色器，代码用材质属性设置各类对象颜色。
10. 把 `MvpArena.unity` 设为 Build Settings 中的启动场景，平台选 Windows，构建到学习用输出目录。

KCP 是本工程使用的 UDP 可靠传输实现。UDP 是用户数据报协议。端口、防火墙和服务器连接入口的项目配置见 [Mirror 与 KCP 配置](../../../Y_MultipleAgentWorkflow/Project/Mirror_KCP_Config.md)。学习构建采用独立输出目录，便于保留工程的正式构建产物。

## 运行

先在一个进程点击 `Server`，再在两个客户端进程填写服务器地址并点击 `Client`。本机测试使用 `localhost`，服务器与客户端端口保持一致。也可以在一个进程点击 `Host`，另一个点击 `Client`。

操作使用 W、A、S、D 移动，空格跳跃，E 投掷。界面显示生命、分数、回合、碎片数量、累计协议字节和服务器 Tick 耗时。固定的镜头同时覆盖两名玩家和整个平台。

Build Settings 中的独立场景直接进入教程网络入口。按照 [运行验收](12-运行验收.md) 记录服务器与两个客户端的运行画面。
