# 06 服务器世界

## 本章解决的问题

角色移动、引信到期、碰撞爆炸和网络采样各自发生在什么时候？本章建立唯一的服务器模拟入口，把这些动作排在同一个 `Tick` 上。阅读重点是 `FixedUpdate` 的顺序，以及对象创建和删除如何让完整基线重新采样。

`MvpWorld` 是跨三份文件的 `partial` 类。本章声明世界字段与模拟入口，第 07 章提供 `Player`、移动与伤害，第 08 章提供爆炸、结构重建和回合规则。三个分部共同使用私有字典、队列、`dirty` 和 `endTick`。第 05～09 章代码与第 01～04 章核心类型共同构成完整编译依赖。

## 数据与职责

| 数据或入口 | 保存的内容 | 消费位置 |
|---|---|---|
| `Round / Tick` | 回合编号与该回合模拟步编号 | 输入检查、引信、事件、快照播放 |
| `Version / baselineId` | 拓扑版本与完整采样编号 | `Capture`、差量编码和客户端时间线 |
| `bodies / players` | 全部业务网络根与角色运行状态 | 对象生命周期、物理结算和状态采样 |
| `fuses / bombSources` | 炸弹到期 Tick 与投掷者编号 | 第 08 章投掷、爆炸和移除 |
| `explosions / causes` | 待结算炸弹编号与触发来源 | 第 08 章 `Explode` |
| `graph / blocks / fixedRoot` | 连接图、24 块归属、固定几何根 | 断裂重建与网络基线 |
| `basis / dirty` | 当前差量基准与完整状态重新发布标志 | `PublishBaseline` 和运动包发送 |
| `oldMode / oldStep` | 启动前的全局物理模式与固定步长 | `End` 恢复环境 |
| `BytesSent / LastStepMs` | 已编码状态数组长度累计与本步耗时 | 第 09 章界面 |

## 编写步骤

1. 编写 `Unity/MvpWorld.cs` 的字段，区分业务字典、结构状态和发送状态。
2. 编写 `Begin / End`，在服务器开始时切换到脚本物理模拟，在结束时恢复物理模式与固定步长。
3. 按下面的执行表编写 `FixedUpdate`。两次 `SyncTransforms` 分别服务角色查询与刚体模拟，每步只有一次 `Simulate`。
4. 编写 `Capture / PublishBaseline / Recover`，把“状态对应哪个 Tick”和“差量引用哪个基线”连接起来。
5. 编写对象编号、创建、删除和形状辅助函数，再与第 07、08 章的分部代码对照调用。

| 本步次序 | 代码动作 | 对数据和物理的影响 |
|---|---|---|
| 1 | `++Tick`、第一次 `SyncTransforms` | 先确定本步编号，再让 Transform 变动参与物理查询 |
| 2 | 对每个玩家调用 `MovePlayer` | 合并输入、支撑、重力和击退；角色碰撞回调在 `Move` 期间发生 |
| 3 | 到期引信入队，循环消费 `explosions` | 同时消费上一步刚体碰撞留下的队列；连锁入队也在此循环消费 |
| 4 | 第二次 `SyncTransforms`、`Physics.Simulate` | 将爆炸重建后的几何交给一次 `1/30` 秒的刚体模拟 |
| 5 | `FinishTick` | 根据模拟后位置判定落场、回合结束与重置 |
| 6 | 必要时 `PublishBaseline` | `dirty` 或 `Tick % 30 == 0` 时捕获完整状态，更新 `basis` |
| 7 | 偶数 Tick 发送运动包 | 采样当前状态并相对 `basis` 编码，每个数组单独广播 |
| 8 | 保存 `LastStepMs` | 耗时覆盖本函数中的移动、模拟、规则结算与编码发送调用 |

队列消费在 `Physics.Simulate` 之前。刚体 `OnCollisionEnter` 在该次模拟中把炸弹编号入队时，当前步的消费循环已经结束，所以碰撞触发在下一次 Tick 的队列阶段结算。该步的完整基线或运动采样仍可包含这枚炸弹。引信和当前消费循环中产生的连锁则在本步结算。

## 完整代码

```csharp file=Unity/MvpWorld.cs
using System;
using System.Collections.Generic;
using System.Linq;
using Mirror;
using UnityEngine;
using N3 = System.Numerics.Vector3;
using NQ = System.Numerics.Quaternion;

namespace Mvp
{
    public sealed partial class MvpWorld : MonoBehaviour
    {
        // Round 隔离回合；Tick 在每次服务器 FixedUpdate 开头增长，重开归零。
        public uint Round { get; private set; } = 1;
        public uint Tick { get; private set; }
        // 结构或对象集合改变使 Version 增长；完整基线另有 baselineId。
        public uint Version { get; private set; }
        // 只累计本类发送的 Wire 状态数组长度，每次广播只加一次。
        public long BytesSent { get; private set; }
        // 本次 FixedUpdate 内实际经过的毫秒数，包含编码与发送调用。
        public float LastStepMs { get; private set; }
        // manager 提供统一网络 Prefab，graph 提供节点与连接关系。
        MvpNetwork manager;
        Structure graph;
        // bodies 管全类别业务根，players 管角色专属状态。
        readonly Dictionary<uint, MvpBody> bodies = new Dictionary<uint, MvpBody>();
        readonly Dictionary<uint, Player> players = new Dictionary<uint, Player>();
        // 引信映射到到期 Tick，投掷者与触发来源在不同字典中保存。
        readonly Dictionary<uint, uint> fuses = new Dictionary<uint, uint>();
        readonly Dictionary<uint, uint> bombSources = new Dictionary<uint, uint>();
        // 多种原因允许重复入队，Explode 通过移除引信保证只结算一次。
        readonly Queue<uint> explosions = new Queue<uint>();
        // 固定 24 块，Parent=0 表示固定结构，其余值指向碎片业务根。
        readonly BlockState[] blocks = new BlockState[24];
        Transform fixedRoot;
        // 最近一次完整采样是随后运动包的差量基准。
        WorldState basis;
        // 对象、基线、事件各有编号；endTick 是重开时间，lastRecovery 是全局节流时间。
        uint nextId = 1, baselineId, eventId, endTick, lastRecovery;
        // dirty 请求本步末尾发布基线；running 同时保护启动和幂等结束。
        bool dirty, running;
        SimulationMode oldMode;
        float oldStep;
        // 共享形状材质通过场景引用提供，Shape 可建立 URP Lit 兜底材质。
        public Material ArenaMaterial;

        // Awake 将场景材质交给静态形状辅助函数，服务器与显示端共用该入口。
        void Awake() => sharedMaterial = ArenaMaterial;

        // 核心层用 System.Numerics，Unity 层用 UnityEngine；这里仅逐分量转换。
        public static N3 N(Vector3 p) => new N3(p.x, p.y, p.z);
        public static Vector3 U(N3 p) => new Vector3(p.X, p.Y, p.Z);
        public static NQ N(Quaternion q) => new NQ(q.x, q.y, q.z, q.w);
        public static Quaternion U(NQ q) => new Quaternion(q.X, q.Y, q.Z, q.W);

        // OnStartServer 调用：保存全局配置，建立固定结构并请求第一份完整基线。
        public void Begin(MvpNetwork network)
        {
            manager = network; running = true;
            oldMode = Physics.simulationMode; oldStep = Time.fixedDeltaTime;
            // 关闭自动模拟，由本类在每个固定步显式执行一次刚体物理。
            Physics.simulationMode = SimulationMode.Script; Time.fixedDeltaTime = Rules.Step;
            graph = new Structure();
            fixedRoot = new GameObject("FixedStructure").transform;
            fixedRoot.SetParent(transform, false);
            // 初始归属全为固定根，Local 取结构图的静止位置。
            for (int n = 0; n < 24; ++n)
                blocks[n] = new BlockState { Node = n, Parent = 0, Local = graph.Rest[n] };
            RebuildFixed();
            dirty = true;
        }

        // 服务器停止或组件禁用共用本入口；重复调用由 running 拦住。
        public void End()
        {
            if (!running) return;
            running = false;
            // 全局物理设置必须与启动前一致，避免继续影响场景中的其他逻辑。
            Physics.simulationMode = oldMode; Time.fixedDeltaTime = oldStep;
            // 这里清理业务缓存，Mirror 网络对象的关停由网络生命周期承担。
            bodies.Clear(); players.Clear(); fuses.Clear(); bombSources.Clear(); explosions.Clear(); causes.Clear();
            if (fixedRoot != null) Destroy(fixedRoot.gameObject);
            Round = 1; Tick = 0; Version = 0;
            nextId = 1; baselineId = 0; eventId = 0; endTick = 0; lastRecovery = 0;
            roundStart = 0; BytesSent = 0; LastStepMs = 0;
        }
        // 组件被禁用也退出脚本模拟状态。
        void OnDisable() => End();

        // 服务器模拟的唯一入口；纯客户端实例直接返回。
        void FixedUpdate()
        {
            if (!running || !NetworkServer.active) return;
            double start = Time.realtimeSinceStartupAsDouble;
            ++Tick;
            // 让上一步直接写入的 Transform 对角色的地面和支撑查询可见。
            Physics.SyncTransforms();
            foreach (var p in players.Values) MovePlayer(p);
            // ToArray 固定本次到期列表，Explode 随后会删除引信项。
            foreach (uint id in fuses.Where(p => p.Value <= Tick).Select(p => p.Key).ToArray())
                explosions.Enqueue(id);
            // 本循环也消费 Explode 追加的连锁项，直至队列为空。
            while (explosions.Count > 0) Explode(explosions.Dequeue());
            // 爆炸可能销毁旧根并建立新碰撞体，先同步，再模拟一次。
            Physics.SyncTransforms();
            Physics.Simulate(Rules.Step);
            // 模拟中的碰撞入队留到下一 Tick；这里先判定落场和回合。
            FinishTick();
            // 拓扑变化立即触发完整采样，普通周期为每 30 Tick 一次。
            if (dirty || Tick % Rules.Rate == 0) PublishBaseline();
            if (Tick % 2 == 0 && basis != null)
            {
                // Capture 与刚生成的 basis 使用同一基线编号，Wire 按对象拆成批次。
                foreach (byte[] packet in Wire.Motion(Capture(baselineId), basis))
                {
                    // true 只向 ready 连接广播；可丢弃通道允许运动包损失。
                    NetworkServer.SendToAll(new MvpMotion { Bytes = packet }, Channels.Unreliable, true);
                    // 按编码数组统计一次，连接数量与传输协议开销另有口径。
                    BytesSent += packet.Length;
                }
            }
            LastStepMs = (float)((Time.realtimeSinceStartupAsDouble - start) * 1000);
        }

        // 已登记玩家才可请求；旧回合请求允许触发当前基线，超前回合被拒绝。
        public void Recover(MvpBody body, uint round)
        {
            if (body == null || !players.ContainsKey(body.Id) || round > Round ||
                Tick - lastRecovery < 15) return;
            // 新基线向全部观察者发送，使后续差量引用在所有连接上有效。
            // lastRecovery 在世界上共享，15 Tick 间隔约为 0.5 秒。
            lastRecovery = Tick; dirty = true;
        }

        // 捕获与可靠广播共用同一份 basis，后续差量统一引用它。
        void PublishBaseline()
        {
            // 周期基线只增长 baselineId；Version 保持实际拓扑版本。
            basis = Capture(++baselineId);
            byte[] bytes = Wire.Baseline(basis);
            NetworkServer.SendToAll(new MvpBaseline { Bytes = bytes }, Channels.Reliable, true);
            BytesSent += bytes.Length; dirty = false;
        }

        // 从服务器实物建立值状态；克隆块和断边数组以隔离后续结构修改。
        WorldState Capture(uint baseline)
        {
            var w = new WorldState { Round = Round, Tick = Tick, Version = Version, Baseline = baseline,
                Blocks = (BlockState[])blocks.Clone(), Broken = (bool[])graph.Broken.Clone() };
            w.Bodies = bodies.Values.OrderBy(b => b.Id).Select(b =>
            {
                var rb = b.GetComponent<Rigidbody>();
                // 炸弹/碎片读刚体速度，玩家读角色求解的 Velocity；休眠取刚体状态。
                var s = new BodyState { Id = b.Id, Generation = b.Generation, Kind = b.Kind,
                    Position = N(b.transform.position), Rotation = N(b.transform.rotation),
                    Velocity = rb != null ? N(rb.velocity) : N(players[b.Id].Velocity),
                    Sleeping = rb != null && rb.IsSleeping() };
                // 生命和分数只从玩家运行状态复制。
                if (players.TryGetValue(b.Id, out var p)) { s.Health = p.Health; s.Score = p.Score; }
                return s;
            }).ToArray();
            return w;
        }

        // 数量预算与编号耗尽在分配入口检查，业务编号只向前增长。
        uint Allocate()
        {
            if (bodies.Count >= Rules.MaxBodies || nextId == uint.MaxValue)
                throw new InvalidOperationException("对象预算耗尽");
            return nextId++;
        }

        // 动态类别的共同创建前半段：登记身份并标脏；调用方再加物理组件和 Spawn。
        MvpBody NewBody(BodyKind kind, Vector3 position)
        {
            var b = Instantiate(manager.BodyPrefab, position, Quaternion.identity);
            b.Id = Allocate(); b.Round = Round; b.Kind = kind;
            bodies.Add(b.Id, b); ++Version; dirty = true;
            return b;
        }

        // 移除业务根、引信与投掷者记录，并通知 Mirror 销毁网络对象。
        void RemoveBody(uint id)
        {
            if (!bodies.TryGetValue(id, out var b)) return;
            bodies.Remove(id); fuses.Remove(id); bombSources.Remove(id);
            ++Version; dirty = true;
            // Unity 延迟销毁对象，立即停用可让本 Tick 只模拟新几何。
            b.gameObject.SetActive(false);
            NetworkServer.Destroy(b.gameObject);
        }

        // 固定根在本教程使用单位世界变换；动态块需由所属根转换到世界空间。
        Vector3 NodePosition(int n)
        {
            var block = blocks[n];
            return block.Parent == 0 ? U(block.Local) : bodies[block.Parent].transform.TransformPoint(U(block.Local));
        }

        // 仅重建 Parent=0 的固定块，动态块形状由 Gameplay 分部建立。
        void RebuildFixed()
        {
            ClearShapes(fixedRoot);
            foreach (var b in blocks.Where(b => b.Parent == 0))
                Shape(PrimitiveType.Cube, fixedRoot, U(b.Local), new Vector3(1.45f, .5f, 1.45f),
                      graph.Anchor[b.Node] ? Color.green : Color.gray, true);
        }

        // 倒序遍历子物体，先停用碰撞和渲染，再安排 Unity 延迟销毁。
        public static void ClearShapes(Transform root)
        {
            for (int i = root.childCount - 1; i >= 0; --i)
            {
                var child = root.GetChild(i).gameObject;
                child.SetActive(false); UnityEngine.Object.Destroy(child);
            }
        }

        // 生成形状与颜色；collide 区分服务器物理几何和客户端纯视觉几何。
        public static GameObject Shape(PrimitiveType kind, Transform parent, Vector3 local,
                                       Vector3 scale, Color color, bool collide)
        {
            var shape = GameObject.CreatePrimitive(kind);
            shape.name = "Mesh"; shape.transform.SetParent(parent, false);
            shape.transform.localPosition = local; shape.transform.localScale = scale;
            var collider = shape.GetComponent<Collider>();
            // 视觉形状立即禁用 Collider，Destroy 的延迟不影响本帧查询。
            collider.enabled = collide;
            if (!collide) UnityEngine.Object.Destroy(collider);
            if (sharedMaterial == null)
                sharedMaterial = new Material(Shader.Find("Universal Render Pipeline/Lit"));
            // 共享材质配合属性块提供每个形状的颜色，避免逐形状复制材质。
            var renderer = shape.GetComponent<Renderer>();
            renderer.sharedMaterial = sharedMaterial;
            var properties = new MaterialPropertyBlock();
            properties.SetColor("_BaseColor", color); properties.SetColor("_Color", color);
            renderer.SetPropertyBlock(properties);
            return shape;
        }
        // 静态材质缓存供服务器和客户端形状创建共用。
        static Material sharedMaterial;

        // 场景辅助线从当前世界节点位置取端点，因此也跟随旋转碎片。
        void OnDrawGizmos()
        {
            if (graph == null || !running) return;
            Gizmos.color = Color.yellow;
            for (int e = 0; e < graph.Edges.Count; ++e)
                if (!graph.Broken[e])
                    Gizmos.DrawLine(NodePosition(graph.Edges[e].A), NodePosition(graph.Edges[e].B));
        }
    }
}
```

## 手工追踪一个 Tick

设当前 `Tick=89`，炸弹 10 的引信为 90，队列里已有上一步碰撞触发的炸弹 11；玩家存活，`basis` 指向上一份完整基线。

1. 进入 `FixedUpdate`，编号增长为 90；角色先移动。
2. 到期筛选把 10 追加到已有队列，队列成为 `[11,10]`。先结算 11；假设它的范围内有 10，则追加 10，队列成为 `[10,10]`。
3. 第一次结算 10 时移除引信并执行爆炸；第二次取出 10 时 `fuses.Remove(10)` 返回假，直接结束该次调用。
4. 重建几何后同步 Transform，再模拟 `1/30` 秒。假设炸弹 12 在这次模拟中高速撞到碎片，它入队后保持到 Tick 91 的消费阶段。
5. `FinishTick` 根据本次模拟后的玩家位置判定落场。Tick 90 是 30 的倍数，采样完整基线；它含仍存活的炸弹 12。
6. Tick 90 也是偶数，运动批次使用刚发布的基线编号。若基线数组长度为 `L`，两份运动数组长度为 `M1、M2`，本步统计增加 `L+M1+M2`。

即使有两个 ready 客户端，`BytesSent` 的本步增量仍为 `L+M1+M2`。它是业务状态数组的编码产量，实际每个连接发送多少、Mirror 消息头、数组长度前缀、批处理、KCP、UDP、重传，以及 `MvpExplosion` 和输入消息都另属口径。`Sleeping` 随状态采样；运动发送循环仍按每两个 Tick 运行。

## 预期与排查

| 检查动作 | 代码对应的预期 | 优先检查位置 |
|---|---|---|
| 开始和结束服务器 | 开始用脚本物理模式和 `1/30` 步长，结束恢复原配置 | `Begin / End`、`running`、`OnDisable` |
| 对照一次固定步 | 角色 → 队列 → 一次物理模拟 → 回合 → 网络采样 | `FixedUpdate`；避免额外调用 `Physics.Simulate` |
| 炸弹撞击碎片 | 当前模拟入队，下一 Tick 队列消费 | 第 05 章碰撞回调、第 08 章 `Impact` |
| 创建或删除业务根 | 更新字典与 `Version`，最近一次末尾采样发布基线 | `NewBody / RemoveBody`、`dirty` |
| 客户端请求恢复 | 有效请求令世界标脏，完整基线向全部 ready 连接广播 | `Recover` 的全局 15 Tick 限制 |
| 碎片休眠 | `Capture` 带休眠标记，运动调度仍是偶数 Tick | 刚体 `IsSleeping`、`Wire.Motion` |

`NodePosition` 对固定块直接返回 `Local`，对应教程固定根和世界根采用单位变换的场景约定。场景根有额外平移或旋转时，应先核对这一坐标前提，再判断固定块与动态碎片的位置关系。
