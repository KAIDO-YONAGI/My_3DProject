# 07 让现有角色跟随下落平台

`NetworkPlayer` 使用 `CharacterController`，自身运动器负责施加重力，但不会自动继承脚下平台的平移和旋转。平台移动时，角色可能先失去接触再自己下落。我们需要把接触点这一帧的位移并入角色原有移动，让“站着被带动”和“跳离平台”有明确的处理位置。

本章保留当前方向键、跳跃、转向和动画。我们只改运动链的输入和位移合成位置。

## 1. 添加脚下平台速度记录

创建 `Assets/Core/Scripts/Gameplay/Mvp/PlatformPassenger.cs`：

```csharp file=Assets/Core/Scripts/Gameplay/Mvp/PlatformPassenger.cs
using UnityEngine;

namespace Core.Scripts.Gameplay.Mvp
{
    public sealed class PlatformPassenger : MonoBehaviour
    {
        private PlatformChunk supportChunk;
        private Vector3 supportLocalPoint;
        private Vector3 previousWorldPoint;
        private bool hasSupportSample;

        // 每帧移动角色前调用一次，读取上次接触点随平台移动了多少。
        public Vector3 ConsumeSupportVelocity(float deltaTime)
        {
            if (!hasSupportSample || supportChunk == null || deltaTime <= 0f)
            {
                return Vector3.zero;
            }

            Vector3 currentWorldPoint = supportChunk.transform.TransformPoint(supportLocalPoint);
            Vector3 velocity = (currentWorldPoint - previousWorldPoint) / deltaTime;
            previousWorldPoint = currentWorldPoint;
            hasSupportSample = false;
            return velocity;
        }

        public void RecordHit(ControllerColliderHit hit)
        {
            PlatformChunk chunk = hit.collider.GetComponentInParent<PlatformChunk>();
            if (chunk == null || chunk.Anchored || hit.normal.y < 0.45f)
            {
                return;
            }

            supportChunk = chunk;
            // 保存平台局部接触点，平台旋转时这个点也会一起移动。
            supportLocalPoint = chunk.transform.InverseTransformPoint(hit.point);
            previousWorldPoint = hit.point;
            hasSupportSample = true;
        }

        public void Clear()
        {
            supportChunk = null;
            supportLocalPoint = Vector3.zero;
            previousWorldPoint = Vector3.zero;
            hasSupportSample = false;
        }
    }
}
```

`ControllerColliderHit` 是角色自己的 `CharacterController.Move` 碰撞结果。法线的 Y 分量较大表示接触面朝上；侧面撞击不会被误认为脚下支撑。客户端平台刚体是 Kinematic，所以它的 Rigidbody 速度不代表网络插值后的实际位移。脚本把接触点记在平台局部坐标里，再比较相邻两帧接触点的世界位置，算出这台客户端实际看到的平台速度。平台旋转造成的接触点移动也会计入。

在 `NetworkPlayer.prefab` 根对象上添加 `PlatformPassenger`。新组件与 `PlayerCharacterController`、`CharacterController` 同在根对象。

## 2. 把接触结果交给现有控制器

打开 `Assets/Core/Scripts/Character/Control/PlayerCharacterController.cs`。在类字段中增加：

```csharp
private PlatformPassenger platformPassenger;
```

在文件顶部的 using 区域增加：

```csharp
using Core.Scripts.Gameplay.Mvp;
```

在 `EnsureRuntimeState()` 中、`characterController == null` 的提前返回之前加入：

```csharp
if (platformPassenger == null)
{
    platformPassenger = GetComponent<PlatformPassenger>();
}
```

在 `Update` 里，把现有的：

```csharp
CurrentMotion = motor.Tick(input, inputSpace, Time.deltaTime);
```

替换为：

```csharp
Vector3 supportVelocity = platformPassenger != null
    ? platformPassenger.ConsumeSupportVelocity(Time.deltaTime)
    : Vector3.zero;
CurrentMotion = motor.Tick(input, inputSpace, Time.deltaTime, supportVelocity);
```

然后在同一个 `PlayerCharacterController` 类中加入 Unity 碰撞回调：

```csharp
private void OnControllerColliderHit(ControllerColliderHit hit)
{
    platformPassenger?.RecordHit(hit);
}
```

每帧的顺序是：读取上一帧角色碰撞到的动态平台速度，再让运动器计算这帧玩家输入；CharacterController 完成移动时，`OnControllerColliderHit` 记录接触到的平台，供下一帧使用。

例如上一帧接触点的世界 Y 为 `12`，这一帧变成 `11.9`，两帧间隔为 `0.02` 秒，那么采样速度为 `(11.9 - 12) / 0.02 = -5` 米每秒。把这份速度乘回 `deltaTime`，角色就跟随平台下移 `0.1` 米。保存局部点而不是平台中心，是为了把旋转带来的边缘位移也算进去。

## 3. 把平台位移并进同一次 CharacterController.Move

打开 `Assets/Core/Scripts/Character/Movement/CharacterMotor.cs`。保留原来的 `Tick` 计算，只对它做三个局部修改。

先给方法增加最后一个参数：

```csharp
public CharacterMotion Tick(
    CharacterInput input,
    Transform inputSpace,
    float deltaTime,
    Vector3 supportVelocity)
```

找到 `jumpStarted` 为真时设置跳跃速度的代码，在设置跳跃速度后加入：

```csharp
planarVelocity += Vector3.ProjectOnPlane(supportVelocity, Vector3.up);
```

这表示角色从正在移动的平台起跳时，把平台在水平面的速度加到自己的水平速度。竖直方向则并入跳跃初速度：

```csharp
verticalVelocity = settings.GetJumpSpeed() + Mathf.Max(0f, supportVelocity.y);
```

所以该分支完整的核心顺序是：

```csharp
if (jumpStarted)
{
    // 下落平台不削弱主动跳跃；上升平台给跳跃额外向上速度。
    verticalVelocity = settings.GetJumpSpeed() + Mathf.Max(0f, supportVelocity.y);
    planarVelocity += Vector3.ProjectOnPlane(supportVelocity, Vector3.up);
}
```

再找到创建 `frameMotion` 的位置。用以下逻辑替换原来两行：

```csharp
Vector3 motionVelocity = planarVelocity + Vector3.up * verticalVelocity;
if (groundedBeforeMove && !jumpStarted)
{
    // 站着时跟平台走；起跳这一帧由上面的初速度接管。
    motionVelocity += supportVelocity;
}

Vector3 frameMotion = motionVelocity * deltaTime;
CollisionFlags collisionFlags = characterController.Move(frameMotion);
```

站在平台上时，角色当前帧输入位移和平台当前速度相加，一起送给现有的那一次 `CharacterController.Move`。因此角色自身的碰撞检测仍由原控制器处理，不会变成两个脚本各自挪一次角色。起跳时则停止贴着平台走，并把平台速度作为起跳初速度的一部分。

## 4. 给运动器添加复位入口

在 `CharacterMotor` 中增加：

```csharp
public void ResetMotion()
{
    planarVelocity = Vector3.zero;
    verticalVelocity = settings.GroundedPull;
    airborneDuration = 0f;
}
```

在 `PlayerCharacterController` 中增加：

```csharp
public void ResetMotion()
{
    EnsureRuntimeState();
    motor?.ResetMotion();
    platformPassenger?.Clear();
}
```

回到第 05 章的 `ArenaPlayerActions.ServerReset`，在 `ServerTeleport(...)` 调用后加入：

```csharp
if (connectionToClient != null)
    TargetResetMotion(connectionToClient);
```

再在 `ArenaPlayerActions` 类中加入这个方法：

```csharp
[TargetRpc]
private void TargetResetMotion(NetworkConnectionToClient target)
{
    // 位置交给 ServerTeleport；这里仅清除本机运动器的旧状态。
    GetComponent<PlayerCharacterController>()?.ResetMotion();
}
```

`TargetRpc` 把这次调用只送给拥有这个玩家的客户端。该客户端才运行自己的 `CharacterMotor`，所以旧速度也要在这里清掉；位置同步和运动器内部状态各有自己的复位入口。

## 5. 用运行结果检查是不是接对了

在服务器与客户端进入游戏后，观察第二层平台的格子断开并成为动态碎片：

1. 站在尚未移动的平台上，角色跟随移动平台而不悬空。
2. 在移动碎片上按跳跃，角色有平台运动方向带来的初速度。
3. 跳离后，角色不会继续被旧平台拉回去。
4. 角色自己的跑动动画、相机和方向控制仍由原组件工作。

若人物在客户端和服务器的相对位置有轻微差异，这是当前玩家使用拥有者位置同步、平台使用服务器物理同步的边界。服务器根据收到的玩家位置进行回合判断；位置校验与移动回滚不是本章的一部分。
