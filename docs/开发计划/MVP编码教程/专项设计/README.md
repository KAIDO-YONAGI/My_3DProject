## 怎样把查询内容用起来

**查看现有项目时，先从实际脚本追调用。** 角色接入篇给出当前源码入口，API 总览解释跨网络的位置，其他普通方法仍在本进程执行。

**编写 MVP 时，以主线的 `csharp file=...` 完整文件为单位。** 状态、集合、投掷预测与命中篇中的组件示例用于理解或扩展对应职责。它们的类型、Prefab 和接入接口各自组成一个练习，主线使用 `Mvp` 命名空间和自写世界状态。

**做深入设计时，先确定输入、输出和时间。** 结构篇与同步内核篇定义规模扩展、恢复和预测的规则；主线提供基础闭环，可按相同规则逐项对照实验。
