# 08 用道具破坏平台并完成一局

本章把服务端回合、炸弹携带者、平台破坏道具和胜负状态接进现有玩法场景。玩家仍是 `NetworkPlayer`，操作仍由它上面的 `ArenaPlayerActions` 发给服务器；平台和道具由服务器创建、裁决和销毁。

这一章内容较多，按下面四步完成，每次只关注一种状态变化：

1. 等待两人、倒计时、开始和结算。
2. 开局携带者贴近另一人，让平台整片脱落。
3. 拾取道具，按 E 请求挖掉瞄准位置附近的格子。
4. 控制刷出频率和数量上限，再把脚本接到场景。

各段代码使用同一个 `ArenaMatch` 类。第一段建立文件骨架，后面的方法都加到类内最后一个 `}` 前；每段前面会说明执行时机和数据含义。

## 1. 先看三个脚本分别做什么

本章先写完三个脚本，再在第 7 节编译、制作 Prefab 和连接场景。文件都放在 `Assets/Core/Scripts/Gameplay/Mvp`，命名空间统一为 `Core.Scripts.Gameplay.Mvp`。

| 脚本 | 负责的事情 |
| --- | --- |
| `ArenaMatch` | 保存回合阶段，检查接近、攻击、淘汰和胜负 |
| `ArenaPickup` | 检查附近玩家，发放一次道具使用次数 |
| `ArenaMatchBootstrap` | 等服务器的五层场地准备好，生成一个对局对象 |

`ArenaMatch` 用到 `ArenaPickup` 类型，所以先把本章三个文件补齐再查看编译结果。

## 2. 先让一局开始并结束

创建 `Assets/Core/Scripts/Gameplay/Mvp/ArenaMatch.cs`，先写骨架。`Phase` 是大家共同看到的当前阶段；`PhaseEndsAt` 是这个阶段结束的服务器时间。客户端只需要同步一个时间点，就能在界面显示剩余秒数。

```csharp file=Assets/Core/Scripts/Gameplay/Mvp/ArenaMatch.cs
using System;
using System.Collections.Generic;
using Mirror;
using UnityEngine;
using UnityEngine.SceneManagement;

namespace Core.Scripts.Gameplay.Mvp
{
    public enum ArenaMatchPhase : byte
    {
        // 这些名字分别表示等待、开局倒计时、对局进行和结算。
        Waiting,
        Countdown,
        Playing,
        Results
    }

    public sealed class ArenaMatch : NetworkBehaviour
    {
        public static ArenaMatch Instance { get; private set; }

        [SerializeField] private ArenaPickup pickupPrefab;
        [SerializeField] private float countdownSeconds = 3f;
        [SerializeField] private float resultsSeconds = 5f;
        [SerializeField] private float carrierGraceSeconds = 4f;
        [SerializeField] private float carrierContactDistance = 2.4f;
        [SerializeField] private float pickupInterval = 5f;
        [SerializeField] private float breakRadius = 1.2f;
        [SerializeField] private float useRange = 25f;

        // 所有客户端都需要知道的当前对局状态，由服务器修改。
        [SyncVar] public ArenaMatchPhase Phase;
        [SyncVar] public uint RoundId;
        // 保存玩家 netId，客户端可据此找到对应的网络玩家。
        [SyncVar] public uint CarrierNetId;
        [SyncVar] public uint WinnerNetId;
        [SyncVar] public int AliveCount;
        // 保存结束的时间点，客户端用它减去当前网络时间显示倒计时。
        [SyncVar] public double PhaseEndsAt;

        private readonly Dictionary<uint, double> nextUseTime = new();
        private bool openingDetached;
        private double carrierArmedAt;
        private double nextPickupAt;
        private int nextPickupLayer = 2;
    }
}
```

### 网络对象启动时，接上使用规则

把下面四个生命周期方法放进 `ArenaMatch` 类。注意 `ServerUseRule = ServerTryUse`：第 05 章玩家请求到达服务器后，就会进入本章的正式规则方法。`ServerTryUse` 在第 4 节补齐。

```csharp
        public override void OnStartServer()
        {
            Instance = this;
            Phase = ArenaMatchPhase.Waiting;
            RoundId = 0;
            CarrierNetId = 0;
            WinnerNetId = 0;
            AliveCount = 0;
            PhaseEndsAt = NetworkTime.time;
            ArenaPlayerActions.ServerUseRule = ServerTryUse;
        }

        public override void OnStartClient()
        {
            Instance = this;
        }

        public override void OnStopServer()
        {
            ArenaPlayerActions.ServerUseRule = null;
            ServerDestroyPickups();
            nextUseTime.Clear();
            if (Instance == this)
            {
                Instance = null;
            }
        }

        public override void OnStopClient()
        {
            if (Instance == this)
            {
                Instance = null;
            }
        }
```

### 用阶段控制每帧该做什么

继续在同一个类中加入 `Update`。它只在服务器运行：

```csharp
        [ServerCallback]
        private void Update()
        {
            switch (Phase)
            {
                case ArenaMatchPhase.Waiting:
                    // 至少两名玩家且五层场地准备好，才开始计时。
                    if (ServerConnectedPlayers().Count >= 2 &&
                        ArenaSceneBootstrap.Instance != null &&
                        ArenaSceneBootstrap.Instance.Ready)
                    {
                        Phase = ArenaMatchPhase.Countdown;
                        PhaseEndsAt = NetworkTime.time + countdownSeconds;
                    }
                    break;

                case ArenaMatchPhase.Countdown:
                    if (ServerConnectedPlayers().Count < 2)
                    {
                        Phase = ArenaMatchPhase.Waiting;
                        PhaseEndsAt = NetworkTime.time;
                    }
                    else if (NetworkTime.time >= PhaseEndsAt)
                    {
                        ServerStartRound();
                    }
                    break;

                case ArenaMatchPhase.Playing:
                    ServerTickRound();
                    break;

                case ArenaMatchPhase.Results:
                    if (NetworkTime.time >= PhaseEndsAt)
                    {
                        Phase = ArenaMatchPhase.Waiting;
                        PhaseEndsAt = NetworkTime.time;
                    }
                    break;
            }
        }
```

例如服务器当前时间是 `10` 秒，倒计时长 `3` 秒，进入倒计时就把 `PhaseEndsAt` 写为 `13`。每帧只需比较当前时间是否达到 `13`；客户端显示倒计时也使用同一个时间点。

### 开局时复位场地和玩家

把下面方法加入类中。它先清掉上局道具、重建五层，再复位玩家和抽取携带者：

```csharp
        [Server]
        private void ServerStartRound()
        {
            ArenaSceneBootstrap arena = ArenaSceneBootstrap.Instance;
            List<ArenaPlayerActions> players = ServerConnectedPlayers();
            if (arena == null || !arena.Ready || players.Count < 2)
            {
                Phase = ArenaMatchPhase.Waiting;
                return;
            }

            RoundId++;
            if (RoundId == 0)
            {
                RoundId = 1;
            }

            ServerDestroyPickups();
            arena.ServerBuild(RoundId);
            if (!arena.Ready)
            {
                Phase = ArenaMatchPhase.Waiting;
                return;
            }

            for (int i = 0; i < players.Count; i++)
            {
                // ServerReset 同步位置并清理该玩家的本局状态。
                players[i].ServerReset(ServerSpawnPosition(arena, i), RoundId);
            }

            CarrierNetId = players[UnityEngine.Random.Range(0, players.Count)].netId;
            WinnerNetId = 0;
            openingDetached = false;
            carrierArmedAt = NetworkTime.time + carrierGraceSeconds;
            nextPickupAt = NetworkTime.time + pickupInterval;
            nextPickupLayer = 2;
            nextUseTime.Clear();
            Phase = ArenaMatchPhase.Playing;
            PhaseEndsAt = 0;
            AliveCount = players.Count;
        }
```

`RoundId` 是本局编号。每个玩家、平台、道具都保存这个编号，服务器据此排除上一局对象和中途加入的观战者。开始新局时才统一给已连接玩家写入新编号。

### 进行中检查淘汰，人数剩一时结算

加入下面两个方法。玩家进入虚空后，服务器把 `Alive` 改为 `false`；客户端通过第 05 章的钩子关闭自己的运动控制器。

```csharp
        [Server]
        private void ServerTickRound()
        {
            foreach (ArenaPlayerActions player in ServerConnectedPlayers())
            {
                if (player.RoundId != RoundId)
                {
                    player.ServerSetAlive(false);
                }
                else if (player.Alive &&
                         ArenaSceneBootstrap.Instance != null &&
                         player.transform.position.y < ArenaSceneBootstrap.Instance.VoidY)
                {
                    player.ServerSetAlive(false);
                }
            }

            List<ArenaPlayerActions> alivePlayers = ServerAlivePlayers();
            AliveCount = alivePlayers.Count;
            if (AliveCount <= 1)
            {
                ServerFinishRound(alivePlayers);
                return;
            }

            ServerKeepCarrier(alivePlayers);
            ServerTryDetachOpening(alivePlayers);
            ServerTrySpawnPickup();
        }

        [Server]
        private void ServerFinishRound(List<ArenaPlayerActions> alivePlayers)
        {
            WinnerNetId = alivePlayers.Count == 1 ? alivePlayers[0].netId : 0;
            CarrierNetId = 0;
            ServerDestroyPickups();
            Phase = ArenaMatchPhase.Results;
            PhaseEndsAt = NetworkTime.time + resultsSeconds;
        }
```

`ServerTickRound` 依次处理淘汰、胜负、携带者和刷道具。胜负一旦成立就直接 `return`，同一帧不会继续触发炸弹或刷道具。零人生还时 `WinnerNetId=0`，表示平局。

## 3. 让携带者贴近另一人时炸掉开局平台

先加这个方法：若携带者断线或淘汰，就在剩余玩家中重新选择，并给新携带者一段预备时间。

```csharp
        [Server]
        private void ServerKeepCarrier(List<ArenaPlayerActions> alivePlayers)
        {
            foreach (ArenaPlayerActions player in alivePlayers)
            {
                if (player.netId == CarrierNetId)
                {
                    return;
                }
            }

            ArenaPlayerActions nextCarrier =
                alivePlayers[UnityEngine.Random.Range(0, alivePlayers.Count)];
            CarrierNetId = nextCarrier.netId;
            carrierArmedAt = NetworkTime.time + carrierGraceSeconds;
        }
```

再加接近检测。`openingDetached` 保证每局开局平台只触发一次，`carrierArmedAt` 表示炸弹开始响应接近的时间。

```csharp
        [Server]
        private void ServerTryDetachOpening(List<ArenaPlayerActions> alivePlayers)
        {
            if (openingDetached || NetworkTime.time < carrierArmedAt)
            {
                return;
            }

            ArenaPlayerActions carrier = null;
            foreach (ArenaPlayerActions player in alivePlayers)
            {
                if (player.netId == CarrierNetId)
                {
                    carrier = player;
                    break;
                }
            }

            if (carrier == null)
            {
                return;
            }

            foreach (ArenaPlayerActions other in alivePlayers)
            {
                if (other == carrier ||
                    Vector3.Distance(carrier.transform.position, other.transform.position) >
                    carrierContactDistance)
                {
                    continue;
                }

                foreach (PlatformChunk chunk in new List<PlatformChunk>(PlatformChunk.ServerChunks))
                {
                    if (chunk != null && chunk.RoundId == RoundId &&
                        chunk.Layer == 0 && chunk.IsOpening && chunk.Anchored)
                    {
                        // 改变整片的固定状态，不调用挖格子的分裂逻辑。
                        chunk.ServerDetach();
                        openingDetached = true;
                        return;
                    }
                }

                openingDetached = true;
                return;
            }
        }
```

距离在服务器用已经收到的玩家位置计算。这里实现“两个玩家贴近触发开局脱落”；屏幕上的白色标签属于下一章的显示层，不参与这个距离判定。

## 4. 让 E 键请求通过规则检查

把下面方法加入同一个类。先看三道检查：当前阶段和玩家状态、使用间隔、服务器射线命中。最后才扣道具并破坏平台。

```csharp
        [Server]
        private bool ServerTryUse(ArenaPlayerActions player, Vector3 aimDirection)
        {
            if (Phase != ArenaMatchPhase.Playing ||
                player == null ||
                !player.Alive ||
                player.RoundId != RoundId ||
                aimDirection.sqrMagnitude < 0.0001f)
            {
                return false;
            }

            if (nextUseTime.TryGetValue(player.netId, out double allowedAt) &&
                NetworkTime.time < allowedAt)
            {
                return false;
            }

            Vector3 direction = aimDirection.normalized;
            Vector3 origin = player.transform.position + Vector3.up;
            RaycastHit[] hits = Physics.RaycastAll(
                origin, direction, useRange, Physics.DefaultRaycastLayers,
                QueryTriggerInteraction.Ignore);
            Array.Sort(hits, (a, b) => a.distance.CompareTo(b.distance));
            return ServerApplyFirstHit(player, hits);
        }
```

射线起点来自服务器上的玩家位置，方向来自玩家请求。`RaycastAll` 返回顺序没有保证，所以先按距离排序。下面的方法依次查看命中结果，跳过玩家自己的碰撞体，遇到第一个有效遮挡就决定是否允许攻击。

把它加入同一个类中：

```csharp
        [Server]
        private bool ServerApplyFirstHit(ArenaPlayerActions player, RaycastHit[] hits)
        {
            foreach (RaycastHit hit in hits)
            {
                if (hit.collider == null)
                {
                    continue;
                }

                NetworkIdentity hitIdentity =
                    hit.collider.GetComponentInParent<NetworkIdentity>();
                if (hitIdentity == player.netIdentity)
                {
                    continue;
                }

                PlatformChunk chunk = hit.collider.GetComponentInParent<PlatformChunk>();
                if (chunk == null)
                {
                    return false;
                }

                if (!chunk.Anchored ||
                    chunk.RoundId != RoundId ||
                    !HasCellNearHit(chunk, hit.point))
                {
                    return false;
                }

                if (!player.ServerConsumeCharge())
                {
                    return false;
                }

                // 到这里才扣使用间隔并破坏，瞄空不会扣除库存。
                nextUseTime[player.netId] = NetworkTime.time + 0.5f;
                chunk.ServerBreak(hit.point, breakRadius);
                return true;
            }

            return false;
        }
```

命中的是当前回合、仍固定的平台时，再确认附近确实还有格子。把下面方法也加入类中：

```csharp
        [Server]
        private bool HasCellNearHit(PlatformChunk chunk, Vector3 worldPoint)
        {
            ArenaSceneBootstrap arena = ArenaSceneBootstrap.Instance;
            if (arena == null || chunk.Layer < 0 || chunk.Layer >= arena.FloorOrigins.Count)
            {
                return false;
            }

            Transform origin = arena.FloorOrigins[chunk.Layer];
            if (origin == null)
            {
                return false;
            }

            Vector3 localHit = origin.InverseTransformPoint(worldPoint);
            float maxDistance = PlatformLayout.CellSize * 0.8f;
            foreach (int cell in chunk.Cells)
            {
                Vector3 localCell = PlatformLayout.PositionOf(cell);
                Vector2 offset = new Vector2(localHit.x - localCell.x, localHit.z - localCell.z);
                if (offset.sqrMagnitude <= maxDistance * maxDistance)
                {
                    return true;
                }
            }

            return false;
        }
```

这里把命中点换到对应楼层的局部坐标，与格子中心比较。固定平台分裂后的根仍沿用原楼层的位置和旋转，所以可以使用 `FloorOrigins[layer]`；动态碎片已由前面的 `!chunk.Anchored` 条件排除。

## 5. 以固定频率在下层刷道具

先加入定时入口。`nextPickupAt` 控制频率，每次只生成一个道具；`nextPickupLayer` 让第三、四、五层轮流尝试。

```csharp
        [Server]
        private void ServerTrySpawnPickup()
        {
            if (pickupPrefab == null || NetworkTime.time < nextPickupAt)
            {
                return;
            }

            nextPickupAt = NetworkTime.time + pickupInterval;
            for (int attempt = 0; attempt < 3; attempt++)
            {
                int layer = 2 + ((nextPickupLayer - 2 + attempt) % 3);
                if (ServerPickupCount(layer) >= layer - 1)
                {
                    // Layer 从 0 计数，第三、四、五层的场上上限是 1、2、3。
                    continue;
                }

                if (!ServerTryChoosePickupPosition(layer, out Vector3 position))
                {
                    continue;
                }

                GameObject instance = Instantiate(
                    pickupPrefab.gameObject, position, Quaternion.identity);
                SceneManager.MoveGameObjectToScene(instance, gameObject.scene);
                ArenaPickup pickup = instance.GetComponent<ArenaPickup>();
                pickup.RoundId = RoundId;
                pickup.Layer = layer;
                NetworkServer.Spawn(instance);
                nextPickupLayer = layer == 4 ? 2 : layer + 1;
                return;
            }
        }
```

接着加入候选位置选择。只从仍固定的平台读取现存格子，因此洞里、被打掉的位置和下落碎片都不会成为新的刷新点。

```csharp
        [Server]
        private bool ServerTryChoosePickupPosition(int layer, out Vector3 position)
        {
            position = Vector3.zero;
            ArenaSceneBootstrap arena = ArenaSceneBootstrap.Instance;
            if (arena == null || layer < 2 ||
                layer >= arena.FloorOrigins.Count ||
                arena.FloorOrigins[layer] == null)
            {
                return false;
            }

            Transform origin = arena.FloorOrigins[layer];
            List<Vector3> candidates = new();
            foreach (PlatformChunk chunk in PlatformChunk.ServerChunks)
            {
                if (chunk == null || !chunk.Anchored ||
                    chunk.RoundId != RoundId || chunk.Layer != layer)
                {
                    continue;
                }

                foreach (int cell in chunk.Cells)
                {
                    Vector3 cellCenter = origin.TransformPoint(PlatformLayout.PositionOf(cell));
                    candidates.Add(cellCenter + origin.up *
                        (PlatformLayout.Thickness * 0.5f + 0.75f));
                }
            }

            while (candidates.Count > 0)
            {
                int index = UnityEngine.Random.Range(0, candidates.Count);
                Vector3 candidate = candidates[index];
                candidates.RemoveAt(index);

                bool occupied = false;
                foreach (ArenaPickup existing in ArenaPickup.ServerPickups)
                {
                    if (existing != null &&
                        Vector3.Distance(existing.transform.position, candidate) < 1f)
                    {
                        occupied = true;
                        break;
                    }
                }

                if (!occupied)
                {
                    position = candidate;
                    return true;
                }
            }

            return false;
        }
```

再加统计和清理方法。销毁道具会修改集合，因此清理时先复制列表。

```csharp
        [Server]
        private int ServerPickupCount(int layer)
        {
            int count = 0;
            foreach (ArenaPickup pickup in ArenaPickup.ServerPickups)
            {
                if (pickup != null && pickup.RoundId == RoundId && pickup.Layer == layer)
                {
                    count++;
                }
            }

            return count;
        }

        [Server]
        private void ServerDestroyPickups()
        {
            foreach (ArenaPickup pickup in new List<ArenaPickup>(ArenaPickup.ServerPickups))
            {
                if (pickup != null)
                {
                    NetworkServer.Destroy(pickup.gameObject);
                }
            }
        }
```

最后补齐玩家查询与出生位置。这三个方法都仍然加入 `ArenaMatch` 类：

```csharp
        [Server]
        private List<ArenaPlayerActions> ServerConnectedPlayers()
        {
            List<ArenaPlayerActions> players = new();
            foreach (ArenaPlayerActions player in ArenaPlayerActions.ServerPlayers)
            {
                if (player != null && player.netId != 0)
                {
                    players.Add(player);
                }
            }

            players.Sort((a, b) => a.netId.CompareTo(b.netId));
            return players;
        }

        [Server]
        private List<ArenaPlayerActions> ServerAlivePlayers()
        {
            List<ArenaPlayerActions> players = new();
            foreach (ArenaPlayerActions player in ServerConnectedPlayers())
            {
                if (player.Alive && player.RoundId == RoundId)
                {
                    players.Add(player);
                }
            }

            return players;
        }
```

`ServerConnectedPlayers` 按 `netId` 排序，使每局分配出生位置的顺序稳定；`ServerAlivePlayers` 在此基础上只留下本局存活玩家。

```csharp
        [Server]
        private Vector3 ServerSpawnPosition(ArenaSceneBootstrap arena, int playerIndex)
        {
            Transform floor = arena.FloorOrigins[0];
            int column = playerIndex % 3;
            int row = playerIndex / 3;
            Vector3 localOffset = new Vector3(
                (column - 1) * PlatformLayout.CellSize,
                0f,
                (row - 1) * PlatformLayout.CellSize);
            Vector3 position = floor.TransformPoint(localOffset);
            position.y = arena.PlayerSpawn != null
                ? arena.PlayerSpawn.position.y
                : floor.position.y + PlatformLayout.Thickness + 1f;
            return position;
        }
```

本章出生位置按中心 3×3 格子展开，供最多九人的小规模验证。`ServerReset` 负责新局状态和网络传送，第 07 章补上的目标 RPC 清理本机运动器速度。

## 6. 编写网络道具

创建 `Assets/Core/Scripts/Gameplay/Mvp/ArenaPickup.cs`：

```csharp file=Assets/Core/Scripts/Gameplay/Mvp/ArenaPickup.cs
using System.Collections.Generic;
using Mirror;
using UnityEngine;

namespace Core.Scripts.Gameplay.Mvp
{
    public sealed class ArenaPickup : NetworkBehaviour
    {
        public static readonly HashSet<ArenaPickup> ServerPickups = new();

        [SyncVar] public uint RoundId;
        [SyncVar] public int Layer;

        [SerializeField] private float collectDistance = 1.25f;
        private float nextCheckAt;

        public override void OnStartServer()
        {
            ServerPickups.Add(this);
        }

        public override void OnStopServer()
        {
            ServerPickups.Remove(this);
        }
    }
}
```

先保存上面的文件骨架，再把下面 `Update` 加到 `ArenaPickup` 类里。它每 `0.2` 秒检查一次附近玩家，只有本局存活者可以拾取。

```csharp
        [ServerCallback]
        private void Update()
        {
            if (Time.time < nextCheckAt)
            {
                return;
            }

            nextCheckAt = Time.time + 0.2f;
            ArenaMatch match = ArenaMatch.Instance;
            if (match == null || match.Phase != ArenaMatchPhase.Playing ||
                match.RoundId != RoundId)
            {
                NetworkServer.Destroy(gameObject);
                return;
            }

            foreach (ArenaPlayerActions player in ArenaPlayerActions.ServerPlayers)
            {
                if (player == null || !player.Alive || player.RoundId != RoundId)
                {
                    continue;
                }

                if (Vector3.Distance(player.transform.position, transform.position) <=
                    collectDistance)
                {
                    // 发放一次使用次数，然后销毁全网共享的道具对象。
                    player.ServerAddCharge();
                    NetworkServer.Destroy(gameObject);
                    return;
                }
            }
        }
```

道具每 0.2 秒在服务器检查一次附近玩家，只给本回合存活玩家增加一个使用次数。每层道具上限为 `Layer - 1`：第三层 1 个、第四层 2 个、第五层 3 个；每隔固定时间最多生成一个。候选位置只从当前回合、仍然锚定的平台 `Cells` 中读取，再用对应 `FloorOrigins[layer]` 和 `PlatformLayout.PositionOf(cell)` 算世界坐标。因此洞、已经挖掉的格子和脱落碎片都不会成为刷出位置。

## 7. 在玩法场景启动 Match

创建 `Assets/Core/Scripts/Gameplay/Mvp/ArenaMatchBootstrap.cs`：

```csharp file=Assets/Core/Scripts/Gameplay/Mvp/ArenaMatchBootstrap.cs
using Mirror;
using UnityEngine;
using UnityEngine.SceneManagement;

namespace Core.Scripts.Gameplay.Mvp
{
    public sealed class ArenaMatchBootstrap : MonoBehaviour
    {
        [SerializeField] private ArenaMatch matchPrefab;

        private ArenaMatch spawnedMatch;
        private bool spawnedOnce;

        private void Update()
        {
            if (spawnedOnce ||
                !NetworkServer.active ||
                matchPrefab == null ||
                ArenaSceneBootstrap.Instance == null ||
                !ArenaSceneBootstrap.Instance.Ready)
            {
                return;
            }

            spawnedOnce = true;
            GameObject instance = Instantiate(matchPrefab.gameObject);
            SceneManager.MoveGameObjectToScene(instance, gameObject.scene);
            spawnedMatch = instance.GetComponent<ArenaMatch>();
            NetworkServer.Spawn(instance);
        }

        private void OnDestroy()
        {
            if (NetworkServer.active && spawnedMatch != null)
            {
                NetworkServer.Destroy(spawnedMatch.gameObject);
            }
        }
    }
}
```

保存三个完整脚本，等待 Unity 编译。然后在 `Assets/Core/Prefabs/Gameplay` 制作两个 Prefab：

1. 在 Hierarchy 创建空物体 `ArenaMatch`，添加 `NetworkIdentity` 和 `ArenaMatch` 组件。
2. 把物体拖入 `Assets/Core/Prefabs/Gameplay` 制成 `ArenaMatch.prefab`，删除场景中的原物体。
3. 创建 Cube，命名为 `ArenaPickup`，Scale 设为 `(0.35, 0.35, 0.35)`。
4. 保留 Mesh Filter 和 Mesh Renderer，移除 Cube 自带的 Box Collider。道具通过服务器计算距离拾取。
5. 添加 `NetworkIdentity` 和 `ArenaPickup` 组件，拖入同一目录制成 `ArenaPickup.prefab`，删除场景中的原物体。
6. 打开 `ArenaMatch.prefab`，把 `ArenaPickup.prefab` 拖入它的 `Pickup Prefab` 字段，保存 Prefab。
7. 打开现有 `Assets/Core/Prefabs/NetworkManager.prefab`，把这两个 Prefab 加入 `Spawnable Prefabs`，与第 04 章的平台 Prefab 放在同一列表，保存。
8. 打开 `Assets/Core/Scenes/MultiplayerSampleScene.unity`，选中第 06 章的 `ArenaSceneBootstrap` 场景物体，添加 `ArenaMatchBootstrap` 组件。
9. 把 `ArenaMatch.prefab` 拖到组件的 `Match Prefab`，保存玩法场景。

`ArenaMatchBootstrap` 只在 `NetworkServer.active` 且五层平台 `Ready` 后生成一个 Match 网络对象。现有 NetworkManager 继续负责连接和玩家生成。

运行时，至少两名玩家进入后开始倒计时；倒计时结束，服务器重建本回合平台并给玩家分配出生点。存活人数降为一人时该玩家获胜，人数为零时平局；结算后进入等待状态，下一局重新开始。游戏进行中进入的玩家保留在场景中作为观战者，下一回合开始时再由 `ServerReset` 加入。

## 8. 分四次观察，不一次追所有逻辑

先启动服务器和两名客户端，确认“等待 → 倒计时 → 进行中”。再让携带者靠近另一人，只观察开局平台整片下落。接着走到第三层拾取道具，按 E 检查格子缺口和库存减一。最后落入虚空，检查淘汰、结算和下一局复位。

如果某一步不符合预期，沿该步对应的方法往下查。例如 E 没有效果，先看 `Charges`，再看 `ServerTryUse` 的阶段与回合条件，最后看射线是否命中当前固定平台。这样每次只需要理解一条短调用链。
