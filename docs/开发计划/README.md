## 先分清三种内容

**当前工程**从 `Assets/Core/Scenes/InitialScene.unity` 启动。拥有者客户端通过 `PlayerCharacterController` 调用 `CharacterMotor` 计算移动，再由 `NetworkTransformReliable` 上行位置和旋转；角色外观与动画走各自的同步入口。实际调用链见 [00 导读](MVP编码教程/00-从当前项目开始.md)。

**MVP 教程**使用 `Assets/MvpTutorial/` 作为动手创建文件的目录，在独立 `MvpArena` 中练习服务器计算、结构断裂与快照显示。带 `csharp file=...` 标记的代码块对应完整文件，组装顺序以主线为准。

**专项设计**按问题提供解释、组件练习和扩展规则。角色接入篇对应现有源码；准备状态、公共机关、投掷预测等篇目通过自己的示例接口演示机制；结构与同步内核篇继续展开规模、预算和预测恢复设计。各篇开头说明与主线的关系。

## 按这条线学习

1. 读 00 导读，打开文中列出的现有脚本，追清一次按键如何变成位置和动画。
2. 写 01—04 章的普通 C# 核心，用第 11 章的控制台程序检查数据、图、编码和恢复。
3. 写 05—09 章的 Unity 文件，按第 10 章组装场景，检查 C# 编译与 Mirror Weaver。
4. 按第 12 章运行服务器和两个客户端，观察破坏、动态支撑、回合、中途加入和恢复。
5. 根据总览的六至八阶段选择玩法与技术扩展，接口问题随时查 API 总览和专项。

具体操作集中在 MVP 主线；总览负责安排范围，API 总览负责选接口，专项负责深入查询，成果文档负责说明实际证据。查正式工程事实时，以源码、资源、运行结果和权威文档为依据。
