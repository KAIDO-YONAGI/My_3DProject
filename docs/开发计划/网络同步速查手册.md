# 网络同步速查手册

Mirror 是项目使用的 Unity 网络框架。本手册集中列出机制选型、工程参数和阅读入口。实施顺序见 [开发计划总览](改造计划总览.md)，完整讲解与示例见 [联机系统教学](联机系统教学/README.md)，工程配置见 [Mirror 与 KCP 工程配置](../../Y_MultipleAgentWorkflow/Project/Mirror_KCP_Config.md)。

## 机制选型

先确定数据的决定者、更新频率、接收范围、丢失后的恢复方式和中途加入所需状态，再选择发送机制。

| 数据用途 | Mirror 机制或业务方案 | 方向与接收范围 | 详细入口 |
| --- | --- | --- | --- |
| 对象上的操作请求 | `Command`，客户端向服务器调用的方法机制 | 客户端上行，服务器校验连接与业务资格 | [角色请求链路](联机系统教学/03-角色切换完整链路.md) |
| 当前角色、生命、分数、回合阶段 | `SyncVar`，Mirror 的同步字段 | 按组件方向与范围发送，初始状态恢复当前值 | [状态与事件](联机系统教学/05-状态与事件的编码.md) |
| 名单、物品与弹药集合 | `SyncList`、`SyncDictionary` 同步列表与字典，`SyncHashSet`、`SyncSortedSet` 同步集合 | 初始完整内容与后续集合变化 | [集合与公共对象](联机系统教学/06-集合公共对象与消息.md) |
| 一次公共表现通知 | `ClientRpc`，面向对象观察者的远程过程调用 | 服务器发给当前就绪观察者，可配置包含拥有者 | [事件参数与范围](联机系统教学/05-状态与事件的编码.md) |
| 单连接提示或请求结果 | `TargetRpc`，面向指定连接的远程过程调用 | 服务器发给目标客户端，对应网络对象承接通知 | [定向通知](联机系统教学/05-状态与事件的编码.md) |
| 按连接收发的独立消息 | `NetworkMessage`，Mirror 的消息接口 | 双向传递，业务层选择连接与认证条件 | [消息完整示例](联机系统教学/06-集合公共对象与消息.md) |
| 组件教学中的连续运动 | `NetworkTransform` 变换同步组件、`NetworkRigidbody` 刚体同步组件 | 按组件方向采样与插值 | [运动同步选择](联机系统教学/08-运动轨迹与同步选择.md) |
| 正式交付的角色与碎片运动 | 自定义批量快照与插值内核，经 Mirror 消息传输 | 服务器采样下行，每连接分配预算与基线 | [独立快照同步内核](联机系统教学/专项设计/独立快照同步内核.md) |
| 地形变更与中途加入 | 结构版本事件、一致世界基线与恢复控制 | 服务器下行，客户端按 Tick 和依赖接续 | [六类网络逻辑](联机系统教学/专项设计/独立快照同步内核.md#六类网络逻辑) |

RPC 是 Remote Procedure Call，指远程过程调用。状态保存当前事实，事件表达一次动作；持续效果用状态或实体恢复，瞬时效果携带播放所需参数。有关联的状态按一致边界采样，同一对象上的组件布局与序列化格式在两端保持匹配。

`SyncDirection` 是 Mirror 组件的同步方向。`ServerToClient` 由服务器发布状态，`ClientToServer` 由拥有者客户端上行、服务器向其他观察者转发。方向按 `NetworkBehaviour` 配置，该类型是 Mirror 的网络组件基类。每项业务数据同时明确最终决定者和校验规则。

`Observers` 是 Mirror 的观察者同步范围，`Owner` 是拥有者同步范围。不同发送范围的数据拆分到相应组件。`NetworkIdentity` 是网络身份组件，`netId` 是本次网络对象生命周期的编号；跨回合和对象复用的业务引用另带回合与代次。

## 当前玩家链路

[NetworkPlayer.prefab](../../Assets/Core/Prefabs/NetworkPlayer.prefab) 保存稳定网络根，客户端按角色编号装配视觉实例。本地角色使用网络根上的运动与碰撞组件，模型、动画和相机在客户端绑定。

| 根组件 | 实际方向 | 数据与处理 |
| --- | --- | --- |
| `NetworkCharacterSync` | `ServerToClient` | 服务器校验角色请求并同步 `characterId` |
| `NetworkTransformReliable`，可靠变换同步组件 | `ClientToServer` | 拥有者上传位置与旋转，服务器和远端按变换快照插值 |
| `NetworkCharacterMovementSync` | `ClientToServer` | 拥有者上传离散状态、二维局部方向和权重，服务器校验、保存并转发 |

本地控制器在 `Update` 读取输入并调用 `CharacterMotor.Tick`，通过 `CharacterController.Move` 更新网络根。运动表现组件在 `LateUpdate` 标记待发送，即使角色静止也持续提供状态，运行时同步间隔为 `0.1` 秒。接收端检查状态枚举、方向长度和权重，远程控制器在 `LateUpdate` 应用最近接受的状态。链路与源码入口见 [玩家移动同步](联机系统教学/04-玩家移动同步.md)。

正式交付按 [开发路线](改造计划总览.md) 实施服务器运动与输入上行，完整运动状态与输入确认下行。本地角色预测与校正、远端插值和碎片运动共用自定义同步内核。

### 连接与发送

KCP 是项目传输组件使用的协议。Mirror 的 `KcpTransport` 在 UDP 上提供可靠与非可靠通道，连接与参数集中查阅工程配置。

| 参数 | 配置或默认值 | 用途 |
| --- | --- | --- |
| 监听端口 | UDP `7777` | 服务器连接入口 |
| 客户端地址 | `127.0.0.1` | 本机调试连接 |
| 自动重连间隔 | `3` 秒 | 客户端重连 |
| KCP `NoDelay`、`Interval` | `true`、`10` 毫秒 | 传输更新 |
| KCP `Timeout` | `10000` 毫秒 | 连接超时 |
| 可靠消息上限 | `297433` 字节 | 传输可承载上限 |
| 非可靠消息上限 | `1194` 字节 | 运动批次分包的传输约束 |
| `NetworkManager.sendRate` | 源码默认 `60` | Mirror 网络发送节奏 |
| `unreliableBaselineRate` | 源码默认 `1` | Mirror 内置非可靠状态同步的可靠基线频率 |
| `unreliableRedundancy` | 源码默认 `false` | Mirror 内置非可靠状态冗余 |
| `exceptionsDisconnect` | 源码默认 `true` | 收发处理异常时的断线策略 |
| 玩法模拟 | 以 `30Hz` 起步 | 独立固定 Tick，按测量调整 |

Mirror 的管理器将 `sendRate` 配置到 `NetworkServer.tickRate`，对应网络发送间隔为发送率的倒数。无界面服务器配置分支同时设置目标帧率。玩法固定 Tick 通过自己的模拟序号和物理入口推进，网络发送、物理步与渲染分别配置。计时算法见 [发送间隔教学](联机系统教学/07-代码生成与序列化.md#7-发送间隔与固定-tick)，源码默认值见 [NetworkManager.cs](../../Assets/Plugins/Mirror/Core/NetworkManager.cs)。

注册网络道具和碎片 Prefab 后，由服务器调用 `NetworkServer.Spawn` 创建网络生命周期，调用 `NetworkServer.Destroy` 销毁。客户端与服务器使用一致的 Prefab 布局和读写格式。包体预算还要计入 Mirror 消息头与传输开销，正式内核的基线与确认由业务协议管理。

## 时间与通道

`NetworkTime` 是 Mirror 的网络时间接口。教学组件使用下表时间；正式内核接收显式时钟输入，并将服务器 Tick 映射到统一播放时间。

| 接口 | 含义与用途 |
| --- | --- |
| `NetworkTime.localTime` | 当前进程未缩放时间，本地等待与超时 |
| `NetworkTime.time` | 缩放网络时间，客户端使用插值播放时间线 |
| `NetworkTime.unscaledTime` | 未缩放网络时间，客户端使用未缩放播放时间线 |
| `NetworkTime.predictedTime` | 面向输入预测的服务器时间估计 |
| `NetworkTime.rtt` | 平均往返时延，RTT 表示 Round Trip Time |

| 通道 | 使用内容 | 接收与恢复 |
| --- | --- | --- |
| 可靠 | 请求结果、结构变更、生命周期、完整恢复控制 | 有序重传，设置队列、分块与流量上限 |
| 非可靠 | 高频运动快照 | 允许丢失，按身份、Tick、基线与周期完整状态恢复 |

爆炸、破裂和碎片运动按同一播放时间呈现。角色校正比较同一确认 Tick，插值误差比较同一播放 Tick。动态支撑重演查询对应 Tick 的碎片历史。时间与差量细节见 [时间轴与插值](联机系统教学/专项设计/独立快照同步内核.md#时间轴与插值)。
