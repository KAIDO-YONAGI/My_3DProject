# 结构破坏与动态碎片

本设计定义结构算法、Unity 物理适配、服务器玩法与动态支撑。实施顺序见 [开发路线](../../00-改造计划总览.md)，消息、快照与恢复规则见 [独立快照同步内核](独立快照同步内核.md)。

## 交付场景与职责

搭建带支柱和桥面的竞技场。爆炸切断连接，失去支撑的区域按连通关系坍塌；碎片撞击玩家、结构和爆炸物，形成连续断裂与连锁爆炸；玩家可在平移和旋转的碎片上移动与跳离。

| 模块 | 输入 | 输出 |
| --- | --- | --- |
| 独立结构核心 | 块、连接、锚点、作用量、稳定编号 | 断裂连接、支撑集合、碎块分组和结构版本 |
| Unity 适配层 | 核心结果、碰撞候选与物理配置 | 几何与遮挡采样、刚体、接触和撞击记录 |
| 玩法模拟 | 操作意图、爆炸与撞击记录 | 伤害、冲量、来源、动态支撑和淘汰 |
| 网络适配 | 权威结构结果与碎片状态 | 业务身份映射、结构事件、快照和恢复基线 |
| 表现层 | 当前结构、运动状态与事件 | 模型、飞屑、声音、动画和调试视图 |

结构核心采用普通 C# 数值、数组和编号，独立测试程序直接调用。定义自己的几何数据或使用测试程序与 Unity 均支持的数值类型，在适配边界转换 Unity 向量。Unity 提供碰撞查询与掉落刚体模拟，结构核心负责断裂与分组。

## 结构数据

采用预先划分的地形块和连接图。每个地形实例保存固定的初始图，回合状态保存当前连接与块归属。

| 数据 | 字段与含义 |
| --- | --- |
| 地形 | `TerrainId`、`StructureVersion`、初始图标识和当前块归属 |
| 块 | 稳定 `BlockId`、局部形状、质量、局部质心和材料 |
| 连接 | 稳定 `EdgeId`、两端块、作用点、剩余强度和有效状态 |
| 支撑 | 锚点块、锚点有效状态和支撑规则 |
| 连通分量 | 分量编号、成员、有效锚点数量和包围范围 |
| 运行归属 | 块属于固定地形或某个碎片，变更时保留 `BlockId` |
| 碎片 | `RoundId + FragmentId + Generation`、成员块、内部连接、姿态和生命周期 |

在初始图内建立块到邻边、块到当前分量、块到运行实体的索引。稳定块编号表达结构身份，运行碎片编号表达本次组合，网络对象编号由接入层关联。

空间索引筛选爆炸半径内的块与连接。核心接收适配层提供的遮挡系数和采样点数值，按配置计算连接作用量。所有列表按稳定编号排序，分组编号由服务器分配。

## 爆炸与连锁作用

一次爆炸保存事件编号、来源事件、初始玩家业务身份、直接触发实体、服务器 Tick、爆心、半径和材料作用参数。

```text
确认引爆条件与事件身份
→ 查询受影响块、连接和碰撞目标
→ 计算距离衰减、遮挡和连接损伤
→ 提交本次连接变化
→ 更新支撑与连通分组
→ 创建或拆分碎片，计算初始冲量
→ 结算玩家伤害、击退与支撑变更
→ 发布结构结果、生命周期和表现事件
```

连接损伤由距离衰减、遮挡系数、爆炸强度和材料响应计算，超过剩余强度时断裂。通过固定采样配置让测试可以重现同一作用结果。玩家伤害与块受力分别使用对应规则。

碰撞回调先生成撞击记录，统一在模拟步骤结算。按实体对、Tick 和作用类型合并重复接触，配置最小冲击阈值、冷却与单 Tick 连锁数量上限。超出当 Tick 预算的已确认触发进入有界待处理队列并保留实际结算 Tick。

引信到期、碰撞和连锁请求共用一次引爆状态转换。事件保存直接触发来源，玩家归属沿配置的有效来源链传递。服务器事件记录保证一次伤害与一次结构提交，客户端播放记录保证一次效果。

## 支撑检测与局部更新

完整算法先从所有有效锚点遍历有效连接，得到受支撑集合，再对剩余块遍历并划分掉落连通分量。该结果作为正确性对照。

局部更新以发生连接变化的原连通分量为边界：

1. 收集变化边的端点及其原分量，将重叠候选合并。
2. 在候选分量内部沿全部有效边遍历，重新划分子分量。
3. 统计每个子分量中的有效锚点，得到固定与掉落分组。
4. 更新块到分量、边到归属和块到碎片的映射。
5. 提交新结构版本，输出有序的断裂边、分组与归属结果。

锚点失效、块移除和连接添加均登记为拓扑变化。连接添加时合并两端的候选分量；跨实体连接通过明确的合并操作处理。每个受影响候选遍历到分量边界，保留与远处锚点的真实连接关系。

用访问代次数组替代反复创建访问集合，复用遍历队列、边列表和分组缓冲。分量包围范围与空间索引用于缩小候选查询。大型单分量断裂时记录实际遍历规模，用性能数据选择进一步优化。

性质验证包括：每块恰有一个归属；分组内节点通过有效边连通；固定分组可达有效锚点；掉落分组完整覆盖失去支撑的块；局部结果与完整遍历的成员集合一致。

## 碎片生成与再次断裂

一个掉落分组对应一个玩法刚体，组合其成员块碰撞体。根据质量与局部位置计算质心，按碎片根变换保持块的世界姿态。定义固定地形、碎片局部坐标和世界坐标的转换接口。

碎片再次受击时，对其内部图执行相同断裂与分组算法。新子碎片继承来源和成员块，分别分配业务身份；旧碎片记录结束 Tick 与替代关系。拆分时按原刚体的质心线速度和角速度计算子碎片初始速度：

```text
子碎片线速度 = 原质心线速度 + 原角速度 × 子质心相对原质心的位移
子碎片角速度 = 原角速度
```

再按爆炸或撞击规则添加冲量。角速度统一使用弧度每秒，姿态、质心与速度在同一坐标系下计算。玩家的稳定接触块用于定位拆分后的新支撑实体。

生命周期统一为：

```text
创建 → 活动 ↔ 休眠 → 销毁
活动或休眠 → 再次断裂 → 子碎片创建与旧碎片结束
```

服务器使用物理状态和配置判定休眠，保存最终姿态；外力、碰撞或规则触发唤醒。销毁条件包含寿命、越界与回合结束。处于有效支撑关系的碎片按玩法规则保留或先发出支撑失效结果。

大块碎片参与碰撞、伤害与站立，服务器维护姿态和生命周期。小石屑、灰尘与火花使用事件位置、时间与随机种子生成本地效果。视觉随机种子统一生成参数，玩法结果取服务器状态。

## 动态支撑

角色支撑状态保存碎片完整身份、稳定接触块、碎片局部接触点、接触法线、接触 Tick、角色相对位置和有效状态。固定地形也通过稳定支撑身份进入同一接触接口。

在 Tick 边界采集支撑前后姿态，利用局部接触点计算世界位移。角色相对行走、支撑平移和支撑旋转在同一运动步骤合成，经角色碰撞适配器执行。接触选择按可站立法线、距离、持续接触和稳定编号排序，配置切换阈值以稳定边缘接触。

```text
接触点世界位置 = 支撑位置 + 支撑旋转 × 局部接触点
接触点速度 = 质心线速度 + 角速度 × 接触点相对质心的位移
跳离速度 = 角色主动速度 + 配置比例 × 接触点速度 + 跳跃速度
```

站立时跟随支撑位移，行走更新局部接触点。跳离在一次状态转换中继承速度并解除支撑。支撑切换保持角色世界位置，再计算新支撑的局部坐标。碎片拆分按 `BlockId` 迁移到对应子碎片；接触块消失、销毁或越界时释放支撑并进入下落规则。

角色根由运动入口写入，支撑引用和局部点显式保存，视觉模型随角色显示。服务器结算接触与受力，角色对碎片施加作用时通过服务器物理规则处理。

## 支撑历史与角色重演

服务器与客户端按 Tick 保存相关碎片的姿态、质心、速度、成员关系、碰撞形状版本、创建拆分销毁边界，以及角色支撑状态。历史按回合与完整对象身份索引，时间范围覆盖输入确认等待和允许的重演窗口。

客户端通过 [同步内核的时间规则](独立快照同步内核.md#时间轴与插值) 构造对应 Tick 的支撑采样。重演 Tick 落在相邻样本之间时插值姿态；样本更新稀疏时使用有界外推，并记录采样来源与误差。形状与身份的离散变化按事件 Tick 生效。

角色校正恢复确认 Tick 的完整状态，再逐 Tick 读取历史支撑与历史碰撞上下文，重演剩余输入。适配器使用隔离的历史碰撞查询对象或显式形状查询，当前显示碎片沿播放时间移动。客户端预测自己的角色，历史上下文由服务器碎片轨迹提供。

本地预测 Tick 通常领先远端播放 Tick。为角色查询单独提供预测时间上的支撑样本，保留采样 Tick 与有界外推范围，画面中本地站立关系使用相同支撑采样建立视觉对齐，记录它与远端播放姿态的差距。通过实验确定支撑显示偏移与校正阈值。

完整的支撑身份、块映射或历史样本缺失时，暂存依赖消息并请求对应恢复数据。超出等待和历史预算时应用新权威基准，重建支撑与输入历史。分组、映射、运动和支撑基线按同一恢复边界提交。

## 网络接入

Mirror 是项目的 Unity 网络框架。`NetworkIdentity` 保存网络身份，`NetworkServer.Spawn` 将服务器创建的对象登记并通知客户端，`NetworkServer.Destroy` 同步网络销毁。

业务碎片身份映射到 Mirror 的运行期 `netId`，组成、结构版本与支撑关系使用业务身份。服务器广播结构结果，客户端据给定分组更新场景；大块碎片快照由独立内核批量发送。对象创建、结构事件与快照跨通道到达时，按身份与 Tick 缓存并接续。

协议字段、预算、回合隔离与中途加入完整恢复统一引用 [六类网络逻辑](独立快照同步内核.md#六类网络逻辑)。Mirror 组件用法与对照练习见 [运动轨迹与同步选择](../08-运动轨迹与同步选择.md) 和 [爆炸物与命中裁决](../10-爆炸物与命中裁决.md)。

| 网络恢复 | 破坏后加入、恢复期再次爆炸、乱序重复、对象未就绪、复用和回合重开 |

固定图规模、连接密度、锚点、爆炸序列、随机种子和设备，记录访问节点边数、算法耗时分位数、分配、物理耗时、活动休眠碎片数和 Tick 总耗时。逐步增加结构与碎片规模，分别测量算法和 Unity 物理。

输出节点连接视图、支撑分组、局部更新范围、接触点和速度向量。保存原始测量数据、配置与复现步骤，用双客户端视频验证同一爆炸链中的结构、伤害与支撑结果。
