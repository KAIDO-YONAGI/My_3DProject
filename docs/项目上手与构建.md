# 项目上手与构建

本文介绍工程依赖、首次运行、多人联调与 Windows 客户端/专用服务器构建。网络参数和场景链路的完整说明见 [Mirror 与 KCP 工程配置](../Y_MultipleAgentWorkflow/Project/Mirror_KCP_Config.md)；服务器运行细节见 [专用服务器](../Y_MultipleAgentWorkflow/Multiplayer/Dedicated_Server.md)。

## 环境与依赖

- Unity Editor：`2022.3.62f3c1`，版本记录在 `ProjectSettings/ProjectVersion.txt`。
- Windows 构建：在 Unity Hub 为该 Editor 安装 Windows Build Support；构建服务器时还需安装 Windows Dedicated Server Build Support。客户端使用 Windows Standalone，服务器使用 Windows Dedicated Server 子目标。
- Unity Package Manager：依赖由 `Packages/manifest.json` 声明，`Packages/packages-lock.json` 锁定解析结果。首次打开时等待 Unity 完成包解析和脚本编译，不要手工重复添加清单中的包。
- Git 包：`com.coplaydev.unity-mcp` 通过 GitHub URL 从 `main` 分支解析，首次解析需要可访问 GitHub。
- 第三方插件：Mirror `96.11.2`、ParrelSync 和 DynamicBone 已放在 `Assets/Plugins/`，随仓库导入，不需要另外下载或导入。
- 输入：工程启用新的 Input System。输入资产位于 `Assets/Core/Input/PlayerControls.inputactions`，不要切换到旧 Input Manager 模式。
- Addressables：配置位于 `Assets/Plugins/AddressableAssetsData/`。当前工程未设置随 Player Build 自动构建 Addressables 内容，首次构建或内容变更后需先手动构建 Addressables。

主要 Unity 包及版本：

|---|---|
| Universal Render Pipeline | `14.0.12` |
| Addressables | `1.22.3` |

## 打开与运行

1. 在 Unity Hub 添加本仓库根目录，使用 `2022.3.62f3c1` 打开。
2. 等待 Package Manager 完成依赖解析，并等待 Console 中脚本编译完成。
3. 打开 `Assets/Core/Scenes/InitialScene.unity` 并进入 Play Mode。该场景会加载常驻层，随后由场景管理器加载玩法场景。
4. 编辑器默认客户端连接地址为 `127.0.0.1`。没有服务器时，常驻场景中的单机角色仍可用于本地移动与相机调试。

Build Settings 已启用并按顺序包含以下五个场景，保持 `InitialScene` 为首个场景：

1. `Assets/Core/Scenes/InitialScene.unity`
2. `Assets/Core/Scenes/PersistentScene.unity`
3. `Assets/Core/Scenes/VoxelArena.unity`
4. `Assets/Core/Scenes/TestScenes/MultiplayerSampleScene.unity`
5. `Assets/Core/Scenes/TestScenes/MultiplayerSampleScene 1.unity`

启动链路为 `InitialScene` 加载 `PersistentScene`，再由常驻层的 `SceneChanger` 以 Additive 模式加载玩法场景。Mirror 的 `onlineScene` 为空，玩法场景切换由 `SceneChanger` 管理。

## 多人联调

1. 先启动 Windows Dedicated Server 构建。服务器由 `HeadlessStartMode=AutoStartServer` 自动启动，并在 UDP `7777` 监听。
2. 客户端连接地址配置在 `Assets/Core/Prefabs/NetworkManager.prefab` 的 `NetworkManager.networkAddress`。本机联调使用 `127.0.0.1`；跨设备联调时填写服务器的局域网 IP，并允许 UDP `7777` 通行。
3. 进入 `InitialScene` 后，客户端自动连接服务器。Mirror 为连接生成 `NetworkPlayer`，角色外观由 `CharacterIdSync` 与 `NetworkCharacterManager` 配置。
4. 在本机运行多个编辑器客户端时，使用 `Assets/Plugins/ParrelSync/` 创建克隆实例，并为各实例分别启动客户端。

网络传输、重连、玩家生成、同步方向与完整配置项见 [Mirror 与 KCP 工程配置](../Y_MultipleAgentWorkflow/Project/Mirror_KCP_Config.md)。

## Addressables 构建

Addressables 的 `BuildAddressablesWithPlayerBuild` 当前为关闭状态。首次构建，或修改 Addressables 内容后：

1. 在 Unity 中打开 `Window > Asset Management > Addressables > Groups`。
2. 确认当前构建平台为 Windows。
3. 在 Addressables Groups 窗口选择 `Build > New Build > Default Build Script`。
4. 确认构建完成后，再构建客户端或专用服务器。

Addressables 使用 `BuildScriptPackedMode`；内容构建目录和配置位置见 [Unity 工程与资产](../Y_MultipleAgentWorkflow/Project/Project_Guide.md) 的 Addressables 一节。

## Windows 构建

客户端与服务器使用相同的 Build Settings 场景清单、`NetworkPlayer` 组件布局和序列化字段。先按上一节生成 Addressables 内容，再分别构建两个目标。

### 客户端

1. 打开 `File > Build Settings`。
2. 选择 `Windows, Mac, Linux` 平台并将 Target Platform 设为 Windows；首次切换时执行 `Switch Platform`。
3. 确认五个场景均已启用，`InitialScene` 排在第一位。
4. 选择 `Build`，将可执行文件输出到 `D:/Unity/Releases/3D_MultiplayerGame/Client/`。

### 专用服务器

1. 在 `File > Build Settings` 中选择 `Dedicated Server` 子目标，并将 Target Platform 设为 Windows。如果列表中没有该目标，在 Unity Hub 为 `2022.3.62f3c1` 安装 Windows Dedicated Server Build Support。
2. 确认五个场景均已启用，`InitialScene` 排在第一位。
3. 选择 `Build`，将可执行文件输出到 `D:/Unity/Releases/3D_MultiplayerGame/Server/`。
4. 启动 `My_3DProject.exe`；服务器启动日志应显示正在监听 UDP `7777`。

输出目录可以按本机环境调整。服务器启动模式、监听与玩家生成流程见 [专用服务器](../Y_MultipleAgentWorkflow/Multiplayer/Dedicated_Server.md)。

## 网络与角色配置

| 配置项 | 当前设置 | 配置入口 |
|---|---|---|
| Transport | `kcp2k.KcpTransport` | `NetworkManager.prefab` |
| 服务器端口 | UDP `7777` | `KcpTransport.Port` |
| 客户端地址 | `127.0.0.1` | `NetworkManager.networkAddress` |
| 玩家 Prefab | `NetworkPlayer.prefab` | `NetworkManager` |
| 自动创建玩家 | 开启 | `NetworkManager` |
| 出生点模式 | `Random` | `NetworkManager` |
| 位置同步方向 | `ClientToServer` | `NetworkTransformReliable` |
| 自动重连间隔 | `3` 秒 | `AutoStartClient` |
| Mirror onlineScene | 留空 | `NetworkManager` |

`NetworkManager.prefab` 组合 Mirror `NetworkManager`、`NetworkManagerHUD`、`KcpTransport` 与 `AutoStartClient`。`NetworkPlayer.prefab` 是稳定的网络根节点，包含 `NetworkIdentity`、`NetworkTransformReliable`、`CharacterController`、`PlayerCharacterController` 与 `CharacterIdSync`。

角色外观资源位于 `Assets/Core/Prefabs/Characters/`，模型源文件位于 `Assets/Core/Models/`：

| 角色编号 | 完整角色 Prefab | 模型源文件目录 |
|---|---|---|
| `0` | `娜娜莉（华丽飞踢）.prefab` | `异环_娜娜莉（华丽飞踢）/` |
| `1` | `娜娜莉（学园之星）.prefab` | `异环_娜娜莉（学园之星）/` |

两个角色的 Prefab 路径均在 `Assets/Core/Prefabs/Characters/` 下，模型目录均在 `Assets/Core/Models/` 下。默认角色编号为 `1`。完整角色 Prefab 提供 `Camera`、`AudioListener`、`ThirdPersonCamera`、`Animator`、`CharacterController`、`DynamicBone` 与 `PlayerCharacterController`；联机时本地与远程玩家共用角色资源，并按身份启停相机、输入和控制器。详细装配规则见 [角色系统](../Y_MultipleAgentWorkflow/Character/Character_Guide.md)。
