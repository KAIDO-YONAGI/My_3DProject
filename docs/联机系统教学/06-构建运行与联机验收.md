# 构建、运行与联机验收

## 1. 构建前配置

### Build Settings

启用并按以下顺序排列：

1. `Assets/Core/Scenes/InitialScene.unity`
2. `Assets/Core/Scenes/PersistentScene.unity`
3. `Assets/Core/Scenes/MultiplayerSampleScene.unity`

### NetworkManager

打开 `Assets/Core/Prefabs/NetworkManager.prefab`，检查：

```text
Transport = KcpTransport
networkAddress = 127.0.0.1
playerPrefab = Player_Network.prefab
autoCreatePlayer = true
playerSpawnMethod = Random
onlineScene = 空
offlineScene = 空
headlessStartMode = AutoStartServer
```

### KcpTransport

```text
Port = 7777
DualMode = true
NoDelay = true
Interval = 10
Timeout = 10000
FastResend = 2
SendWindowSize = 4096
ReceiveWindowSize = 4096
MaxRetransmit = 40
```

### Player_Network

根对象包含：

```text
NetworkIdentity
NetworkTransformReliable
CharacterController
PlayerCharacterController
NetworkCharacterSync
```

`NetworkTransformReliable.SyncDirection` 为 `ClientToServer`。

### NetworkCharacterManager

检查：

- `localCharacterPrefabs` 全部引用 `CharactersForLocal`。
- `characterPrefabs` 全部引用 `CharactersForSync`。
- 两套数组长度一致。
- 相同下标表示同一角色。
- `defaultCharacterId=1`。

## 2. 构建输出

客户端输出根目录：

`D:/Unity/Releases/3D_MultiplayerGame/Client/`

专用服务器输出根目录：

`D:/Unity/Releases/3D_MultiplayerGame/Server/`

客户端与服务器需要使用相同的场景、`Player_Network` 组件布局、NetworkBehaviour 顺序和角色数组配置。

## 3. 启动专用服务器

Windows Server 构建启动后，`HeadlessStartMode=AutoStartServer` 会调用 `NetworkManager.StartServer`。

日志中的关键链路：

```text
NetworkServer.Listen
KcpTransport.ServerStart
KcpServer.Start
UDP 7777 listening
```

可以用 PowerShell 检查端口：

```powershell
Get-NetUDPEndpoint -LocalPort 7777
```

输出中出现本地 UDP `7777` 表示服务端 socket 已绑定。

## 4. 双编辑器连接

两个 Unity 编辑器都打开构建入口或当前常驻开发场景并进入 Play。

`AutoStartClient` 在每个编辑器中执行：

```text
127.0.0.1:7777
  → KCP 握手
  → Mirror Connected
  → Ready
  → AddPlayer
```

服务端收到两个连接后创建两个 `Player_Network`。每个编辑器都接收这两个网络对象。

## 5. 角色数量验收

两名客户端连接时，每个编辑器中应形成：

```text
Player_Network(Clone) 本地拥有者
  └─ 名称带 LocalCharacter 的本地角色表现

Player_Network(Clone) 远程玩家
  └─ 名称带 RemoteCharacter 的同步角色表现
```

同时检查：

- `PersistentScene` 中的单机 `LocalPlayer` 处于关闭状态。
- 每个 `Player_Network` 下面只有一个当前角色表现。
- 网络根数量等于服务端连接玩家数量。
- 专用服务器保存两个服务端玩家对象，不运行本地相机和输入。

场景中出现三个人物时，检查第三个对象的父级：

- 父级存在 `NetworkIdentity`，它属于 Mirror 玩家。
- 父级没有 `NetworkIdentity`，它属于场景单机角色。

联机状态下，场景单机角色由 `NetworkCharacterManager.ApplyPresentationMode` 关闭。

## 6. 相机验收

每个客户端检查：

1. 本地拥有者角色表现中的 Camera 已启用。
2. Camera 的 Tag 为 `MainCamera`。
3. `ThirdPersonCamera` 已启用。
4. `AudioListener` 已启用。
5. 网络根 `PlayerCharacterController.inputSpace` 指向这台 Camera。
6. 远程角色表现中的 Camera、`ThirdPersonCamera` 和 `AudioListener` 处于关闭状态。
7. 场景 `LocalPlayer` 相机处于关闭状态。
8. MultiplayerSampleScene 的 Camera 保持停用。

Game 视图显示 `No cameras rendering` 时，按以上顺序检查本地玩家是否已经完成角色装配，以及 `ConfigureLocalCamera` 是否获得了本地角色 Prefab 中的 Camera。

## 7. 移动方向验收

1. 水平旋转本地相机。
2. 按前进键。
3. 观察网络根移动方向。
4. 确认移动方向沿相机水平 forward。
5. 在另一个客户端观察同一玩家的远程位置与动画。

关键引用：

```text
NetworkCharacterManager
  → RebindInputSpace(localCamera.transform)
  → CharacterMotor.ResolveMoveDirection
```

## 8. 高度与物理验收

1. 确认 MultiplayerSampleScene 已加载。
2. 确认 TerrainCollider 已启用。
3. 确认网络根 `CharacterController` 已启用。
4. 确认视觉子对象的 `CharacterController` 已停用。
5. 观察玩家从 Spawn Transform 进入重力过程。
6. 落地后检查 `CharacterController.isGrounded`。
7. 观察网络根和远程副本高度保持一致。

落地过程由 `CharacterMotor`、`CharacterController.Move` 和 TerrainCollider 完成。网络同步复制运动结果。

## 9. 角色切换验收

对本地拥有者调用：

```csharp
networkCharacterSync.SetLocalCharacter(characterId);
```

检查：

1. 服务端接受并更新 `characterId`。
2. 本地客户端切换到 `localCharacterPrefabs[id]`。
3. 远程客户端切换到 `characterPrefabs[id]`。
4. 旧角色表现被销毁。
5. 新角色表现挂到同一个 `Player_Network`。
6. 本地 Camera 继续启用。
7. 网络根继续保持原有位置与所有权。

## 10. 构建客户端验收

启动一个专用服务器和两个构建客户端：

1. 两个客户端连接 `127.0.0.1:7777`。
2. 每端显示两个网络角色。
3. 每端只有一台本地 Camera。
4. 移动方向随相机变化。
5. 远程位置与动画同步。
6. 角色依靠重力和地形碰撞落地。
7. 角色切换在两端显示同一角色编号对应的不同表现 Prefab。

## 11. 日志定位

| 现象 | 检查入口 |
|---|---|
| 服务端没有监听 | `KcpServer.Start`、UDP `7777`、端口占用 |
| 客户端持续重试 | `AutoStartClient` 地址、KCP 端口、服务端进程 |
| 连接成功后没有玩家 | Ready、AddPlayer、`NetworkManager.playerPrefab` |
| 有网络根但没有模型 | `NetworkCharacterSync.OnStartClient`、角色数组编号 |
| 本地显示同步 Prefab | `NetworkIdentity.isLocalPlayer` 与装配时序 |
| 多一个场景角色 | `ApplyPresentationMode` 与场景 `LocalPlayer` |
| Game 视图没有相机 | 本地 Prefab Camera 与 `ConfigureLocalCamera` |
| 相机转动不改变前进 | `inputSpace` 与 `ResolveMoveDirection` |
| 角色悬空 | Spawn Transform、TerrainCollider、CharacterController 和模型原点 |
| 反序列化长度异常 | 客户端与服务器的 NetworkBehaviour 布局和字段 |
