# 移动、相机与物理

## 1. 运行时组件分工

```text
PlayerCharacterController
  → 读取输入
  → CharacterMotor
      → 计算方向
      → 计算水平速度
      → 计算重力与跳跃
      → CharacterController.Move
  → CharacterMotion
  → CharacterAnimator

ThirdPersonCamera
  → 读取鼠标
  → 计算 yaw 与 pitch
  → 跟随网络根
  → 处理镜头碰撞
```

网络同步发生在 `Player_Network` 根。角色视觉作为子对象跟随根 Transform。

## 2. PlayerCharacterController.cs

路径：

`Assets/Core/Scripts/Movement/Runtime/PlayerCharacterController.cs`

### 输入归属

`Update` 先判断运行环境：

- 专用服务器上的网络玩家不运行输入、重力和动画驱动。
- 客户端连接后，仅 `NetworkIdentity.isLocalPlayer=true` 的玩家读取输入。
- 没有 `NetworkIdentity` 的单机角色继续运行相同移动逻辑。

这使单机角色和网络本地角色共用同一套移动代码。

### 输入内容

`ReadInput` 从 Unity Input Manager 读取：

- `Horizontal`
- `Vertical`
- 左右 Shift
- Space

二维移动向量使用 `ClampMagnitude` 限制为单位长度，斜向输入不会获得额外速度。

### RebindInputSpace

网络角色装配完成后，`NetworkCharacterManager` 将本地 Camera Transform 传给：

```csharp
PlayerCharacterController.RebindInputSpace
```

远程玩家传入 `null`。远程玩家本身不读取输入。

### RebindAnimator

角色表现创建或切换后，网络根通过 `RebindAnimator` 使用新模型的 Animator，并复制该角色的动画素材配置。

## 3. CharacterMotor.cs

路径：

`Assets/Core/Scripts/Movement/Runtime/CharacterMotor.cs`

### 相机方向转换

`ResolveMoveDirection` 按以下顺序选择方向基准：

1. 显式绑定的 `inputSpace`。
2. `Camera.main`。
3. 角色根自身朝向。

有本地 Camera 时，代码把相机 forward 和 right 投影到水平面：

```text
forward = 相机 forward 在水平面的投影
right = 相机 right 在水平面的投影
direction = forward * Vertical + right * Horizontal
```

因此相机水平旋转会直接改变角色前进方向。相机俯仰不会把前进输入变成向上或向下移动。

### 水平速度

目标速度来自 `CharacterMovementSettings`：

- 运行速度 `6.8`
- 疾跑速度 `10.8`
- 加速度 `32`
- 减速度 `38`
- 空中控制倍率 `0.45`

`Vector3.MoveTowards` 让当前水平速度向目标水平速度变化。

### 重力与跳跃

当前配置：

- Gravity `-28`
- JumpHeight `1.2`
- GroundedPull `-2`

每帧流程：

1. 读取移动前的 `CharacterController.isGrounded`。
2. 接地且竖直速度向下时设置 GroundedPull。
3. 接地并按下跳跃时计算起跳速度。
4. 叠加重力。
5. 组合水平速度和竖直速度。
6. 调用 `CharacterController.Move`。
7. 根据 `CollisionFlags.Above` 和 `CollisionFlags.Below` 修正竖直速度。

### CharacterController.Move

最终位移只有这一条路径：

```csharp
characterController.Move(frameMotion)
```

`CharacterController` 根据地形和其他 Collider 约束结果，返回本帧碰撞标志。

## 4. 高度与落地

网络玩家从 `NetworkStartPosition` 生成。生成后，本地拥有者运行 `CharacterMotor`，重力将角色向下移动，TerrainCollider 提供地面碰撞。

落地高度由以下配置共同决定：

- Spawn Transform 位置。
- Terrain 高度。
- TerrainCollider。
- `CharacterController.center`。
- `CharacterController.height`。
- `CharacterController.radius`。
- `CharacterController.skinWidth`。
- GroundedPull。

当前网络根的 `CharacterController`：

```text
height = 2
radius = 0.5
center = (0, 1, 0)
slopeLimit = 45
stepOffset = 0.3
skinWidth = 0.08
```

视觉子对象局部位置为零。模型原点和脚底的资源偏移决定画面中的脚底位置，网络根和 `CharacterController` 决定实际碰撞位置。

角色正常移动与落地过程不调用 Transform 传送，也不按固定 Y 值钳制高度。场景切换时 `SceneChanger` 会执行一次目标场景初始位置设置，这属于场景装载定位。

## 5. ThirdPersonCamera.cs

路径：

`Assets/Core/Scripts/Movement/Runtime/ThirdPersonCamera.cs`

### SetTarget

本地角色表现装配时，管理器把相机跟随目标设置为 `Player_Network` 根。视觉模型切换后，相机继续跟随同一个网络根。

### 轨道输入

鼠标输入更新：

- yaw
- pitch
- distance

pitch 受最小和最大角度限制，滚轮调整镜头距离。

### 角色朝向

`rotateTarget=true` 且存在移动输入时，ThirdPersonCamera 使用 yaw 构造水平旋转，并平滑设置目标根的朝向。

角色朝向和移动方向使用同一个相机 yaw 来源：

- `ThirdPersonCamera` 用 yaw 转动网络根。
- `CharacterMotor` 用 Camera Transform 计算前进和右方向。

### 镜头碰撞

相机从角色焦点向后执行 `SphereCastNonAlloc`：

- 忽略角色自身 Collider。
- 找到最近障碍物距离。
- 缩短实际镜头距离。
- 使用 `minHeightY` 维持最低镜头高度。
- 使用 `SmoothDamp` 平滑相对偏移。

## 6. Camera.main 与 inputSpace

联机场景中可能同时存在：

- 场景单机 Camera。
- 本地网络角色 Camera。
- 远程资源中的 Camera 组件。
- Additive 玩法场景 Camera。

`NetworkCharacterManager` 会把本地拥有者 Camera 标记为 `MainCamera`，并显式绑定给网络根的 `inputSpace`。移动计算优先使用这个显式引用，因此前进方向不会依赖相机查找顺序。

## 7. 远程玩家

远程网络根不执行本地输入和 `CharacterMotor.Tick`。位置由 `NetworkTransformReliable` 插值应用。

远程动画读取网络根的帧间位移。远程视觉实例上的 `CharacterController` 和 `PlayerCharacterController` 已停用，因此它不会产生额外重力、碰撞或输入。

## 8. 本地相机启用规则

只有 `isLocalPlayer=true` 的角色表现启用：

- Camera
- AudioListener
- ThirdPersonCamera

单机状态启用 `LocalPlayer` 相机。联机状态关闭场景单机相机。Additive 场景加载完成后，管理器再次执行相机收拢。

## 9. 运行检查

### 相机方向

1. 连接服务端。
2. 找到本地 `Player_Network`。
3. 确认 `PlayerCharacterController.inputSpace` 指向本地角色 Camera。
4. 水平旋转相机。
5. 按前进键。
6. 角色沿相机水平 forward 移动。

### 物理落地

1. 确认玩法场景 TerrainCollider 已加载。
2. 确认网络根 `CharacterController.enabled=true`。
3. 确认视觉子对象 `CharacterController.enabled=false`。
4. 观察角色生成后的竖直移动。
5. 接地后 `isGrounded` 保持稳定。

### 角色数量与相机

1. 两个编辑器连接同一服务端。
2. 每端出现两个 `Player_Network`。
3. 每个网络根下面有一个角色表现。
4. 场景 `LocalPlayer` 在联机状态关闭。
5. 每端只有一个 Camera 和一个 AudioListener 处于启用状态。
