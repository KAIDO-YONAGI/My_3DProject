# 代码文件索引

本索引按运行调用链排列。每个条目说明文件入口、关键部分和它交给下一层的数据。

## 1. 场景框架

### InitialLoad.cs

路径：`Assets/FrameWork/Scripts/Scene/InitialLoad.cs`

- `Awake` 注册 Persistent Scene。
- `LoadPersistentScenes` 以 Additive 模式加载常驻场景。
- 输出是已经进入运行时的 `PersistentScene`。

### PersistentSceneRegistry.cs

路径：`Assets/FrameWork/Scripts/Scene/PersistentSceneRegistry.cs`

- `Register` 保存常驻场景名。
- `IsPersistent` 供场景卸载流程判断。
- `SubsystemRegistration` 时清空静态集合。

### SceneChanger.cs

路径：`Assets/FrameWork/Scripts/Scene/SceneChanger.cs`

- `Start` 请求加载首个玩法场景组。
- `RequestSceneLoad` 先广播事件，再执行加载。
- `UnloadCurrentScenes` 跳过已注册的常驻场景。
- `LoadScenesRoutine` 以 Additive 模式加载玩法场景。
- `SetPlayerPostion` 在场景加载阶段设置单机角色初始位置。
- `OnLoadCompleted` 广播完成事件并恢复输入。

### TimeManager.cs

路径：`Assets/FrameWork/Scripts/Scene/TimeManager.cs`

- 为场景切换提供暂停与恢复。
- `SceneChanger` 在加载窗口内调用它管理时间状态。

## 2. 项目网络脚本

### AutoStartClient.cs

路径：`Assets/Core/Scripts/Networking/AutoStartClient.cs`

- `Update` 检查进程类型和 Mirror 活动状态。
- 设置连接地址。
- 调用 `NetworkManager.StartClient`。
- 用 `reconnectInterval` 控制重试。
- `GetTransportPort` 从活动 KcpTransport 读取诊断端口。

### NetworkCharacterSync.cs

路径：`Assets/Core/Scripts/Networking/NetworkCharacterSync.cs`

- `characterId` 是服务器同步的 `SyncVar`。
- `OnStartServer` 设置默认角色编号。
- `OnStartClient` 应用初始角色表现。
- `OnStartLocalPlayer` 确认本地拥有者表现。
- `SetLocalCharacter` 是本地角色切换入口。
- `CmdSetCharacter` 在服务器校验并写入角色编号。
- `OnCharacterIdChanged` 处理同步变化。
- `OnStopClient` 移除视觉实例。

### NetworkCharacterManager.cs

路径：`Assets/Core/Scripts/Networking/NetworkCharacterManager.cs`

- `localCharacterPrefabs` 保存本地拥有者完整角色。
- `characterPrefabs` 保存远程同步角色。
- `IsValidCharacterId` 确认编号可在两套数组解析。
- `ApplyCharacter` 选择 Prefab、创建实例、关闭重复控制器并绑定 Animator。
- `RemoveCharacter` 清理旧模型、相机输入引用和 Animator 引用。
- `ConfigureLocalCamera` 只启用本地拥有者的 Camera、AudioListener 和 ThirdPersonCamera。
- `SetStandalonePlayerEnabled` 切换场景单机角色。
- `SetStandaloneCameraEnabled` 切换场景单机相机。
- `HandleSceneLoaded` 在 Additive 场景加载后重新应用表现模式。

## 3. 项目移动脚本

### CharacterInput.cs

路径：`Assets/Core/Scripts/Movement/Runtime/CharacterInput.cs`

- 保存一帧移动向量、疾跑状态和跳跃按下状态。
- `PlayerCharacterController` 创建，`CharacterMotor` 消费。

### CharacterMotion.cs

路径：`Assets/Core/Scripts/Movement/Runtime/CharacterMotion.cs`

- 保存接地、疾跑、局部方向和移动权重。
- `CharacterMotor` 或远程位移分析创建，`CharacterAnimator` 消费。

### PlayerCharacterController.cs

路径：`Assets/Core/Scripts/Movement/Runtime/PlayerCharacterController.cs`

- `Update` 执行输入归属检查、输入读取、移动和本地动画。
- `LateUpdate` 根据网络位移驱动远程动画。
- `EnsureRuntimeState` 建立 CharacterMotor 与 CharacterAnimator。
- `RebindAnimator` 将网络根连接到当前视觉模型 Animator。
- `RebindInputSpace` 将网络根连接到本地 Camera 朝向。
- `ReadInput` 读取 Horizontal、Vertical、Shift 和 Space。

### CharacterMotor.cs

路径：`Assets/Core/Scripts/Movement/Runtime/CharacterMotor.cs`

- `Tick` 执行方向、速度、跳跃、重力、碰撞位移和动画快照。
- `ResolveMoveDirection` 将输入转换到 Camera 水平坐标。
- `RotateTowards` 在移动朝向配置启用时转动角色。
- 最终通过 `CharacterController.Move` 移动网络根。

### CharacterAnimator.cs

路径：`Assets/Core/Scripts/Movement/Runtime/CharacterAnimator.cs`

- 创建和维护 AnimatorOverrideController。
- 将当前角色的 Idle、Run、Sprint 和 Jump 动画填入通用控制器。
- `Apply` 根据 CharacterMotion 设置 Animator 参数。
- `Dispose` 释放运行时动画覆盖器。

### CharacterBoneFollower.cs

路径：`Assets/Core/Scripts/Movement/Runtime/CharacterBoneFollower.cs`

- 保存角色视觉骨骼跟随配置。
- `Initialize` 绑定 Animator 骨骼。
- `Apply` 在 LateUpdate 阶段应用跟随结果。
- 角色切换时从视觉控制器复制配置。

### ThirdPersonCamera.cs

路径：`Assets/Core/Scripts/Movement/Runtime/ThirdPersonCamera.cs`

- `SetTarget` 将跟随对象绑定到网络根。
- `ReadOrbitInput` 更新 yaw、pitch 和 distance。
- `UpdateTransform` 计算相机位置与旋转。
- `ResolveDistance` 用 SphereCast 处理镜头障碍。
- 移动输入存在时用 yaw 平滑旋转网络根。

### CharacterMovementSettings.cs

路径：`Assets/Core/Scripts/Movement/Config/CharacterMovementSettings.cs`

- 保存运行、疾跑、加速、减速、空中控制、旋转、重力、跳跃和接地吸附参数。
- `GetTargetSpeed` 返回当前目标速度。
- `GetJumpSpeed` 根据重力和跳跃高度计算起跳速度。

### DirectionalAnimationSet.cs

路径：`Assets/Core/Scripts/Movement/Config/DirectionalAnimationSet.cs`

- 保存一个移动状态的方向动画集合。
- 为前后左右和斜向移动提供动画映射。

### DirectionalAnimationSample.cs

路径：`Assets/Core/Scripts/Movement/Config/DirectionalAnimationSample.cs`

- 保存一个方向采样与对应 AnimationClip。
- 供 DirectionalAnimationSet 选择最接近当前移动方向的动画。

### CharacterJumpAnimationSet.cs

路径：`Assets/Core/Scripts/Movement/Config/CharacterJumpAnimationSet.cs`

- 保存跳跃阶段需要的动画资源。
- 由 CharacterAnimator 写入 AnimatorOverrideController。

## 4. Mirror Transport

### Transport.cs

路径：`Assets/Mirror/Core/Transport.cs`

- 定义客户端和服务器传输接口。
- 定义连接、数据、断开和错误事件。
- KcpTransport 通过这些接口接入 Mirror。

### PortTransport.cs

路径：`Assets/Mirror/Core/PortTransport.cs`

- 为支持端口配置的 Transport 提供统一的 `Port` 属性。
- KcpTransport 实现该接口。
- NetworkManagerHUD 通过该接口读取和修改监听端口。

### KcpTransport.cs

路径：`Assets/Mirror/Transports/KCP/KcpTransport.cs`

- `Awake` 创建 KcpConfig、KcpClient 和 KcpServer。
- 将 kcp2k 回调转换为 Mirror Transport 事件。
- `ClientConnect` 与 `ServerStart` 是连接和监听入口。
- EarlyUpdate 处理接收。
- LateUpdate 处理发送。

## 5. kcp2k 高层

### KcpConfig.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpConfig.cs`

- 保存 socket 与 KCP 参数。
- 客户端和服务器以同一结构初始化连接。

### KcpClient.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpClient.cs`

- `Connect` 创建并连接 UDP socket。
- `RawReceive` 与 `RawSend` 操作客户端 socket。
- `RawInput` 解析通道与 Cookie。
- `TickIncoming` 接收当前帧数据。
- `TickOutgoing` 刷新发送。

### KcpServer.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpServer.cs`

- `Start` 创建 UDP socket 并绑定端口。
- `RawReceiveFrom` 接收数据与远端端点。
- `CreateConnection` 为通过握手的端点创建连接。
- `TickIncoming` 处理 socket 和所有连接。
- `TickOutgoing` 刷新所有连接。

### KcpServerConnection.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpServerConnection.cs`

- 表示服务器侧的一个客户端。
- 保存 connectionId、Cookie 与独立 KCP 状态。
- 通过服务器共享 socket 向自己的远端端点发送。

### KcpPeer.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpPeer.cs`

- `Reset` 建立低层 Kcp 对象。
- `SendHello` 发起握手。
- `SendReliable` 将可靠数据交给 KCP。
- `SendUnreliable` 直接生成 UDP 数据报。
- `OnRawInputReliable` 与 `OnRawInputUnreliable` 处理通道数据。
- `TickIncoming` 处理 KCP 状态、超时和收到的数据。
- `TickOutgoing` 处理 Ping 和发送刷新。

### KcpHeader.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpHeader.cs`

- 定义可靠与非可靠通道使用的 Hello、Data、Ping、Disconnect 头。

### KcpChannel.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpChannel.cs`

- 区分可靠与非可靠数据通道。

### KcpState.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/KcpState.cs`

- 表达连接的握手、认证、连接和断开状态。

### Common.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/highlevel/Common.cs`

- 保存通道头尺寸、Cookie 尺寸和消息尺寸计算。

## 6. KCP 算法

### Kcp.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/kcp/Kcp.cs`

- `Send` 分片并加入发送队列。
- `Input` 解析 ACK、窗口与数据 Segment。
- `Update` 根据时间推进 KCP。
- `Flush` 生成确认、窗口探测、数据和重传。

### Segment.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/kcp/Segment.cs`

- 保存分片数据、序号、确认状态、发送时间和重传信息。

### AckItem.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/kcp/AckItem.cs`

- 保存待发送 ACK 的序号与时间戳。

### Pool.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/kcp/Pool.cs`

- 复用 KCP 数据结构，降低持续收发产生的分配。

### Utils.cs

路径：`Assets/Mirror/Transports/KCP/kcp2k/kcp/Utils.cs`

- 提供时间和低层数值辅助。

## 7. Mirror 连接与对象

### NetworkManager.cs

路径：`Assets/Mirror/Core/NetworkManager.cs`

- `StartServer` 建立服务器。
- `StartClient` 建立客户端。
- `OnClientConnect` 发送 Ready 和 AddPlayer。
- `GetStartPosition` 选择出生点。
- `OnServerAddPlayer` 创建 Player_Network。

### NetworkManagerHUD.cs

路径：`Assets/Mirror/Core/NetworkManagerHUD.cs`

- 在运行画面中提供 Host、Client 和 Server 控制入口。
- 显示当前客户端与服务器状态。
- 客户端进入 Ready 状态后提供 Add Player 入口。
- 通过 PortTransport 显示和修改活动传输层端口。

### NetworkClient.cs

路径：`Assets/Mirror/Core/NetworkClient.cs`

- `Connect` 调用活动 Transport。
- `Ready` 告知服务器客户端已进入世界。
- `AddPlayer` 请求创建玩家。
- `OnSpawn` 处理网络对象生成。
- `ApplySpawnPayload` 应用身份、Transform、所有权和初始状态。
- `OnEntityStateMessage` 处理运行时状态。

### NetworkServer.cs

路径：`Assets/Mirror/Core/NetworkServer.cs`

- `Listen` 启动 Transport 监听。
- `AddPlayerForConnection` 将玩家绑定到连接。
- `Spawn` 分配 netId 并发送对象生成数据。
- 服务端状态同步在这里按观察者发送。

### NetworkConnection.cs

路径：`Assets/Mirror/Core/NetworkConnection.cs`

- 提供消息发送、批处理、时间戳和连接基础状态。

### NetworkConnectionToServer.cs

路径：`Assets/Mirror/Core/NetworkConnectionToServer.cs`

- 表示客户端到服务器的连接。
- 将客户端消息交给活动 Transport。

### NetworkConnectionToClient.cs

路径：`Assets/Mirror/Core/NetworkConnectionToClient.cs`

- 表示服务器保存的一个客户端连接。
- 保存 Ready、玩家 identity、owned 对象和快照缓冲信息。

### NetworkMessages.cs

路径：`Assets/Mirror/Core/NetworkMessages.cs`

- 定义 Ready、AddPlayer、Spawn、EntityState 和 Command 等核心消息结构。

### NetworkIdentity.cs

路径：`Assets/Mirror/Core/NetworkIdentity.cs`

- 保存 netId、所有权和 NetworkBehaviour 列表。
- 调用服务器、客户端、本地玩家与权限生命周期。
- 按组件顺序序列化和反序列化状态。

### NetworkBehaviour.cs

路径：`Assets/Mirror/Core/NetworkBehaviour.cs`

- 提供网络身份快捷属性。
- 提供 SyncVar 脏位和序列化入口。
- 提供 Command 与 Rpc 发送基础。
- 定义 NetworkBehaviour 生命周期。

### NetworkStartPosition.cs

路径：`Assets/Mirror/Core/NetworkStartPosition.cs`

- 将所在 Transform 注册到 NetworkManager 出生点列表。

Mirror Weaver 在编译阶段为 `[SyncVar]`、`[Command]` 和序列化字段生成调用代码。`NetworkCharacterSync` 的角色编号与 Command 因此可以进入 Mirror 消息链路。

## 8. Mirror 变换同步

### NetworkTransformBase.cs

路径：`Assets/Mirror/Components/NetworkTransform/NetworkTransformBase.cs`

- 保存同步字段配置。
- 保存客户端和服务器快照缓冲。
- `Construct` 读取当前 Transform。
- `AddSnapshot` 将收到状态加入有序缓冲。
- `Apply` 将插值结果写入目标 Transform。

### NetworkTransformReliable.cs

路径：`Assets/Mirror/Components/NetworkTransform/NetworkTransformReliable.cs`

- `LateUpdate` 检查变换变化并驱动同步。
- `OnSerialize` 写入初始状态或增量状态。
- `OnDeserialize` 读取变换字段。
- `OnClientToServerSync` 接收本地拥有者快照。
- `OnServerToClientSync` 接收服务器广播快照。
- 通过快照缓冲对位置和旋转进行插值。

### TransformSnapshot.cs

路径：`Assets/Mirror/Components/NetworkTransform/TransformSnapshot.cs`

- 保存时间、位置、旋转和缩放。
- 提供两个快照之间的插值。

### TransformSyncData.cs

路径：`Assets/Mirror/Components/NetworkTransform/TransformSyncData.cs`

- 表达一次变换同步中包含的字段。
- 支持位置、旋转和缩放的选择性序列化。

## 9. 端到端文件顺序

一次客户端移动同步经过：

```text
PlayerCharacterController.cs
  → CharacterMotor.cs
  → Unity CharacterController
  → NetworkTransformReliable.cs
  → NetworkIdentity.cs
  → NetworkConnectionToServer.cs
  → KcpTransport.cs
  → KcpClient.cs
  → KcpPeer.cs
  → Kcp.cs
  → UDP socket

UDP socket
  → KcpServer.cs
  → KcpServerConnection.cs
  → KcpPeer.cs
  → KcpTransport.cs
  → NetworkServer.cs
  → NetworkIdentity.cs
  → NetworkTransformReliable.cs
  → 其他客户端
```

一次角色切换经过：

```text
NetworkCharacterSync.SetLocalCharacter
  → NetworkBehaviour Command
  → NetworkConnectionToServer
  → KcpTransport
  → UDP 与 KCP
  → NetworkServer
  → NetworkIdentity
  → NetworkCharacterSync.CmdSetCharacter
  → SyncVar characterId
  → Entity State
  → 各客户端 NetworkCharacterSync.OnCharacterIdChanged
  → NetworkCharacterManager.ApplyCharacter
```
