# 娜娜莉（华丽飞踢）配置须知

本文记录 `Assets/Models/异环_娜娜莉（华丽飞踢）` 当前已经验证过的物理配置，重点说明：

- 每个 `DynamicBone` 参数是做什么的
- 这个模型现在实际填的是什么值
- 后续如果用户继续反馈，应该优先调哪里

## 1. 目标与参考

- 目标模型：`Assets/Models/异环_娜娜莉（华丽飞踢）`
- 目标 prefab：`Assets/Models/异环_娜娜莉（华丽飞踢）/娜娜莉（华丽飞踢）.prefab`
- 参考模型：`Assets/Models/异环_娜娜莉（学园之星）`

## 2. 先记住的结论

这次模型最容易搞错的是下面两点：

1. 腰上那件可见的绑身外套 / 裙摆，主驱动骨链不是 `Bn_*_cloth*`，而是 `Bn_*_qunB*` 和 `Bn_*_qunC*`。
2. 尾巴当前不是 6 个碰撞体，而是只保留了 3 个躯干碰撞体。

## 3. 当前 DynamicBone 分组

当前 `娜娜莉（华丽飞踢）.prefab` 一共 13 组 `DynamicBone`：

- 尾巴：1 组
- `cloth*`：7 组
- 腰间外套 / 裙摆 `qunB/qunC`：5 组

### 3.1 尾巴

- 根骨：`Armature/root/Bip001/Bip001-Pelvis/Bn_m_qunB_001/Bn_m_tail_001`
- 说明：尾巴维持当前版本，不再回退

### 3.2 腰间外套 / 裙摆

当前真正控制可见绑腰外套摆动的是这 5 条骨链：

- `Bn_l_qunB_001`
- `Bn_m_qunB_001`
- `Bn_r_qunB_001`

下面这 7 条骨链仍然保留 `DynamicBone`：

- `Bn_l_clothB_001`

- `Bn_r_clothC_001`

但它们不是当前用户看到的那件腰间外套的主驱动来源。

## 4. 先看懂曲线是怎么生效的

这个项目里最重要的一点，不是只看基础值，而是要看基础值和分布曲线一起算。

实际生效值的计算方式可以直接理解成：

`最终值 = 基础值 × Distrib 曲线在当前位置的倍率`

其中：

- `0` 代表骨链根部
- `1` 代表骨链末端
- 如果中间还有一个关键点，比如 `0.68`，意思就是前 68% 的骨链和后 32% 的骨链会用不同的倍率变化

所以：

- 基础值决定“这一组大概有多强”
- `Distrib` 决定“这股力主要作用在前段还是后段”

## 5. 每个 DynamicBone 参数的作用

下面这些解释，都是按当前项目实际使用方式来写的。

| 参数 | 作用 | 调大后的感觉 | 调小后的感觉 |
| --- | --- | --- | --- |
| `m_Root` | 这组物理从哪根骨头开始接管 | 不是数值参数 | 不是数值参数 |
| `m_UpdateRate` | 内部模拟频率 | 更密、更稳 | 更省但更粗 |
| `m_UpdateMode` | 用什么时间步更新 | 取决于模式 | 取决于模式 |
| `m_Damping` | 给现有摆动“刹车” | 更稳、更不晃、更容易停 | 更活、更拖尾、更会继续摆 |
| `m_DampingDistrib` | `Damping` 沿骨链的倍率分布 | 哪一段更容易被刹住 | 哪一段更容易保留摆动 |
| `m_Elasticity` | 拉回初始朝向的弹性力 | 更容易回正、更像被拉回去 | 回正更慢、更容易拖 |
| `m_ElasticityDistrib` | `Elasticity` 沿骨链的倍率分布 | 哪一段更爱回正 | 哪一段更不爱回正 |
| `m_Stiffness` | 保持原始朝向、限制偏折的刚性 | 更挺、更板、更不容易弯 | 更软、更容易折出去 |
| `m_StiffnessDistrib` | `Stiffness` 沿骨链的倍率分布 | 哪一段更硬 | 哪一段更容易解锁 |
| `m_Inert` | 身体位移有多少直接带给骨链 | 更跟身、更少拖尾 | 更拖尾、更容易晚半拍 |
| `m_InertDistrib` | `Inert` 沿骨链的倍率分布 | 哪一段更跟身 | 哪一段更拖尾 |
| `m_Radius` | 粒子的碰撞半径 | 更容易挡穿模，也更容易被卡住 | 更不容易被卡，但更容易穿模 |
| `m_RadiusDistrib` | `Radius` 沿骨链分布 | 哪一段更粗 | 哪一段更细 |
| `m_EndLength` | 在末端补一个虚拟长度 | 末端更长 | 不补 |
| `m_EndOffset` | 在末端补一个虚拟偏移 | 末端多一个虚拟点 | 不补 |
| `m_Gravity` | 额外重力方向 | 更往某方向垂 | 不额外下坠 |
| `m_Force` | 额外持续外力 | 更往某方向飘 | 没有外推力 |
| `m_Colliders` | 参与碰撞的碰撞体列表 | 限制更多，不易穿模 | 限制更少，更自由 |
| `m_Exclusions` | 不参与这一组模拟的骨头 | 避免和别的组打架 | 不排除 |
| `m_FreezeAxis` | 锁某个轴的平面运动 | 运动更受限 | 完全自由 |
| `m_DistantDisable` | 远距离自动关物理 | 远处省性能 | 一直算 |
| `m_ReferenceObject` | 远距离判断参考物 | 配合上项用 | 不启用时无意义 |
| `m_DistanceToObject` | 远距离阈值 | 更远才关闭 | 更近就关闭 |

## 7. 当前三类配置的实际数值

### 7.1 尾巴配置

尾巴当前只保留 1 组。

| 参数 | 当前值 | 备注 |
| --- | --- | --- |
| `m_Root` | `Bn_m_tail_001` | 尾巴根骨 |
| `m_Damping` | `0.24` | 摆动阻尼偏低，保证整条尾巴会传动 |
| `m_DampingDistrib` | `0 -> 0.32`, `1 -> 0.18` | 根部有效值约 `0.077`，末端约 `0.043` |
| `m_Elasticity` | `0.56` | 回正力中等 |
| `m_ElasticityDistrib` | `0 -> 0.42`, `1 -> 0.70` | 根部约 `0.235`，末端约 `0.392` |
| `m_Stiffness` | `0.20` | 让尾巴别像棍子 |
| `m_StiffnessDistrib` | `0 -> 0.28`, `1 -> 0.06` | 根部约 `0.056`，末端约 `0.012` |
| `m_Inert` | `0.82` | 跟身能力较强 |
| `m_InertDistrib` | `0 -> 0.58`, `1 -> 1.00` | 根部约 `0.476`，末端约 `0.82` |
| `m_Colliders` | 3 个 | `Pelvis`、`Spine1`、`Spine2` |
| `m_Exclusions` | 空 | 不排除额外骨头 |

当前这套尾巴的目标是：

- 整条链都能传递摆动
- 不再只有尾尖在轻微动
- 同时避免被头和手臂碰撞体夹死

### 7.2 腰间外套 / 裙摆 `qunB/qunC`

这 5 组当前统一使用同一套基础参数。

| 参数 | 当前值 | 备注 |
| --- | --- | --- |
| `m_Root` | `Bn_l/m/r_qunB_001`、`Bn_l/r_qunC_001` | 5 条裙摆链 |
| `m_Damping` | `0.31` | 比上一版略稳，避免太松散 |
| `m_DampingDistrib` | `0 -> 1`, `0.68 -> 1`, `1 -> 0.82` | 前 68% 保持原强度，末端稍微更自由 |
| `m_Elasticity` | `0.58` | 比上一版再降一点，减少“回正太快” |
| `m_ElasticityDistrib` | `0 -> 1`, `0.68 -> 1`, `1 -> 0.22` | 前段维持形体，末端明显减弱回正力 |
| `m_Stiffness` | `0.32` | 保持外套前段别塌，但不做成板子 |
| `m_StiffnessDistrib` | `0 -> 1`, `0.68 -> 1`, `1 -> 0.15` | 最后几个节点真正解锁 |
| `m_Inert` | `0.58` | 跟身体走，但保留一定拖尾 |
| `m_InertDistrib` | `0 -> 0.20`, `1 -> 0.85` | 根部更拖，末端更跟随前一节 |
| `m_Colliders` | 3 个 | `Pelvis`、`Spine1`、`Spine2` |
| `m_Exclusions` | 大多为空 | 只有中间 `Bn_m_qunB_001` 那组排除了 `Bn_m_tail_001` |

把这组换算成更直观的有效值，大致是：

| 项目 | 根部有效值 | 末端有效值 |
| --- | --- | --- |
| `Damping` | `0.31` | `0.254` |
| `Elasticity` | `0.58` | `0.128` |
| `Stiffness` | `0.32` | `0.048` |
| `Inert` | `0.116` | `0.493` |

这套数值当前想达成的感觉是：

- 前半段稳住，不塌腰
- 最后一截明显比前面更自由
- 不是整片一起硬转
- 也不会像上一版那样太软

如果用户反馈“摆动回正太快、显得僵硬”，优先下调的是：

1. `m_Elasticity`
2. `m_ElasticityDistrib` 末端倍率
3. `m_Stiffness` 或 `m_StiffnessDistrib` 末端倍率

这次刚做的就是这个方向。

## 8. 当前碰撞体使用规则

### 8.1 尾巴

- 只用 3 个躯干碰撞体
- 不再用头和双上臂碰撞体

### 8.2 腰间外套 / 裙摆 `qunB/qunC`

- 也只用 3 个躯干碰撞体
- 目的是避免腰间外套被头部或手臂碰撞体错误限制

### 8.3 `cloth*`

- 仍然保留 6 个碰撞体的旧方案

## 9. 出现不同观感时，优先改哪个参数

| 现象 | 优先调整 |
| --- | --- |
| 几乎不动 | 先降 `Damping`，再降 `Stiffness`，再看碰撞体是不是太多 |
| 回正太快、显得僵 | 先降 `Elasticity`，再降 `ElasticityDistrib` 末端倍率，再降 `Stiffness` |
| 太软、塌、没支撑 | 先升 `Stiffness`，再升 `Damping` |
| 拖尾太重、跟不上身体 | 升 `Inert` |
| 摆动太碎、像抖 | 升 `Damping` |
| 容易穿模 | 增加 `m_Colliders`，或之后再考虑给 `m_Radius` |

## 10. 最低验证项

每次改完至少检查下面几点：

1. 腰上外套在角色转身、起停时，末端能明显晚于根部摆动
2. 裙摆应该是“后段解锁”，不是整片一起硬转
3. 尾巴维持当前版本，不要被新改动带坏
4. 中间裙摆链不能和尾巴互相抢控制

## 11. 当前最终结论

可以直接记住这几条：

1. 腰间可见外套主看 `qunB/qunC`
2. `cloth*` 不是主驱动来源
3. 尾巴只用 3 个躯干碰撞体
4. 裙摆如果“回正太快”，优先降 `Elasticity`
5. 裙摆如果“太软没支撑”，优先升 `Stiffness`
