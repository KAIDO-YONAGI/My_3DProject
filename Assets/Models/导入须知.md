# 异环_娜娜莉 角色导入须知

适用目录：

- `Assets/Models/异环_娜娜莉（华丽飞踢）`
- `Assets/Models/异环_娜娜莉（学园之星）`

已整理完成：

- 两个角色 prefab 直接引用的动作资源，已经复制到各自目录下的 `Dependencies/CLazyRunnerActionAnimPack`。
- 两个角色实际用到的共享脚本，已经统一整理到 `Assets/Models/_SharedDependencies`。
- prefab 里的动作引用和脚本引用都还保持有效；脚本是通过保留原 `.meta` GUID 的方式迁移的。

当前这两个角色目录内，各自带有一套独立动作副本，共 `25` 个资源：

- `Idle` 1 个
- `Jog` 10 个
- `Boost` 10 个
- `Walk` 1 个
- `Walk Controller` 1 个
- `Jump` 2 个

导入到新项目时，至少需要一并带走：

1. `Assets/Models/异环_娜娜莉（华丽飞踢）`
2. `Assets/Models/异环_娜娜莉（学园之星）`
3. `Assets/Models/_SharedDependencies`

共享脚本目录说明：

- 角色控制脚本：
  - `Assets/Models/_SharedDependencies/Movement`
- Dynamic Bone 运行脚本：
  - `Assets/Models/_SharedDependencies/DynamicBone/Scripts`

当前 prefab 实际会用到的组件包括：

- `SimpleActionCharacterController`
- `ThirdPersonMouseCamera`
- `DynamicBone`
- `DynamicBoneCollider`

这些组件背后的脚本依赖已经一并整理进共享目录，包括：

- `CameraFloorAvoidance`
- `CharacterBoneFollower`
- `SimpleCharacterMotor`
- `SimpleCharacterStateMachine`
- `SimpleCharacterAnimationRig`
- `DirectionalAnimationSet`
- `SimpleCharacterMovementSettings`
- `DynamicBoneColliderBase`
- `DynamicBonePlaneCollider`

是否还需要额外安装 Dynamic Bone：

- 一般不需要。当前工程里实际用到的 Dynamic Bone 脚本已经跟着角色整理到了 `Assets/Models/_SharedDependencies/DynamicBone/Scripts`。
- 如果目标项目里已经有另一份 `DynamicBone` 插件或同名脚本，不要再重复导入这一份，否则会出现重名类冲突。

建议导入环境：

- Unity `2022.3.62f3c1`

迁移建议：

1. 最稳妥的方式是直接复制上面这 3 个目录，并保留所有 `.meta` 文件。
2. `Assets/CLazyRunnerActionAnimPack` 原始动作包，对这两个 prefab 现在已经不是必需项；但如果当前项目里还有别的角色或场景在用它，不要删除原包。
3. 当前工程里的 `Assets/Scripts/Movement` 已经迁到 `Assets/Models/_SharedDependencies/Movement`。
4. 当前工程里的 `Assets/DynamicBone/Scripts` 已经迁到 `Assets/Models/_SharedDependencies/DynamicBone/Scripts`。

可选项：

- 如果你还想保留编辑器里的自动配置缓存，再额外带上：
  - `Assets/Settings/SimpleCharacterAutoConfigCache.asset`
- 这个缓存不是 prefab 运行必需项，不带也能正常显示和播放当前已绑定动作。

可选精简：

- 如果目标项目只想要静态角色展示，不需要键鼠动作控制，也不需要头发或饰品物理，可以在导入后移除这些组件：
  - `SimpleActionCharacterController`
  - `ThirdPersonMouseCamera`
  - `DynamicBone`
  - `DynamicBoneCollider`
- 做完上面的精简后，`Assets/Models/_SharedDependencies` 里的大部分脚本都可以不再保留。
